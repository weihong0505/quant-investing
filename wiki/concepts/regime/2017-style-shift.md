# 2017 风格切换（Style Shift）

## 事件概述

2017 年是 A 股风格的分水岭：**大盘白马蓝筹（"漂亮50"）持续跑赢，中小创/小盘股系统性跑输**。

- 上证 50 / 沪深300 全年上涨，白酒（茅台）、家电（美的、格力）、金融（保险、银行）等白马龙头估值修复 + 业绩驱动双升；
- 创业板、中证 1000、微盘风格全年大幅跑输，壳价值、并购重组逻辑退潮（2016 年并购新规 + 2017 年 IPO 常态化 + 减持新规收紧）；
- 外资（陆股通）与机构定价权上升，"业绩为王"取代"题材为王"；
- 2017-2019 小市值因子经历大幅回撤，A 股小盘溢价阶段性终结（与美股 2017 前小盘弱化趋势同期）。

## 时间线

- **2016-12**：中央经济工作会议定调"稳中求进"，监管从严（险资举牌受限）。
- **2017-01~12**：白马单边行情；4 月起金融监管"三三四"去杠杆，中小票承压加剧；11 月见顶后回落。
- **2018**：贸易战熊市，全市场下跌，但白马相对抗跌（2018-01 上证50 一度 11 连阳"虹吸效应"）。

## 为什么记入 Wiki（与项目关联）

1. **回测样本分层依据**：回测工程规范 v2.1 将 **2017-2018 定为"参考段"（辅助证据，不作主判定）**，2019-01 起为主段、2021-02 起为核心段——2017 风格切换是"结构可比性 > 样本长度"分层的现实基础（2017-2018 是价值/小盘策略的结构性弱势期，2019-2021 成长碾压期同理）。
2. **参考段触发线**：参考段净超额年化 ≤−3% 或超额回撤 <−5% 触发《参考段连续性说明》；负段归因锚定 v3 滚动 36m ICIR 观察线（"风格现象 vs 结构失效"判别）。
3. **规模因子语境**：LOG_MCAP（方向 −1，小盘偏好）的"2017 年后小盘溢价有所减弱"即本事件的直接后果；2017-2019 小盘大幅回撤是 log-mcap 页"已知问题"的历史出处。
4. **M5 复盘**：DIRECTION 表（含 LOG_MCAP−）来自美股文献先验，2017 风格切换说明 A 股本地符号必须实测验证（signed IC 第 0 步）。
