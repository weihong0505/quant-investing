# 回测工程规范 v2.1



## 概述

回测的数据口径、引擎规则、样本期、策略判定标准。MImo 两轮审查定稿。

全文：`G:/股市探究/quant-investing/code\factor_docs\backtest_engineering_spec_v2.1.md`



## 核心裁决

| 主题 | 裁决 |

|------|------|

| 复权 | 全系统统一 **hfq**（qfq 新除权改写全部历史，年化漂移4~5%） |

| 双口径 | 收益/比率类信号 hfq；市值/股价水平/股息率/EP/BP 用 raw 价 |

| 基准 | **510300/510500 ETF hfq 主基准**；价格指数不含分红（虚增超额 1.5~2.5%/年） |

| 引擎 | 自研（500~800行）+ 金样本对账 + 与 v3 分层引擎交叉验证 |

| 样本 | 主 2019-01+ / 核心 2021-02+ / 参考 2017-2018 / <2017 弃用 |



## 策略判定标准（7 条，经济+一致性，无显著性硬线）

1. 主段+核心段净超额均 >0（两级标签：≥3% 达标 / 0~3% 边际通过）

2. 2x 成本敏感性 >0；观察线：1x 成本拖累 ≤ 毛超额 50%

3. 最大回撤不劣于同段双基准（**卡玛仅报告项**——基准卡玛实测 0.006~0.010，0.5 线是标定错误）

4. 引擎一致性：Top30 净收益落在 v3 分层 Q4~Q5 之间

5. 滚动 36m 超额曲线无断点

6. 三段制度段切分，负段解释锚定 v3 观察线

7. 入池因子全部通过 v3 检验（存量 10 因子待补检过渡条款）



## 关键实测

- 基准卡玛 0.006~0.010 → "卡玛≥0.5"隐式要求年化≥22.8%，与回撤约束自相矛盾

- 3% 最小幅度线功效仅 20.3%（真3%策略50%概率被误杀）→ 不加硬线

- 东财跨两轮 ≥24h 持续性封禁 → 主源降级预案为刚需（降级新浪源+声明）
