## 1. 问题现状

DIRECTION 表（EP+/BP+/MOM+/TURNOVER−/LOG_MCAP−/VOL_RATIO+）来自美股文献先验（Fama-French、Basu、Jegadeesh-Titman 等），registry 前置登记把"预期符号"锁死了——但符号从未在 A 股 2017+ 样本上验证过。项目自己的研究记录过 A 股 2017 风格切换、2021 抱团瓦解、2024 微盘危机，却把文献先验当结论使用。MOM+ 与 EP/BP+ 的"最大因子矛盾"（Wiki momentum 页自认）被记录、被搁置，然后以 40% 价值+15% 动量线性相加继续运行。

## 2. 证据

- registry：10 因子预期符号列已锁（+ + + + + − + − − +），统计列全空（S1）——符号锁定时零本地证据
- `wiki/concepts/factors/momentum-60d.md` "已知问题"："与价值因子的冲突：EP 说'买银行'，动量说'卖银行'——这是系统中最大的因子矛盾"
- 组合照常运行：WEIGHTS = EP 0.20 + BP 0.20 + MOM_60D 0.15（L52-63），无任何矛盾处理
- 项目自己的实测记录（factor_docs 审查报告）：A 股存在 2017 风格切换/2021 抱团瓦解/2024 微盘危机等结构性断点

## 3. 为什么是错

1. 文献先验 ≠ 本地事实：美股 1927-2016 的价值/动量溢价在 A 股 2017+ 是否成立，本身就是待检验问题——项目把"待检验"当成了"已给定"
2. 矛盾的组合没有裁决：价值与动量同时高权重线性相加，可能是互补增强，也可能是噪声相消——**从未测过**，两种可能都有，等于在盲跑
3. "记录矛盾、继续运行"是最坏的处理方式：记录给了"已经处理"的错觉，实际零处理

## 4. 修改要求

1. **符号本地验证**（并入 S1 检验流程，作为每个因子的第 0 步）：每个因子在 A 股 2017+ 样本上计算**signed IC**，与 registry 锁定符号对照：
   - 一致 → 正常走 v3 检验
   - 相反且显著 → 按防改口三件套：该次检验作废，以新因子号反转方向重新登记，计入 N'
2. **MOM×价值矛盾用 FM 增量检验裁决**（v3 已有条款）：FM 多元回归，变量 `ln_mcap / EP / BP / MOM_60D + 申万行业哑变量`，单侧 NW-t ≥ 2.0 为增量信息：
   - MOM 与 EP/BP 同时显著 → 互补，保留组合，记录交互
   - 只有一方显著 → 淘汰另一方（或权重重排），记 weight-change
   - 都不显著 → 都降权回炉
3. 裁决结果落 registry 备注列 + 独立报告 `factor_docs/test_value_vs_momentum_{日期}.md`
4. 裁决前，momentum 页加 contested 标记（联动 W2 条目 4）；裁决后回填
