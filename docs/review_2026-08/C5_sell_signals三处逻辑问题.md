## 1. 问题现状

卖出信号模块三处逻辑与实际执行口径不一致，其中第 1 项造成止损触发点系统性错位，第 2 项让声明参数失效。

## 2-3. 逐项证据与修改要求

### 子项 1：止损基准价用信号日收盘价，实际成交是 T+1 开盘价

- **证据**：`code/sell_signals.py` L57 `holdings: dict = {}  # code -> (entry_date, entry_price)`；L135 附近新买入时 `entry_price = float(prices[code])`，其中 `prices = price_table.loc[date]`（**信号日**月末收盘价）。但引擎按 v2.1 执行 T+1 **开盘价**成交（backtest.py docstring L13）。
- **为什么是错**：跳空缺口下，账面盈亏从信号日收盘算起，而真实成本是次日开盘。信号日收盘 → T+1 开盘若低开 3%，止损线（默认 −15%）的真实触发点错位 3 个百分点；极端跳空（利空跌停开盘）时账面与实盘差距更大。止损是风控的底线，底线的位置不能漂移。
- **修改要求**（二选一，用户拍板）：
  - 方案 A（推荐）：止损判定**下移到引擎层**——引擎有真实成交价（`Position.avg_cost`），在每日循环或月末估值时用真实浮亏触发卖出信号，信号层只负责时间止盈与信号衰减（这两类只依赖排名与持有期，不依赖成交价）
  - 方案 B：信号层保持现状，但 `entry_price` 改用 **T+1 开盘价**（generate_signals 需传入含 T+1 开盘的 price_table 或成交价表），并在 docstring 明确口径
- **验收**：合成用例——信号日收盘 10 元、次日开盘 9.5 元、随后跌到 8.4 元（真实浮亏 −11.6% < 15% 但按信号日收盘价算 −16% 已触发）：方案 A/B 下该股**不**触发止损（或按真实口径触发，与账面一致）。断言与实际成交价口径一致。

### 子项 2：keep_rank=60 是死代码——实际"跌出 30 即卖"且绕过冷却期

- **证据**：`SellRules.keep_rank = 60`（L26），卖出判定"排名跌出 keep_rank 卖出"（L80-82）；但买入候选循环 `if len(candidates) >= top_n: break`（L113 附近），信号矩阵只给 Top N=30 权重。排名 31~60 的持仓：未触发 signal_decay（仍在 keep_rank 内）、不会进入 candidates（循环在 30 处 break）、信号权重为 0 → 引擎按"目标权重 0"直接清仓，**不经过 cooldown、不记录卖出原因**。
- **为什么是错**：声明的规则（跌出 60 才卖）与实际行为（跌出 30 就卖）不一致；两条卖出路径（signal_decay vs 权重归零）口径不同，冷却期防频繁进出的设计被绕过；卖出原因统计失真。
- **修改要求**：三选一（用户拍板）：
  1. `keep_rank` 与 `top_n` 联动：`keep_rank = top_n`，删除独立参数，docstring 写明"排名跌出 top_n 即卖"
  2. 保留 31~60 的持仓权重：信号矩阵对"排名在 top_n 外、keep_rank 内"的旧持仓保留非零权重（需要放弃严格等权，改为持仓权重按 1/n_hold 归一）——涉及组合权重方案，改动较大
  3. 删除 keep_rank 与 signal_decay 逻辑，卖出仅由时间止盈+止损驱动（最简，符合"低换手价值投资"定位）
- **验收**：合成用例——持仓股排名 35（keep_rank=60 内、top_n=30 外）时行为与所选方案文档一致；卖出原因记录完整（含冷却期状态）。

### 子项 3：等权 1/top_n 无现金再配置

- **证据**：`w = 1.0 / top_n`（L128 附近）对所有候选固定；候选不足 top_n（时间止盈+冷却期叠加时必然出现）时总权重 <1，剩余现金趴账 0 收益。
- **为什么是错**：现金拖累是隐形成本（SOP §A.3 明确"未投仓位计 0 收益（保守）"）；且现金比例随卖出事件波动，组合暴露不可控。
- **修改要求**：候选不足 top_n 时，把剩余权重**按现有候选等比放大**（`w = 1.0 / len(candidates)`）；或维持 1/top_n 但将"现金占比"作为输出列报告并在 docstring 声明。二选一，用户拍板。
- **验收**：合成用例——候选 8 只（top_n=10）时权重合计 = 1.0（方案一）或现金占比被明确报告（方案二）。
