## 1. 问题现状

v3 方法论是**因子级**检验（单因子 IC/分层多空），v2 策略是 **10 因子加权打分**。项目隐含假设"因子都过检 ⇒ 组合可用"——逻辑链条断在因子→组合这一步。且权重（EP 20% vs MOM 15% 的依据）没有任何检验记录。

## 2. 证据

- v3 方法论全文无"组合层检验"章节；SOP §3.2 检验对象均为单因子
- 权重来源：`code/multi_factor_value.py` L52-63 WEIGHTS 注释仅写"v2 权重（已按审查 Q4 调整）"——MImo Q4 只调整了质量组内部权重，EP 0.20 / MOM 0.15 / TURNOVER 0.10 等跨组权重的依据不存在
- 项目文档中没有任何"合成 SCORE 的预测力"检验记录（无合成 IC、无合成分层、无合成回测）

## 3. 为什么是错

1. 单因子显著不能推出线性组合显著：因子间相关（EP×BP、MOM 与价值的负相关——Wiki 自认的"最大矛盾"）、权重配比、方向叠加都可能让组合的净信号互相抵消或集中于单一暴露
2. 权重无依据 = 组合结构是拍脑袋的——这与项目"因子有据"的 SOP 原则直接冲突
3. 缺失这一层，即使 S1 完成，回测结果也无法归因（跑赢/跑输是哪个因子组合的功劳？）

## 4. 修改要求

在 S1 完成后，增加**组合层检验**（方法可并入 v3 或单独成文，建议 `factor_docs/composite_testing_methodology_v1.md`，同样走 MImo 审批）：

1. **合成 SCORE 的横截面检验**：月度 Rank IC（SCORE vs T+1 收益）、合成 ICIR、与单因子 IC 对比——组合 IC 应不低于加权单因子 IC 的基准（否则权重配置有害）
2. **组合引擎回测（真实数据）**：按 backtest_engineering_spec_v2.1 全文执行——净超额（vs 510300/510500 hfq 基准）、2x 成本敏感性、回撤对比、滚动 36m 无断点、制度段切分
3. **权重依据补档**：每个因子的最终权重必须挂证据编号——检验 IC/分层贡献/或明确标注"主观先验（待验）"；权重调整全部记 weight-change 日志
4. **因子交互检查**：高相关因子对（EP×BP 等）在组合中的联合贡献 vs 单独贡献——若联合不加分，按 SOP 共线性闸门处理
5. 结论三档：组合检验通过 → 策略可进入实盘讨论；部分通过 → 权重修订再验；不通过 → 回炉因子选择
