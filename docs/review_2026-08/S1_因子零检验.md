## 1. 问题现状

主策略 v2 的 10 个因子（EP/BP/ROE_TTM/GPM/CFO_NI_TTM/LEV/MOM_60D/TURNOVER/LOG_MCAP/VOL_RATIO）全部以"✅ 主策略"状态在运行，但**没有任何一个因子做过一次统计有效性检验**。项目自己定稿的检验方法论 v3（两轮 MImo 审查）从未被执行。

## 2. 证据

- `docs/factor_docs/factor_registry.md` L23-32：10 个因子的统计列（IC均值/IC标准差/ICIR/naive t/NW-t/胜率/覆盖率/PT MR p/净多空年化/夏普/2x成本/内部基准）**全部为 "—"**；表格底部自述"当前 N'（本季度同期受检）= 0"
- `docs/factor_docs/` 目录清单中**不存在**任何 `test_{因子}_{日期}.md` 检验报告——而 SOP §3.2-6 明确要求"检验报告 factor_docs/test_{因子}_{日期}.md + registry 回填"
- registry 自定规则："未登记的因子检验结果无效"、"检验前登记 → 检验后追加式回填"——回填列全部为空 = 零检验完成

## 3. 为什么是错

1. 按 v3 判定线（预登记方向 signed NW-t ≥ max(3.0, Bonf(N'))、ICIR>0.5 且 |mean IC|≥0.02、净多空年化≥8% 且 2x成本为正、PT MR 单调性），10 个因子没有一个通过——**甚至没有进入过检验流程**
2. v2 策略的权重（EP 20%、MOM 15%……）、方向、去留是在零统计证据下确定的
3. 项目在方法论制定上投入两轮审查，在方法论执行上投入为零——产出比 0

## 4. 修改要求

1. **前置条件**：先完成 C10/S2（数据层），拿到 2017+ 历史行情（hfq+raw）+ 财务数据（yjbb/zcfz，逐期 PIT）+ 指数/ETF 基准
2. 按 `factor_testing_methodology_v3.md` 全文，对 10 个因子逐一执行完整检验流程（先 registry 前置登记预期符号 → IC 关 → 分层关 → 经济闸门 → 样本内外划分）
3. 检验结果**追加式回填** registry（不改原行，防改口三件套生效）；每个因子产出一份 `factor_docs/test_{因子}_{日期}.md`
4. 检验结论分三档处理：过线 → 保留；观察线 → 降权/观察；不过线 → 移出主策略（含权重重归一化，同步更新 code/multi_factor_value.py WEIGHTS/DIRECTION 与 Wiki factor-direction-map 页，记 weight-change 日志）
5. 多重检验阈值使用 v3 单一规则：`max(3.0, Bonferroni(N', 单侧α=0.05))`，N'=本季度同期受检新因子数
6. 注意 v3 的 A 股陷阱清单：等权 5 分组微盘污染（必做市值加权+剔<30亿+规模中性三重稳健性）、次新股剔除≥120 交易日、覆盖率<70% 告警、结构断点分段报告
