## 1. 问题现状

主选股管线的第一步 `get_spot()` 依赖东财 `stock_zh_a_spot_em`（SOP 自述"易限流"的 70 页分页接口），当前处于跨日封禁状态；代码内**没有任何降级路径**，G 盘 data_cache 为空——选股管线此刻无法产出任何输出。

## 2. 证据

- 实测 2026-08-22：`_netdiag.py` 显示 `[eastmoney] FAIL: ReadTimeout`（百度直连 200，排除代理/DNS 问题）——东财侧封禁仍在持续
- `code/multi_factor_value.py` `get_spot()`（L121-142）：只有 `retry(ak.stock_zh_a_spot_em)` 一条路；失败即 `RuntimeError` 中断整个管线
- SOP §1.4 写了降级策略（"spot_em 被限时：跳过当次行情获取（用缓存），财务数据照常跑"、"关键缺口 PE/PB 可延后补拉"）——**策略只写在文档里，没写进代码**
- `code/data_cache/` 不存在 → "用缓存跳过"的预案是空谈（缓存为空，跳过=无数据）

## 3. 为什么是错

1. 单点依赖 + 无降级 = 可用性为零。东财的封禁是持续 ≥24h 级别的（项目自己的实测记录），不是偶发抖动
2. "文档里有预案、代码里没实现"——预案不落地等于没有
3. 选股是实盘决策的前置输入，数据断供直接锁死整个项目

## 4. 修改要求

1. `get_spot()` 增加降级链：东财 spot（首选）→ **新浪兜底**：
   - 新浪 `stock_zh_a_spot()` 稳定但无 PE/PB 列 → 降级时用「新浪价格/总市值 + 本地财务缓存（yjbb EPS_TTM、zcfz 每股净资产）」自行计算 PE/PB：`PE_TTM = 最新价 / EPS_TTM`、`PB = 最新价 / 每股净资产`（注意用 raw 价，符合双口径铁律）
   - 输出 schema 与东财路径对齐（代码、名称、最新价、市盈率-动态→改为按 C9 子项1 的口径、市净率、总市值、换手率、60日涨跌幅——新浪缺的字段（60日涨跌幅、量比）**自算**：60 日涨跌幅用新浪 `stock_zh_a_daily` 复权价自算；量比按 C9 子项5 结论处理）
2. 降级时**必须**在输出与日志中声明数据源与缺失字段（"本次 PE/PB 为新浪价格×本地财务合成"），禁止静默换源
3. 缓存策略升级：`data_cache/` 分层（spot 快照保留最近 3 个交易日；财务数据永久），首次运行允许"用最近一次快照+声明陈旧度"
4. 拉取纪律：东财路径保持分页 sleep ≥0.5s；失败重试 3 次后退避后自动切新浪（不再抛 RuntimeError 中断）
5. 与本任务联动：S2 的 data_fetcher.py 应吸收本降级逻辑（避免两处实现），若 S2 先行则本任务简化为"get_spot 改用 data_fetcher"

### 7.3 ❌ 关键失败：产出 pick 表无选股价值（本项未通过）

- `D:/pyh/python.exe -E run.py` 首次实跑：缓存命中旧 `spot_20260822.parquet`（合成修复前生成，PE/PB 全 NaN）→ `get_spot` 过滤后**入池 0 只** → 空选股表、空 pick csv（不报错，静默产出空文件）
- `get_spot_data(force_refresh=True)` 刷新缓存后重跑：入池 1291 只，但 pick_20260822.csv **30 行全为北交所 bj 前缀 + SCORE 全 NaN**
- 根因（实测验证）：
  1. **代码前缀不匹配**：新浪 spot `代码` = `bj920000`/`sh600000`（带前缀），`build_quality_factors` 产出 qdf `代码` = 纯数字（`000001`）→ `score_factors` 中 `spot.merge(qdf, on='代码')` 全失败：ROE_TTM/EPS_TTM 覆盖 0/1291；剥离前缀后 1291/1291 ✅（即修复方向：`_normalize_spot` 对新浪代码剥前缀，或 merge 前统一）
  2. **北交所过滤失效**：`get_spot` 用 `df['代码'].str.startswith(('4','8'))` 过滤北交所，但新浪代码为 `bj92xxxx` 前缀 → 97 只北交所全部漏网（本应剔除）
  3. 因子全 NaN → SCORE 全 NaN → `sort_values` 后取 head(30) = 新浪返回顺序前 30（全是北交所）
