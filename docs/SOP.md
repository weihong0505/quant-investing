## 0. 总原则



1. **SOP 优先** — 遇新问题先完善 SOP 再继续；SOP 是唯一事实源

2. **先环境，后策略** — 脚本跑不通先查环境（代理/限流/依赖/路径），再查逻辑

3. **小步验证** — 数据到手先看 schema（列名/类型/行数），再写因子

4. **结果可复现** — 输出带日期戳 CSV + 日志；数据落盘缓存

5. **因子有据** — 新因子必须有金融逻辑 + 异构 AI 审批 + IC 检验（见 §3.0）

6. **成本意识** — 回测必须计佣金+滑点（A股约万2.5佣金+千1印花税卖出）

### 1.3 网络与代理（⚠️ 最高频故障区）

本机装有 Clash Verge。Python 访问国内接口的**标准三件套**（脚本头部固定模板）：

```python

import os

os.environ['NO_PROXY'] = '*'

for k in list(os.environ):

    if 'proxy' in k.lower():

        os.environ.pop(k, None)

import requests

_orig = requests.Session.request

def _no_proxy(self, method, url, **kwargs):

    kwargs['proxies'] = {'http': None, 'https': None}

    kwargs.setdefault('timeout', 30)

    return _orig(self, method, url, **kwargs)

requests.Session.request = _no_proxy

```



**故障诊断判断树**（按序排查）：

1. `ProxyError` → 代理拦截 → 查三件套是否在 import requests 之前

2. `RemoteDisconnected` / `Connection aborted` → **接口限流**（非代理问题！）→ 等 10+ 分钟冷却，或换数据源

3. 返回空 DataFrame → 接口变更/参数错误 → 查 akshare 版本与官方文档

4. 全部请求失败 → 系统级代理（TUN 模式）→ 检查 Clash 是否开启 TUN

5. DNS 失败 → 网络断 → 与数据源无关



**诊断脚本**：`_netdiag.py`（DNS 检查 + baidu/东财直连探测），先隔离问题再动手。

## 3. 标准工作流



### 3.0 因子审批与检验流程（⚠️ 强制，先于一切因子工作）

任何**新因子**或**因子逻辑重大修改**：

1. 写《因子设计方案》到 `factor_docs/{因子名}_v{n}.md`（含：定义/数据源/经济逻辑/学术依据/数据处理规则/风险自查/待审查问题清单）

2. 委派给 **MImo V2.5 Pro**（delegate_task）独立审查——审查 agent 必须**实测接口**验证字段与口径，不得只做纸面审查

3. 审查通过 → 集成；有 P0 意见 → 修订方案出 v{n+1} → 定稿

4. 未过审的因子**不得**进入主策略

5. 审查报告与验证脚本归档到 `factor_docs/`（保留 `_review_verify.py` 类脚本）



已通过设计审批的因子（v2）：EP、BP、ROE_TTM、GPM、CFO_NI_TTM、LEV、MOM_60D、TURNOVER、LOG_MCAP、VOL_RATIO

#### 3.0.1 设计审批 ≠ 统计检验（⚠️ 强制条款）
- **设计审批**：验证因子定义、数据源、经济逻辑、口径是否合理——通过后方可集成代码
- **统计检验**：验证因子在历史数据上是否具有预测力（IC/NW-t/净多空等）——通过后方可进入 WEIGHTS
- **二者不可互替**：设计审批通过不代表因子有效；统计检验通过不代表设计无缺陷
- 未经统计检验的因子，其权重必须标注为"实验性"，不得作为实盘依据

#### 3.0.2 执行顺序强制条款
1. **审批 → 代码合并**：设计审批是代码合并到主分支的前置条件；未审批代码必须放在 `code/_draft/` 目录
2. **检验 → WEIGHTS**：统计检验结论是因子进入 WEIGHTS 配置的前置条件；未检验因子权重标注"实验性"
3. **代码状态标注**：每个策略文件头部必须注明：
   - 审批依据（审批报告路径 + 审批日期）
   - 检验依据（检验报告路径 + 检验结论）或"有效性待检验"
4. **阶段门（Phase Gate）**：
   - **阶段一：数据层 + 因子检验** — 数据获取/清洗/因子统计检验
   - **阶段二：真实数据回测** — 接入真实行情+财务数据的策略回测
   - **阶段三：引擎深化** — 性能优化、高级特性、实盘对接
   - ⚠️ **未过阶段一禁止投入阶段三** — 引擎深化的前提是因子已被证明有效



### 3.1 数据获取 SOP

1. 数据源按 §1.4 优先级表选择

2. 首次获取打印 `df.columns` + `df.shape` + `df.head(3)` 确认 schema

3. 落盘 parquet 缓存（`{接口}_{日期}.parquet`）

4. 请求间隔 ≥0.5s；重试 3 次指数退避（2s/4s/6s）

5. 失败时按 §1.3 判断树定位，限流则冷却后重试或换源

6. 收盘数据当日 18:00 后拉取



### 3.2 因子研究 SOP

0. **字段口径登记**：新因子接入前先在 data_caliber_audit.md 登记口径（来源接口/复权口径/报告期口径），未登记不得入 WEIGHTS

1. **定义**：经济逻辑一句话说明 + 学术依据（精确到论文变量，勿张冠李戴）

2. **清洗**：winsorize(±3σ) → 缺失赋中性分 → 行业/金融股中性化（按审批版规则）

3. **防陷阱清单**（MImo 审查沉淀）：

   - 财务数据用**累计值 TTM**：`TTM = 去年年报 + 最新期累计 − 去年同期累计`

   - 逐股 PIT：最新报告期 = max{报告期 | 公告日期 ≤ 今日}，防披露进度偏差

   - 负利润符号保护：EPS≤0 → 比值类因子（CFO_NI 等）直接最低分

   - 金融股质量因子全部中性化（其毛利率等字段大量缺失且口径无意义）

   - 口径对齐：分子分母必须同为归母或同为合并（每股口径天然对齐）

4. **统计检验**：**全文执行 `factor_docs/factor_testing_methodology_v3.md`**（MImo 两轮审查定稿）

   - 关键线速查：signed NW-t ≥ max(3.0, Bonf(N'))、ICIR>0.5 且 |mean IC|≥0.02、净多空年化≥8% 且 2x成本为正、夏普≥0.8、PT MR 单调性 p<0.05

   - 主判定样本 2017-01 起；最近 24 月样本外一次确认制

   - **检验前必须 registry 前置登记**（预期符号锁定，防改口三件套）

5. **共线性闸门**：集成前跑因子相关系数矩阵，|corr|>0.7 的因子对砍 IC 弱者或权重减半

6. **入库**：检验报告 `factor_docs/test_{因子}_{日期}.md` + registry 回填 + MImo 审批



### 3.3 回测 SOP

1. 成本模型：默认佣金万2.5双边 + 印花税**万5**卖出（2023-08-28 起减半）+ 过户费万0.1双边 + 滑点按市值分档（**细则见 §7 附录A**）

2. 基准：**主基准 = 510300/510500 ETF hfq（含分红再投）；沪深300/中证500 价格指数仅作辅基准**（价格指数不含分红，作主基准会虚增超额 ~1.5~2.5%/年）

3. 必报指标：年化收益（毛/净）、年化波动、夏普、最大回撤、卡玛（报告项）、胜率、年化换手、成本拖累、跟踪误差

4. 稳健性：参数敏感性（±20% 扰动）、**成本敏感性 0.5x/1x/2x 三档（必做）**、样本内外切分

5. 防过拟合红线：单次回测不作数，需样本外验证（滚动窗口统计 rolling_stats.py
   + 一次确认制；判定由 v3 signed NW-t 主判定线给出，见 ic_monitor.ICAlerts；
   注意 90 月样本检出功效仅 20.3%，报告须声明功效限制）

6. PIT 纪律：回测必须按公告日对齐财务数据（防未来函数）

7. 执行规则：T+1 成交（T日收盘信号→T+1开盘价）、涨停不买/跌停不卖/停牌跳过

8. **引擎与数据细则全文执行 `factor_docs/backtest_engineering_spec_v2.1.md`**（MImo 两轮审查定稿：hfq 统一复权、双口径铁律、样本分层 2019+/2021-02+、策略判定 7 条）



### 3.4 价值投资决策流程（v2.1 定稿）

> 依据：`docs/factor_docs/value_investing_transition_v2.1.md`（2026-08-25 终审定稿）。v3 系统 = 价值投资决策系统；旧多因子系统（multi_factor_value.py）保留作对照（P5 净超额对照，MOM_60D 归零后 8 因子重归一化权重表见定稿 §5）。

**四层管线**（替代单一 SCORE 排序；参数默认值以本节为准）：

| 层 | 名称 | 规则概要 |
|----|------|---------|
| ① | 可交易性过滤（约束层） | 停牌/退市/ST 排除；市值 ≥30 亿；日换手率 0.1%~20%；上市 ≥5 年 |
| ② | 质量门槛（排除层，一票否决） | 非金融：ROE_TTM ≥8% 或近5年中位数 ≥8%（周期 8 行业豁免：≥4% 且 EPS>0）；GPM>0；CFO_NI_TTM>0；LEV<70%；EPS_TTM>0（金融股同适用） |
| ③ | 估值打分（核心层） | 安全边际分 = 0.30×PE_PCTL + 0.30×PB_PCTL + 0.15×EP_z + 0.15×BP_z + 0.05×DY_z + 0.05×FCF_YIELD_z（主观先验，W-编号草案挂起，组合层检验后定稿）；行业内 z-score 统一申万一级 |
| ④ | 组合构建 | 按安全边际分 top 10-15（默认 12，等权）；行业上限 ≤30%（申万一级）；个股上限 ≤10%；容量 ≤5% ADV；季度调仓（每季末月最后交易日信号，T+1 执行） |

**生产开关条款（fail-closed，v2.1 §7 P2.5）**：
1. 默认拒绝：实验性权重（4 新因子权重 + 安全边际分主观先验权重）不得运行正式流程、不得输出实盘信号
2. 显式 `--experimental` 允许运行，但输出强制标注"实验性"，**禁止实盘信号输出**

## 7. 附录 A：回测成本模型细则



> 原则：**净收益（扣全部成本后）才是策略真实收益**。默认参数宁保守勿乐观。



### A.1 成本构成（A股现行费率）



| 项目 | 费率 | 方向 | 备注 |

|------|------|------|------|

| 佣金 | 万2.5 (0.025%) | 双边 | 可协商至万1~万1.5；**最低 5 元/笔** |

| 印花税 | **万5 (0.05%)** | 仅卖出 | 2023-08-28 起由千1减半；历史回测须按时段切换 |

| 过户费 | 万0.1 (0.001%) | 双边 | 中国结算收取，固定 |

| 滑点 | 5~30 bp | 双边 | 按市值分档，见 A.2 |



**单边基准**：买入 ≈ 2.5+0.1+滑点 bp；卖出 ≈ 2.5+5+0.1+滑点 bp

**往返基准**（中盘股、10bp 滑点）≈ **30.2 bp**



### A.2 滑点分档模型



| 市值档 | 总市值阈值 | 单边滑点 | 理由 |

|--------|-----------|---------|------|

| 大盘 | ≥ 500 亿 | 5 bp | 流动性充足 |

| 中盘 | 100~500 亿 | 10 bp | 基准档 |

| 小盘 | 30~100 亿 | 20 bp | 冲击成本上升 |

| 微盘 | < 30 亿 | 30 bp | 流动性风险显著 |



**进阶模型（可选）**：参与率平方根法则

`impact_bps = k × σ_daily_bps × √(Q / ADV)`，k∈[0.5,1.0]，Q=订单金额，ADV=20日均成交额

**硬约束**：单股单日成交 ≤ 5% ADV，超出部分拆单跨日



### A.3 执行规则（A股微观结构）



| 规则 | 约定 | 原因 |

|------|------|------|

| T+1 | T日收盘信号 → **T+1 开盘价**成交 | A股不能当日卖出；收盘信号次日才可执行 |

| 涨跌停 | 涨停不买、跌停不卖，顺延次日 | 真实市场无法成交 |

| 停牌 | 跳过，复牌后按信号处理 | 无法交易 |

| 整手 | 买入向下取整至 100 股整数倍 | 交易所规则 |

| 最低佣金 | 单笔 < 2 万元时 5 元最低佣金显著抬升费率 → 引擎警告或跳过小额订单 | 5元/2万=万2.5 盈亏平衡点 |

| 现金拖累 | 未投仓位计 0 收益（保守）或货币基金约2%/年 | 现金不产生收益 |



### A.4 历史费率时变表（跨期回测必用）



| 时段 | 印花税(卖出) | 说明 |

|------|-------------|------|

| ~2023-08-27 | 千1 (0.1%) | 2008-09-19 起单边 |

| 2023-08-28 ~ | **万5 (0.05%)** | 财政部减半征收 |



> 佣金在 2015 年前普遍千1~千3，2015 后竞争降至万2.5~万3，2019 后万1~万1.5。

> 10 年长回测建议分时段：<2015 千1、2015-2019 万3、2019+ 万2.5（可再细分）。



### A.5 成本敏感性验证（必做，策略真实性的试金石）



任何回测必须跑三档成本：**0.5x / 1x / 2x**



| 结论 | 判定 |

|------|------|

| 2x 成本仍跑赢基准 | ✅ 策略稳健，可进入下一阶段 |

| 1x 跑赢、2x 不跑赢 | ⚠️ 边缘策略，需降换手或提高信号强度 |

| 1x 都不跑赢 | ❌ 策略无效，回炉重造 |



同时必报：**年化换手率**（>10x/年 → 成本极敏感，需引入再平衡带）。



### A.6 降成本技术（优先级从上到下）



1. **再平衡带**：权重偏离目标 ±20% 相对阈值才交易，可减半换手

2. **月度固定再平衡**：与日频相比换手降一个量级

3. **成交价选择**：VWAP 优于开盘价（若分钟数据可得）

4. **交易时间分散**：大订单拆 2~3 日执行

5. **限价单模拟**：不追高，挂单在昨收附近（需分钟数据）



### A.7 容量估算（AUM 上限）



```

单股日容量 = 5% × 20日均成交额

组合 AUM 上限 ≈ 单股日容量 × 股票数 / 日换手比例

```

例：30 只小盘股（均额 3000 万/日），单股容量 150 万，组合约 **4500 万**。

AUM > 上限 20% 时滑点模型失效，必须告警。
