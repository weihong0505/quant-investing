# 1万元价值投资执行手册（2026-08-25）

> 适用：A股主板（60/00开头）+ 1-3年长期持有 + 闲钱可承受全额损失
> 原则：**纪律 > 收益；学习 > 回报**。1万元本质是"学费+建立纪律"，目标不是翻倍而是形成可复制的决策流程。
> 依据：value_investing_transition_v2.1.md（系统设计）+ 本手册现实化约束
> ⚠️ 本手册是流程规划，**非投资建议**；全部决策权在你，系统输出只能当线索不能当结论。

---

## 0. 一页速览

```
本金：10,000元（闲钱，可承受全额损失）
持仓：2~3只主板股票（100股/手约束 → 单股预算≤3,300元 → 股价≤30元）
期限：1-3年，季度评估
建仓：分2批（首批50% → 观察1个月 → 补至满仓）
卖出：估值分位>80%连续2月 / 质量破门槛 / 变ST / 公司逻辑变坏
复盘：每季度记录 买入原因/卖出原因/盈亏
```

## 1. 为什么是这个结构（1万元的硬约束）

| 约束 | 推导 | 结论 |
|---|---|---|
| 100股/手 | 12只等权=833元/只，买不起1手 | **持仓2~3只** |
| 单股预算 | 10000÷3只÷100股 ≈ 33元/股 | 筛选股价 **5~30元** |
| 板块权限 | 科创50万/创业10万门槛 | **仅主板**（60/00） |
| 交易成本 | 佣金最低5元/笔≈0.1%本金 | **季度调仓，不做日内**；单笔买入≥3000元使费率≤0.17% |
| 波动承受 | A股单日±10%，3只≈单日±1000元 | 心理准备；闲钱所以可承受 |

**为什么2~3只不是1只**：1只=100%个股风险（黑天鹅全损）；2~3只=有分散但每只占比足够大、有动力深入研究。**为什么不是4只以上**：833元/只买不起1手，且研究精力摊薄。

## 2. 选股流程（系统初筛 → 人工复核）

### 2.1 系统初筛（跑一次，输出候选池）

```bash
cd G:\股市探究\quant-investing\code
D:\pyh\python.exe -X utf8 -E run_screen.py --top 3
# 或双击 run_screen.bat（严格模式，PE/PB分位均<50%）
# 可选 --min-mcap 30 放宽市值；--no-save 只打印不落盘
```

初筛后**手动追加现实过滤**：
1. 主板（60/00开头，剔除688/8/4/9/3开头次新科创创业）
2. 股价 5~30 元（买得起2~3手）
3. 市值 ≥ 50亿（避开微盘操纵风险；spot缓存无市值列时用 总市值=price×总股本 补算或人工查）
4. 剔除 ST/*ST（spot 名称含 ST 即剔除）

### 2.2 人工复核清单（每只候选必答5问）

| # | 问题 | 数据来源 | 过关标准 |
|---|---|---|---|
| 1 | 它靠什么赚钱？你能用一句话说清吗？ | 年报/公司简介 | 说不清 → 放弃（能力圈原则） |
| 2 | 质量门槛：ROE≥8%且可持续？ | yjbb 净资产收益率 | 高ROE是**5年均值**更可靠（周期股看中位数） |
| 3 | 现金流是真的吗？ | 每股经营现金流 | cfps/eps ≥ 0.5 更健康；长期为负 → 放弃 |
| 4 | 便宜吗？ | PE<15 且 PB<2 优先；分位<50% | 用系统 PE_PCTL/PB_PCTL；负PE/PB剔除 |
| 5 | 负债安全吗？ | 资产负债率<70% | 金融股豁免此条（银行天生高杠杆） |
| 加分项 | 股息率≥2%？连续分红？ | fhps 分红记录 | 每年真金白银分红的公司更可信 |

**人工复核的铁律**：5问中任何1问不过 → 放弃，换下一只。宁缺毋滥，空仓等机会也是价值投资。

## 3. 建仓计划

```
第1周（选股）：系统初筛 + 人工复核 → 锁定2~3只备选
第2周（首批）：每只买1手（或2只各1-2手），合计投入 ~50%（≈5000元）
第4周（观察）：价格波动不看；重新核对基本面无变化
第5-8周（补仓）：分批补至满仓；若候选大幅下跌>15%且基本面未变 → 这是加仓机会而非恐慌理由
```

**不做什么**：
- ❌ 不一次全仓（留子弹应对下跌）
- ❌ 不追涨停/热点/新闻（买入理由必须是"便宜+好公司"，不是"要涨了"）
- ❌ 不融资不加杠杆（1万本金没有杠杆资格，也绝不该有）

## 4. 持有与卖出纪律

### 4.1 持有期动作（每季度末执行一次，30分钟）
1. 跑系统重新打分（同初筛命令）
2. 核对持仓股：质量门槛是否仍过？（ROE/CFO/LEV）
3. 核对估值：PE_PCTL/PB_PCTL 是否 >80% 且连续2月？
4. 无变化 → 继续持有，不动

### 4.2 卖出触发（任一即卖，T+1执行）
| 触发 | 动作 |
|---|---|
| 估值分位 >80% 连续2个月 | 卖出（高估兑现） |
| 质量破门槛（ROE<8%且5年中位<8%/CFO转负/LEV>70%） | 卖出（逻辑破坏） |
| 变 ST / 退市风险 | 立即卖出 |
| 公司逻辑变坏（人工判断：主营萎缩/造假嫌疑/行业被颠覆） | 卖出（**这条优先于一切规则**） |
| 持仓满8季度 | 全量重估，允许换股 |

**卖出的心理原则**：卖出的理由必须是"当初买入的理由消失了"，而不是"它跌了所以卖"。亏损不是卖出理由，估值和基本面才是。

## 5. 复盘制度（最重要的一环）

每季度在 `G:\股市探究\quant-investing\docs\trading\` 下建一个 `YYYY-Qn.md`：

```markdown
## 2026-Q3 复盘
### 持仓
| 代码 | 名称 | 买入日 | 成本 | 现价 | 盈亏% | 买入理由 | 理由仍成立? |
### 操作记录
- 买入X：原因（当时的分位/ROE/现金流）…金额…
- 卖出Y：原因（触发哪条纪律）…
### 教训
- 这次哪里做对了/做错了？
### 下季度计划
```

**复盘的目的**：积累你自己的决策记录 → 3年后你能回答"我的方法有效吗"。这比1万元的盈亏更有价值。

## 6. 风险声明（必读）

1. **系统因子未经统计检验**（P4未跑）：初筛结果只能当线索。人工复核5问是**必须**的
2. **幸存者偏差**：估值历史接口缺退市股数据，历史分位可能系统性偏乐观
3. **集中持仓风险**：2~3只组合，单只黑天鹅影响20~50%，分散有限
4. **A股制度风险**：退市常态化、ST规则变化、个股财务造假——所以要求"看得懂业务"
5. **不承诺收益**：1万元年化10%也就1000元；亏损50%也就5000元——把它当学习成本
6. **决策权在你**：任何 AI/系统输出都不构成投资建议，最终决策与后果由你承担
