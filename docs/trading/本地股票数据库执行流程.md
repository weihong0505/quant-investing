# 本地股票数据库 — 执行流程（简略版）

> 目标：建立定期自动更新的本地股票数据库（SQLite），替代散落 parquet 缓存

> 依赖脚本：`code/init_db.py`（建库）、`code/update_db.py`（更新）——均已就绪

---

## 一、架构

```
数据源(东财datacenter/新浪/腾讯qt) → update_db.py → G:/股市探究/quant-investing/data/quant.db
                                                        ↓
                                                    run_screen.py 等消费方
```

数据库表：`stock_master`（主表）/ `quarterly_fin`（财务）/ `valuation_daily`（估值历史）/ `dividends`（分红）/ `mcap_snapshot`（市值）/ `meta_updates`（更新日志）

## 二、执行步骤

### 步骤1：建库（一次）
```bash
cd G:\股市探究\quant-investing\code
D:\pyh\python.exe -X utf8 -E init_db.py
# 预期输出: 数据库就绪 + 各表0行
```

### 步骤2：首次灌入（全量）
```bash
# 全表更新（财务从缓存秒级灌入；估值/市值/分红会联网拉取）
D:\pyh\python.exe -X utf8 -E update_db.py
# 或只灌财务（最快验证）：
D:\pyh\python.exe -X utf8 -E update_db.py --tables fin
```

### 步骤3：注册 Windows 任务计划（每日自动更新）
```bat
:: 以管理员身份运行 cmd，或 schtasks 普通权限即可
schtasks /Create /TN "QuantDBUpdate" ^
  /TR "D:\pyh\python.exe -E G:\股市探究\quant-investing\code\update_db.py --tables spot,fin,mcap" ^
  /SC DAILY /ST 18:30 /F
```
- 每天 18:30 收盘后自动更新（行情+财务+市值）
- 验证：`schtasks /Query /TN "QuantDBUpdate"`
- 手动跑一次：`schtasks /Run /TN "QuantDBUpdate"`
- 删除：`schtasks /Delete /TN "QuantDBUpdate" /F`
- 可选：`--tables val`（估值历史全量2-3小时）建议周末手动跑，不进每日任务

### 步骤4：验证
```bash
D:\pyh\python.exe -X utf8 -E -c "import sqlite3; c=sqlite3.connect(r'G:/股市探究/quant-investing/data/quant.db'); print(c.execute('SELECT table_name, rows_after, status FROM meta_updates ORDER BY id DESC LIMIT 8').fetchall())"
```

## 四、注意事项

1. **日线受限**：东财 push2 被封，`daily_bars` 表暂不灌入（等解封或新浪分页方案）；估值/财务/市值不受影响
2. **财务更新**：yjbb/zcfz 缓存季度刷新后，重跑 `update_db.py --tables fin` 即可
3. **任务失败**：查 `meta_updates.status` 定位失败表；数据源限流时等冷却重跑
4. **备份**：`quant.db` 单文件，直接复制即备份
