## 研究资料结构化摄入规范

**新增研究资料的流程：**
1. 文献/报告 → 先登记到 `research/reading_list.md`（标题/作者/年份/核心结论/与项目关联）
2. 深度阅读后 → 提炼为"可执行结论"写入对应主题文件
3. 结论若涉及新因子 → 走 SOP §3.0 审批 + v3 检验
4. 结论若涉及策略参数 → 记录依据与日期，供日后审计

**文件命名**：`research/{主题}_{日期}.md`；主题固定、内容更新则升级日期。
