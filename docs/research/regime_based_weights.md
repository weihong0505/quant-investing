# Regime-Based 因子权重动态调整（设计文档）

> 状态：**设计稿（P2）**，尚未实施。按 SOP §3.0，实施前须经 MImo 审批。
> 日期：2026-08-21

---

## 1. 动机

主策略 v2 使用**固定权重**（价值 40% + 质量 25% + 动量 15% + 流动性 10% + 规模 5% + 情绪 5%）。
固定权重的问题：
- 2019-2021 成长碾压期，价值因子系统性弱势（风格现象），固定权重硬扛会长期跑输
- 2021 后价值回归，固定权重又充分受益
- 因子短期 IC 波动大（月度 IC 标准差 ~0.10~0.13），固定权重无法利用短期信号强度

## 2. 设计原则（红线）

1. **不得违反防过拟合纪律**：权重调整规则必须在样本外确定，一次确认制
2. **调整幅度有上限**：单因子权重偏离基准权重 ≤ ±50%（防权重漂移失控）
3. **低频调整**：季度调权（月度调权换手成本会吃掉收益）
4. **任何调整必须可解释**：规则简单透明，禁止黑箱 ML 调权
5. 实施前走 MImo 审批 + v3 检验

## 3. Regime 识别方案（候选，需 MImo 裁决）

| 方案 | 信号 | 优点 | 缺点 |
|------|------|------|------|
| A. 滚动 IC 调权 | 各因子过去 36m ICIR | 直接反映因子近期有效性；与 v3 滚动 36m 观察线一致 | ICIR 噪声大（36m 窗口功效有限） |
| B. 市场状态调权 | 市场动量（过去12m指数收益正负）+ 波动率分位 | 状态驱动，与经济直觉吻合（价值在牛熊/风格切换中轮动） | 状态与因子表现的映射需要验证 |
| C. 制度段固定权重组 | 按 A股制度段（2019前/注册制过渡/全面注册制）预设权重 | 最简单透明 | 段内不调整，错过段内轮动 |
| D. A+B 混合 | 状态粗分 + 滚动 IC 微调 | 兼顾 | 复杂，参数更多，过拟合风险 |

**倾向**：先做 A（滚动 IC 调权），因为：
- 与 v3 的滚动 36m ICIR 观察线**复用同一统计量**，无新增过拟合面
- 天然满足"因子 IC 月度跟踪"（P1 已建 ic_monitor.py）的数据流
- 权重调整 = 归一化的 max(ICIR, 0) 或 ICIR 加权

## 4. 拟议公式（供 MImo 审查）

```
季度调权:
  w_i^base = 基准权重（当前固定权重）
  icir_i = 因子 i 过去 36m ICIR
  raw_i = max(icir_i, 0.1)          # 地板防归零
  w_i = w_i^base × raw_i / mean(raw)   # 按 ICIR 相对强弱缩放
  约束: 0.5 × w_i^base ≤ w_i ≤ 1.5 × w_i^base  # 幅度上限
  归一化: w_i = w_i / Σw
```

## 5. 验证要求（实施时）

1. Walk-forward：每季度用"截至调权日过去 36m"的 ICIR 调权（严格 PIT，无未来函数）
2. 对比固定权重：净收益（扣成本）、换手增量、2x 成本敏感性
3. 调权增益必须 > 换手成本增量（季度调权换手通常 <5%/次，成本可控）
4. MImo 审批 + 参数敏感性（地板 0.1、幅度上限 50%、窗口 36m 各 ±20% 扰动）
