## 口径说明

- **复权口径**：选股层因子中，价格相关字段(EP/BP/MOM_60D)使用东财spot的"最新价"，该价格为**不复权**价格。引擎层回测有raw(不复权)和hfq(后复权)两套价格。
- **报告期口径**：财务因子采用**PIT(Point-In-Time)**原则，取最新公告日期 ≤ 今日的最新报告期。TTM由最近4个季度滚动计算。
- **P1 新增（2026-08-25）**：估值历史接口（RPT_VALUEANALYSIS_DET）总市值/股本/收盘价均为**不复权**口径、元/股单位；现金流接口（RPT_DMSK_FN_CASHFLOW）`NOTICE_DATE` 为修订日（非首告日），FCF_YIELD 的 PIT 对齐须用 fhps 业绩披露日历校准（定稿 §4）；yjbb「最新公告日期」已实测=首次披露日（非修订日），yjbb 系因子无需额外校准。
- **已确认修复(2026-08-22)**：
  1. EP从动态PE倒数改为EPS_TTM/最新价
  2. NaN EPS给中性分0，真实亏损(≤-0.1)给-3
  3. VOL_RATIO弃用，权重并入TURNOVER
  4. 相关性闸门阈值改为0.7，winsorize后z值计算，触发时砍IC弱者
  5. GPM 由 yjbb「销售毛利率」（实测=报告期累计口径，横截面不可比）改为毛利TTM/营收TTM（lrb 利润表，同源东财）
  6. MOM_60D 口径实测：qfq/hfq 区间收益恒等、raw 与复权差=分红；东财 f24 待解封复核（判别式见 mom60 实测报告）
