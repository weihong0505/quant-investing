# 因子检验统计方法细则 v3（定稿）

> 项目：A股多因子价值选股系统
> 作者：deepseek-v4-pro；审查：MImo V2.5 Pro 两轮（round1/round2 报告归档于本目录）
> 状态：**✅ 定稿（两轮审查通过）**，自 2026-08-21 起生效
> v2→v3 变更：落实终审 11 处必改 + 8 处 P2；单一显著性规则；PT MR 完整算法；样本划分条款

---

## 1. 目的与范围

定义本项目新因子"能不能进主策略"的**统计判定标准与完整检验流程**。
核心问题：一个因子在 A股是否具有**稳定的、扣成本后可交易的**横截面预测能力？
不含：因子经济逻辑审批（SOP §3.0）。
**数据受限声明**：样本 <60 月时全部结论自动降级为"初步"，不得据此入主策略。

## 2. 术语定义

| 术语 | 定义 |
|------|------|
| 因子暴露 | 股票在 T 月末**最后一个交易日**的因子值（PIT 对齐） |
| 前瞻收益 | T+1 自然月收益（主口径）；T+1~T+3 复合收益（辅助） |
| IC | 横截面 Spearman 秩相关：corr(factor_T, ret_T+1)，月度频率 |
| ICIR | IC 均值 / IC 标准差（**ddof=1**，保留两位小数） |
| 分层 | 按因子值横截面分 5 组（20% 分位），组内等权（主）/市值加权（稳健性） |
| 多空组合 | 第 5 组 − 第 1 组 |

## 3. 数据准备规范（PIT 纪律）

1. **对齐**：财务类因子用"公告日 ≤ T"的最新值（PIT）
2. **收益处理**：前瞻收益 1%/99% winsorize（±50% 截断二选一固定）；因子值 ±3σ winsorize（行业内中性化则行业内）
3. **池过滤**（每月重算）：
   - 剔除 ST/*ST、退市整理
   - 剔除上市 < **120 交易日**（敏感性检验 60/250）
   - 剔除 T 期停牌股
   - **T+1 可交易性规则**：T+1 月内停牌 ≥5 交易日或一字板 ≥5 交易日的股票当期剔除
   - ⚠️ 已知局限：akshare 仅含现存股票，**幸存者偏差无法完全消除**，结论须附此声明
4. **缺失**：因子缺失的股票当期剔除；**必须报告月度因子覆盖率**（<70% 告警）+ 缺失指示变量与下期收益的 IC（检验 MCAR）
5. **样本划分（v3 新增）**：
   - **主判定样本** = 2017-01 起全样本（T≈116 月；2010/2015 起点作背景对照）
   - **训练段** = 截至检验日 −24 个月（仅用于 §7-1 共线性保留裁决，决策记 registry）
   - **样本外确认段** = 最近 24 个月：仅作报告项（IC 表、净多空），不参与任何裁决
   - **一次确认制**：样本外确认失败 → 因子降级观察/淘汰，**禁止回训调参后重报**
   - 防过拟合靠：前置登记 + 多重检验线 + 一次确认制（8 年数据再切训练/测试会两败俱伤）
6. **中性化版本**：同时检验原始值、行业+市值中性化值两版；**检验前预指定交易版本**（默认原始版）

## 4. IC 检验（第一道关）

### 4.1 主口径
月度 Spearman(factor_T, ret_T+1)。报告：IC 均值、IC 标准差(ddof=1)、ICIR、IC 胜率（报告项）、naive t、NW-t（**两者对照，判定以 NW-t 为准**）。

### 4.2 NW 滞后阶数
`lag = floor[4 × (N/100)^(2/9)]`（NW 1994，与 statsmodels cov_hac 默认一致，N=60→3）。
T+1~T+3 重叠收益时 `lag = max(3, 公式值)`。

### 4.3 判定
| 档位 | 标准 | 处置 |
|------|------|------|
| 保留 | ICIR > 0.5 **且** \|mean IC\| ≥ 0.02 **且** §9 多重检验线通过 | 进入分层检验 |
| 观察 | 0.3 ≤ ICIR ≤ 0.5 且多空单调显著 | 标记观察，不启用 |
| 淘汰 | 其余 | 终止 |

- **内部基准**：新因子 ICIR 必须 ≥ 存量 10 因子同窗口同池子 ICIR 的中位数（报告对比表）
- **IC 胜率**：降级为**报告项 + 观察线**（实测其判别力弱：T=60~96 原假设通过率 ~16~18%，且上游 ICIR 闸已基本拦净原假设）
- **IC 序列极值对照**：报告 IC 序列 1%/99% winsorize 后的 ICIR（防单月极端 IC 压低 ICIR）

### 4.4 辅助口径
1. **IC 衰减曲线**：T+1/T+2/T+3/T+6/T+12 各期限 RankIC 与 ICIR
2. T+1~T+3 **复合收益**（(1+r1)(1+r2)(1+r3)−1，非均值）的 IC——只作持续性描述
3. **down-month 条件 IC**：市场下跌月份 IC 均值必须非负（硬指标）
4. **高波动月条件 IC**（v3 补全）：市场波动率前 1/3 月份的 IC 均值必须非负（硬指标，与 down-month 对称）
5. **风险调整 IC**：因子对市场+规模+行业回归后残差与收益的 IC
6. **波动率关系**（v3 补全）：因子与当月已实现波动率、市场 β 的横截面相关（防因子是波动率代理，尤其 TURNOVER/VOL_RATIO 类）

## 5. 分层检验（第二道关）

### 5.1 做法
每月按因子值分 5 组，组内等权（主口径），月度再平衡。

### 5.2 成本口径（v3 补全公式）
- **成本构成**：佣金万2.5双边 + 印花税卖出（**按 SOP §7 A.4 时变表：2023-08-28 前千1、之后万5**）+ 过户费万0.1双边 + 分档滑点 5/10/20/30bp（按市值档逐股）
- **净多空月收益** = (rQ5毛 − rQ1毛) − (toQ5 × cQ5 + toQ1 × cQ1)
  - to = 该月各组成分变化比例（市值加权口径用权重换手）；c = 该股所属市值档**往返成本**（买+卖两腿）
- **2x 成本** = 全部交易成本 ×2（与 SOP A.5 口径一致，非只滑点×2）
- 规模中性 15 格：**按 15 格分别计换手与成本**，不复用主口径换手
- 年化换手 >10x → 至少"观察"（衔接 SOP A.5）

### 5.3 三重稳健性（全部必做）
| 检验 | 做法 | 通过标准 |
|------|------|---------|
| 市值加权 | 组内市值加权重算全套 | 净多空仍为正且显著 |
| 微盘剔除 | 剔除总市值 <30 亿样本重算 | 净多空仍为正且显著 |
| 规模中性分层 | 3×5 double sort | 见下 |

**规模中性实现细节（v3）**：
1. **dependent sort**：先市值三分，再各 size 层内因子五分（15 格）
2. 每格等权月收益、月度重算
3. 报告每格平均股票数；大盘层五分后每格 <50 只时告警（该层结论降级）
4. **验证**：size-neutral spread 对 ln_mcap 回归 β，|β| 应接近 0（验证中性化有效）
5. spread = 等权平均 3 个 size 层内的多空（与"先平均同 quintile 再相减"数学等价）

### 5.4 单调性检验（PT MR，完整算法）
**主检验：Patton-Timmermann (2010) MR 检验**，伪代码：
```
输入: R = 预指定交易版本月度 5 组收益矩阵 (T×5)；方向 d=±1（预登记符号，+1=递增）
1. Δ_tj = d × (R[t,j+1] − R[t,j])，j=1..4；J0 = min_j mean_t(Δ_tj)
2. 对 b = 1..9999:
   a. stationary bootstrap 重抽月份索引（时间层整块重抽，平均块长 3）
   b. 重抽矩阵 R* → J*_b = min_j mean(Δ*_tj)
   c. null recentering: J̃*_b = J*_b − J0   ← 不做中心化 p≈0.5 永远检不出
3. p = (1 + #{b: J̃*_b ≥ J0}) / 10000
4. p < 0.05 → 拒绝"非单调"，判单调成立
```
- 重抽单元 = **时间层**（逐月整块），非股票层；R=9999（p 分辨率 1e-4）；随机种子固定归档
- **T<36 时功效不足**，结论降级
- **噪声场景禁用**：10 分组/行业分组等 σ_idio≥1%/月 场景功效实测 <0.33，不得作为硬门槛，改用倒挂计数 + FM β
- 辅助：逐月 5 组收益回归组序号的 FM β（均值 + 单侧 NW-t≥3.0，lag=1~2）
- 倒挂容忍：计数规则"相邻倒挂 ≤1 档 且 Q5>Q1"；报告"完全单调月份占比"（描述性）

### 5.5 分层必报清单
各组年化收益/年化波动/夏普/最大回撤/换手率、多空 NW-t、净多空年化（扣成本）、vs 基准（沪深300+中证500）超额、Q5 组平均市值与 ADV、分组迁移矩阵。

## 6. 因子自相关（决定再平衡频率）

1. 报告 **lag-1/3/6 自相关曲线**（横截面排名的月度 Spearman，对实际交易版本计算）
2. 三档阈值（>0.8 / 0.3~0.8 / <0.3）仅作描述性标签，不作硬门槛
3. **最终裁决用实证对比**：月度 vs 季度再平衡的**净收益（扣成本）**，哪个高用哪个
4. 自相关 <0.3：先提高频率重测净收益；净收益为负或低于基准则弃用（A股 T+1+高成本下提高频率不是免费选项）

## 7. 共线性与增量信息

1. 新因子 vs 存量 10 因子 Spearman 相关矩阵；|corr|>0.7 → 取 ICIR 较强者（**只用训练段=检验日−24m 前数据裁决**，决策记 registry）
2. **Fama-MacBeth 多元回归增量检验**（正式版）：
   - 模型：`r_{i,t+1} = a + b1·f_new + b2·ln_mcap + b3·EP + b4·BP + b5·MOM_60D + Σ_k γ_k·I(ind_k) + ε`
   - 行业 = 申万一级 31 哑变量（减一维）**或**行业内 demean（等价吸收固定效应），二选一固定；金融股按 SOP §3.2
   - 标准化：连续变量（含新因子）每月横截面 z-score（或 rank 化，二选一固定）；收益 1%/99% winsorize
   - FM 第二步：b1 月度序列 → 均值 + NW-t（lag=floor[4×(T/100)^(2/9)]，至少 2）
   - **显著线：预登记方向单侧 NW-t ≥ 2.0**（多重检验税已在 IC 关按 3.0 收取，FM 是第二道增量闸）
   - 报告：b1 均值/分位、NW-t、加入前后 EP/MOM 系数变化、月度 R² 均值、VIF
3. 正交化残差检验作为辅助展示
4. 多因子合成前报告 VIF（>5 告警）

## 8. 稳健性检验（第三道关）

统一矩阵（身份标注）：

| 检验 | 做法 | 身份 |
|------|------|------|
| 样本分段 | 2017-01~2021-12 / 2022-01~今 两段 ICIR | 硬门槛：两段同号且均>0.3 |
| 分组数 | 5 组 vs 10 组 | 报告项 |
| 池子 | 全市场 / 沪深300 / 中证500 | 硬门槛：至少两个池子**成立**（池内 ICIR≥0.3 且与主样本同号） |
| 压力测试 | 2015-06~08、2016-01、2018-10、2020-02、2024-01/02 逐月多空 | 报告项：单月多空<−10% 或连续两月亏损 → 至少"观察" |
| 熊市段 | 2015-06-12~2016-01-28、2018-01-24~2018-12-28、2022-01-04~04-26、2022-07-05~10-31、2024-01-02~02-05 | 报告项（不设硬门槛） |
| 滚动 ICIR | 滚动 36m ICIR 曲线（标注 2017 风格切换/2021-02 抱团瓦解/2024 微盘危机） | 报告项 + **观察线**：末端<0.3 / 连续≥12月为负 / 断点后 12 月未回正 → 任一即降级观察 |
| 中性化 | 原始 vs 行业市值中性 | 预指定版本为准，差异记录 |
| 参数敏感性 | winsorize ±2σ/±3σ、次新股 60/120/250 日、收益截断 ±50%/1%99% | 报告项，各跑一个变体 |
| 季节性（v3 补） | 月度 IC 分解表：1 月效应、4/8/10 月财报季 | 报告项 |
| 行业明细 | 行业内 IC 分布表（识别单行业驱动） | 报告项 |

## 9. 多重检验控制（v3 单一规则）

**单一显著性线（全程序统一，删除双方案）**：

```
预登记方向的 signed NW-t ≥ max(3.0, Bonferroni(N', 单侧 α=0.05))
```

- **N' = 本自然季度同期受检新因子数**，季度重置；不含存量、不含历史失败者
- Bonferroni 单侧 α=0.05 在 N'=37 处恰达 3.0，与主线**无缝衔接无断崖**；N'≥38 自动收紧
- 为什么是 signed 而非 |t|：|t|≥3.0 会放行**符号与预登记相反**的强因子（t=−3.5 被 |·| 误通过）；必须判"预登记方向上的 t"
- **防改口三件套**：
  1. 检验后符号与登记不符 → 该次检验作废；反转方向以**新因子号重新登记**并计入 N'
  2. 检验后调参 → 重新走 registry ⓪步，原记录保留，计入 N'
  3. 未前置登记的因子检验结果无效
- BH 仅用于"同期一批候选因子"的批量报告（辅助说明）

## 10. 经济显著性闸门

**口径（v3 补全）**：施加于**预指定交易版本**（默认原始版等权）的净多空；月收益年化 ×√12；无风险利率=0。

| 闸门 | 通过线 | 观察线 |
|------|--------|--------|
| 净多空年化 | ≥ 8% | 4~8% |
| 2x 成本敏感性 | 净多空仍为正 | — |
| 净多空夏普 | ≥ 0.8 | 0.5~0.8 |

- 注：夏普 ≥0.8 与年化 ≥8% 同时可达 ⇔ 年化波动 ≤10%（波动更高时夏普线成为实际约束）
- **三重稳健性版本（市值加权/微盘剔除/规模中性）不套上述绝对线**——规模中性 spread 剔除微盘溢价后量级系统性偏低，套同一线会误杀真因子；其判定线 = "净多空为正且显著"
- 任一硬闸不满足 → 观察或淘汰，不论统计量多漂亮

## 12. 检验流程

```
⓪ registry 前置登记（时间戳+预期符号+样本期+数据版本hash+脚本路径，字段锁定）
  → ① 数据准备(PIT+池过滤+winsorize+覆盖率报告)
  → ② IC 检验（幅度下限+内部基准+§9显著线）
  → ③ 分层+单调性（PT MR）+三重稳健性+成本后净多空
  → ④ 自相关曲线+再平衡频率实证
  → ⑤ 共线性（训练段裁决）+FM多元增量检验
  → ⑥ 稳健性矩阵+滚动ICIR+压力测试+季节性
  → ⑦ 多重检验（signed NW-t 线）
  → ⑧ 经济显著性闸门
  → ⑨ 回填 registry（追加式，不改原行）+输出报告
  → ⑩ MImo 审批 → 入主策略
```

## 13. 输出报告模板

`factor_docs/test_{因子名}_{日期}.md` 必含：
1. 因子定义与经济逻辑（一句话）+ registry 编号
2. 数据来源、样本期、覆盖率曲线
3. IC 表：均值/标准差/ICIR/胜率/naive t/NW-t + IC 时序图 + 衰减曲线 + down-month/高波动月 IC + 极值 winsorize 对照
4. 分层表：5 组年化/夏普/回撤/换手 + 净多空（扣成本）+ 三重稳健性 + PT MR 结果 + 迁移矩阵
5. 自相关 lag-1/3/6 曲线 + 再平衡频率实证结论
6. 共线性矩阵 + FM 多元增量检验结果 + VIF
7. 稳健性矩阵 + 滚动 36m ICIR 图 + 极端月份明细表 + 季节性分解
8. 多重检验：signed NW-t、同期 N'、通过线
9. 经济闸门：净多空年化、2x 成本敏感性、夏普
10. 最终判定：保留/观察/淘汰 + 理由
11. 可复现材料：检验脚本路径、数据版本 hash、随机种子
