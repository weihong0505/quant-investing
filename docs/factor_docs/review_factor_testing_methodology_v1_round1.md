## 一、11 个待审查问题逐条裁决

### Q1. IC 阈值体系（ICIR>0.5 / 0.3~0.5 / <0.3）—— 结论：修改

**理由：**
- 档位方向正确，量级与 A 股月频文献一致：好因子的月度 RankIC 通常 0.03~0.08，IC 序列标准差 0.10~0.13，对应 ICIR 0.3~0.7，与 Grinold 基本定律量级吻合。两档（保留/观察）设计合理。
- 但**绝对值阈值缺内部基准**：0.5 是否合理取决于本策略自己的因子池。新因子应至少达到存量 10 因子在**同一窗口、同一池子**下的 ICIR 中位数，否则绝对阈值形同虚设。
- **统计显著 ≠ 经济显著，文档缺经济幅度闸门**（这是全文档最大缺口之一）：已实测验证 ICIR>0.5 时 naive t = ICIR×√T ≥ 2 对任意 T>16 恒成立（T=60 时 t=3.87；即便 IC 自相关 ρ=0.4 使 NW 修正因子 √(1+2ρ)≈1.34，T=60 时 NW-t 仍有 2.89）。因此"ICIR>0.5 且 NW-t>2"两个条件**高度冗余**，形同只测了 ICIR。一个 IC 均值 0.01、标准差 0.02 的因子（T=120 时 t=5.5）能过这道关，但扣成本后无任何经济意义。
- 关于"是否随样本期调整"：t 值天然含 √T 调整，§3-5"<5 年只出初步结论"已覆盖小样本问题，ICIR 线无需再随 T 变化。

**修改建议：**
1. 增加经济幅度下限：|mean(IC)| ≥ 0.02（月度 RankIC，A 股月频口径），不满足则直接淘汰，不论 t 多大。
2. 增加相对基准：新因子 ICIR 必须 ≥ 存量因子同窗口 ICIR 的中位数（报告对比表）。
3. 明确 ICIR 口径：IC 标准差用 ddof=1；ICIR 保留两位小数。
4. 阈值总表（§10）同步加入幅度下限。

### Q2. NW 滞后阶数公式 —— 结论：通过（附 3 条落地说明）

**理由：** 公式 `lag = 4×(N/100)^(2/9)` 即 Newey-West (1994) 自动带宽（Bartlett 核、无预白化），已实测确认与 statsmodels `cov_hac` 的默认 `nlags = floor[4(T/100)^(2/9)]` 完全一致（源码核对 + 数值验证：N=60→3，N=120→4）。公式本身正确。

**落地说明（建议补入正文）：**
1. 明确**取 floor**，与 statsmodels 默认一致，避免实现歧义。
2. 若采用 T+1~T+3 重叠收益（Q8 的辅助口径），相邻观测重叠 2 个月会人为制造 ~3 阶自相关，必须 `lag = max(3, NW公式值)`；T+1 单月主口径用公式值即可。
3. A 股月频 IC 自相关通常弱（ρ≈0.1~0.3），NW 对 t 的压缩有限（ρ=0.3 时 t 约除 1.26）——不要指望 NW 救活边缘因子；报告应同时给出 naive t 与 NW-t 对照。
4. §5 单调性 FM β 的 t 检验用 lag=1~2 即可，不必用 4×(N/100)^(2/9)。

### Q3. 单调性量化检验 —— 结论：修改（含 1 处统计错误、1 处数值陷阱、1 处 ad hoc 规则）

**理由与错误定位：**
- **统计错误**："对 5 组**年化**收益序列回归 `ret_q = α + β×组序号`"——年化收益只有一个横截面、n=5 个观测、df=3，t 检验没有时间维度，无意义。文中"月度层面 t 检验"的正确形态是：**逐月**对 5 组收益回归组序号，得到 β 月度时间序列，再对 β 序列做 NW-t（Fama-MacBeth 风格）。
- **Spearman ≥ 0.9 的数值陷阱**（已实测复现）：n=5 时 Spearman 取值被锁在网格 {±1.0, ±0.9, ±0.8, ...} 上，r≥0.9 数学上等价于"完全单调或恰好一对**相邻**组倒挂"。且 scipy 的浮点实现下，恰一对相邻倒挂实际返回 0.8999999999 < 0.9，会被阈值**误杀**。该规则要么加容差（≥0.899），要么直接改成计数规则"倒挂档数 ≤1 且 Q5>Q1"。
- **"Q3 必须处于中间"是 ad hoc 规则**，无文献依据，与"允许 1 档倒挂"互相矛盾（Q2 倒挂时 Q3 位置由数据决定），应删除。
- **更好的替代检验**：Patton-Timmermann (JFE 2010) 单调关系检验（MR test）——对"Q1<Q2<...<Q5 全序单调"命题直接做 bootstrap p 值检验，是文献标准做法，比 β 回归（只测线性趋势）和 JT 检验更贴合"分组单调"的本意。Jonckheere-Terpstra 可作为备选（检验有序备择，同样只测趋势），两者取其一主用即可。

**修改建议：**
1. 主检验改为 Patton-Timmermann MR 检验（bootstrap，p<0.05），逐月分组收益为输入。
2. 辅助报告：逐月 β 的 Fama-MacBeth 均值 + NW-t（lag=1~2），β>0 且 t>2。
3. 删除"Q3 必须处于中间"；倒挂容忍改为计数规则"相邻倒挂 ≤1 档 且 Q5>Q1"。
4. 同时报告"完全单调月份占比"（描述性指标，PT 检验已将其纳入推断）。

### Q4. 等权 vs 市值加权 —— 结论：修改

**理由：** 等权分组是因子学术检验的标准做法（检验因子自身溢价，不受大市值稀释），作为**主口径正确**。但 A 股等权 5 分组的 Q5 端天然堆满微盘股，多空收益在等权下系统性虚高——这是 A 股因子研究最常见的假阳性来源。仅报告等权会把"微盘溢价"误当成"因子溢价"。

**修改建议（全部为必做，非可选）：**
1. 等权为主口径，**市值加权为强制稳健性检验**：市值加权下净多空收益仍为正且显著，才算通过（与 §8 稳健性表合并）。
2. 增加**微盘剔除敏感性**：剔除总市值 < 30 亿（或市值后 20%）的样本后重算全套。
3. 增加**规模中性分层**：先按市值三分，再在各分位内做因子 5 分组（size-neutral spread）。
4. 修正 §5 的成本口径矛盾："扣成本（SOP §7 附录 A **中盘档**）"不可行——Q5 组多为小盘微盘，应按市值分档滑点（5/10/20/30bp）**逐股**计成本，否则净多空被系统性高估。
5. 分层报告须附基准（沪深300+中证500，按 SOP）超额收益。

### Q5. 自相关阈值 0.8 / 0.3 的划分依据 —— 结论：修改

**理由：** 无严格文献依据，属经验规则，方向大致可辩护（价值/质量类月度秩自相关常 >0.85；动量 0.5~0.8；反转类 <0.3），但存在两处逻辑缺陷：
1. **用 1 阶自相关决定季度再平衡不充分**：0.85 的月度自相关，3 个月后衰减到约 0.85³≈0.61，信号已明显退化。季度再平衡应直接看 **lag-3 自相关**，而非用 lag-1 外推。
2. **"<0.3 → 提高再平衡频率"在 A 股大概率不可行**：月度自相关 <0.3 的因子需要周频甚至日频换手，叠加 T+1、佣金万2.5、印花税万5，成本会吞掉超额。"提高频率"不是免费选项。

**修改建议：**
1. 报告 lag-1/3/6 的自相关曲线（三档阈值只作描述性标签，不作硬门槛）。
2. 再平衡频率的最终裁决改用实证对比：月度 vs 季度再平衡的**净收益（扣成本）**对比，哪个高用哪个。
3. "<0.3"档处置改为："先提高频率重测净收益；若净收益为负或低于基准则弃用"。
4. 自相关须对实际交易版本（原始或中性化，见补充发现 D）计算。

### Q6. 多重检验三档落地 —— 结论：修改（发现两处硬伤：档位严格性不单调 + FDR 程序误用）

**理由（全部经数值实测）：**
- **硬伤 1：三档严格性不单调。** 实测各档单因子有效阈值：
  - Bonferroni N=10 → 双侧 z≈2.81；N=20 → 3.02；N=100 → 3.48；
  - BHY（BY 2001）N=100 首位 → α/(N·H₁₀₀)=9.6e-5（H₁₀₀=5.187）→ 双侧 z≈**3.90**；
  - HLZ 固定 t=3.0 ⇔ 双侧 α≈0.27%。
  即第二档（BHY, N=100）比第三档（HLZ, t=3.0）**更严**；且当前 registry 已 N=11，从 Bonferroni（N≤10, z=2.81）切到 BHY（N=11 首位 z≈3.17）在 10/11 边界存在断崖。"规模越大越严"的直觉排序不成立。
- **硬伤 2：BH/BHY 是"批量 p 值同时排序"的程序**，单因子逐个审批时无法单独使用（需要知道该 p 值在同批候选中的名次）。逐个检验场景只能使用固定阈值（Bonferroni/HLZ），或把同期候选攒批后跑 BH。
- **family 定义缺失**：细则说"用登记总数 N 重新计算阈值"，但 registry 终身累积会让 N 无限增长（N=1000 时 Bonferroni z≈4.0），任何因子都永远过不了关。且 registry 现状（已实测）把**已上线的存量 10 因子也计入 N**——存量因子不是本次检验的假设，计入 N 无统计依据。

**修改建议（落地为固定阈值方案，删繁就简）：**
1. 废除三档自动切换，改为：**预期符号在检验前登记 → 用单侧检验；程序级固定显著性线 |t| ≥ 3.0**（即 HLZ 线，与"新因子"这一角色的先验风险匹配），作为全程序统一门槛，不随 N 变化。
2. 或者保守版：|t| ≥ max(2.8, 由"**本检验周期内同期受检新因子数 N'**"算出的 Bonferroni 线)；N' 不含存量因子、不含历史失败者，每个研究周期（如每季度）重置，历史记录只作审计。
3. BH 仅用于"同期一批候选因子"的批量报告（辅助说明，不作单一门槛）。
4. registry 的速算表同步重写（当前表直接复制了三档缺陷）。

### Q7. 牛熊 2/3 标准与结构变化 —— 结论：修改

**理由：**
- "至少 2/3 熊市段多空为正"没有文献基准，且 2015（杠杆踩踏）、2018（贸易战/去杠杆）、2022（美联储加息+抱团瓦解）三段成因与市场结构迥异，把异质事件绑成一个 2/3 硬门槛过于粗糙。
- **"熊市段"未定义精确起止日期**，不可复现（2015 是 6 月中旬起还是 8 月起？2016-01 熔断算不算？2022 是一段还是两段？）。
- 结构性断点（2017 风格切换、2021-02 抱团瓦解、2024 年初微盘流动性危机）在正文完全没有任何检验手段承接，这是背景与方法的脱节。

**修改建议：**
1. 保留三段压力测试，但**降级为报告项 + 观察线**（不设 2/3 硬门槛）；熊市段精确写死：2015-06-12~2016-01-28、2018-01-24~2018-12-28、2022-01-04~2022-04-26 与 2022-07-05~2022-10-31；另加 2024-01-02~2024-02-05（微盘流动性危机）。
2. 增加硬指标：**市场下跌月份的条件 IC**（down-month IC 均值必须非负）。
3. 增加结构断点检验：**滚动 36 月 ICIR 曲线**（必须附图，标注各风格切换时点）+ 分段 IC 表（2010-2014 / 2015-2016 / 2017-2020 / 2021-今）；可选 Chow 断点检验。
4. 把"牛熊/分段/池子"三行合并为统一的稳健性矩阵，明确各自"硬门槛 vs 报告项"身份。

### Q8. 前瞻收益 T+1 vs T+1~T+3 —— 结论：修改（明确主辅、修正口径）

**理由：**
- T+1 单月应与主策略月频再平衡的实际持有期一致、无重叠、NW 干净，**必须为主口径**。
- "T+1~T+3 平均月收益"作辅助口径时存在口径瑕疵：三均值 ≠ 三月持有收益。实测示例：月收益 [5%, −3%, 4%] 的均值是 2.0%，复合收益是 5.9%，相差近 3 倍。若测"3 个月持有期"应取 (1+r₁)(1+r₂)(1+r₃)−1。
- 比"平均"信息量大得多的是 IC 衰减曲线。

**修改建议：**
1. 主口径：T+1 单月。
2. 辅助口径 1：IC 衰减曲线——T+1/T+2/T+3/T+6/T+12 各期限的 RankIC 与 ICIR（观察衰减速度，决定持有期）。
3. 辅助口径 2（可选）：T+1~T+3 复合收益，NW lag = max(3, 公式值)（重叠修正，见 Q2）。
4. 最终以 T+1 为判定依据，多期口径只作"信号持续性"描述。

### Q11. 遗漏的检验环节 —— 结论：修改（补充 12 项，P0/P1/P2 分级）

**P0（必须补，缺了结论不可信）：**
1. **成本后 IC / 净多空经济闸门**：IC 门槛（§4）与分层（§5）都在毛口径上判定。必须增加：扣完整成本后的净多空年化收益下限（建议 ≥8%），且 2x 成本敏感性下仍为正（与 SOP §7 A.5 衔接）。这是"统计显著 → 可交易"的唯一桥梁。
2. **因子与波动率/β 的关系**：报告因子与当月已实现波动率、市场 β 的相关；高/低波动月份的条件 IC；对市场+规模+行业回归后的**风险调整 IC**（防因子只是波动率代理，尤其对 TURNOVER/VOL_RATIO 类）。
3. **Fama-MacBeth 多元回归增量检验**：新因子加入存量因子（至少市值/EP/动量）的横截面回归，报告增量系数 NW-t——§7 正交化残差检验的正式统计版，判定"增量信息"应以它为准。
4. **极端月份明细表**：2015-06~08、2016-01、2018-10、2020-02、2024-01/02 逐月多空收益；单月多空 < −10% 或连续两月亏损 → 至少"观察"。

**P1（应补）：**
5. **覆盖率与缺失机制**：月度因子覆盖率（<70% 告警）；缺失指示变量与下期收益的 IC（检验 MCAR）。§3-3"缺失剔除"若不报告覆盖率，会隐藏选择偏差。
6. **因子自身换手与容量**：5 分组月度成分换手率、分组迁移矩阵、Q5 组平均市值与 ADV——与成本模型联动。
7. **参数稳健性**：winsorize ±2σ vs ±3σ、3/5/10 分组数、申万一级 vs 二级行业中性化的敏感性——研究者自由度本身就是 snooping 源，至少各跑一个变体。
8. **次新股剔除口径**：60 自然日偏短；A 股 IPO 炒作+业绩变脸窗口约 1 年，建议主口径剔除上市 <120 交易日，敏感性 60/250。
9. **T+1 月内停牌**：除 T 期停牌外，T+1 月内停牌 ≥5 交易日的股票前瞻收益不可得，应剔除（与现有"一字板 ≥5"可选规则合并为一条"T+1 可交易性"规则）。
10. **季节性与披露日历**：1 月效应（2018 前小盘）、4/8/10 月财报季的 IC 分解。
11. **行业明细**：申万一级行业内 IC 分布表，识别单行业驱动。

**P2（流程与一致性）：**

## 三、总体结论

**判定：修改后进入第二轮。** 文档框架完整、流程顺序合理（PIT 纪律、双版本检验、共线性闸门、registry、多重检验意识均正确且高于 SOP 基线），无整节否决；但存在 2 个统计硬伤、1 个全流程级缺口，须在第二轮前修正。

**P0 修改（第二轮前必改）：**
1. Q3：单调性回归口径错误（年化单横截面回归无意义）→ 改 Patton-Timmermann MR 检验 + 逐月 FM β；删除"Q3 居中"规则；修正 Spearman≥0.9 的浮点陷阱。
2. Q6：三档多重检验严格性不单调 + BH/BHY 单因子误用 + family（N）定义缺陷 → 改固定阈值方案（|t|≥3.0 或 max(2.8, Bonferroni(N'))），registry 速算表同步重写。
3. 经济显著性闸门缺失 → 增加 |mean IC|≥0.02 与净多空年化 ≥8%（2x 成本仍为正）。
4. Q4：等权分组在 A 股微盘污染下必须强制市值加权/微盘剔除/规模中性三重稳健性；§5 成本改逐股分档。
5. Q11-P0：补齐 FM 多元增量检验、波动率关系、极端月份明细表。

**P1 修改（第二轮一并复核）：** Q1 相对基准、Q5 自相关曲线化、Q7 门槛软化+滚动 36m ICIR、Q8 主辅口径、Q9 registry 字段、Q10 子样本灵敏度、补充发现 C/D/E。

**通过项：** Q2（NW 公式正确，与 statsmodels 默认一致）、Q10（2010 起点合理）、§9 的 64% 计算、§3 池过滤与 PIT 纪律、§7 共线性 |corr|>0.7 与 VIF>5。

**验证脚本归档：** `factor_docs/_methodology_review_verify_v1.py`（NW 带宽、ICIR-t 关系、Bonferroni/BH/BY/HLZ 阈值、Spearman n=5 取值网格、胜率检验功效、3 月复合 vs 均值——全部实测）。
