## 2. 第二轮 10 问逐条裁决

### 问题 1：双口径铁律的边界是否完整？（股息率因子该用哪口径？）——**修改**

**裁决**：总则（收益/比率类→hfq；市值/股价水平/绝对价格类→raw）方向正确，但有三处边界缺失：

1. **股息率因子未覆盖，且是实弹**：股息率 = 每股股息 / 股价。分子「每股股息」是公告**名义金额**（不复权），分母若用 hfq 价（=raw×F，600036 实测 F=5.47 东财/6.74 新浪）→ 股息率被系统性低估 F 倍（2~7 倍量级），高分红价值股被反向错排。规范未点名，执行必踩。
2. **估值类 EP/BP/PE/PB 未显式点名**（本项目核心因子，EP/BP 为存量因子）：「以绝对价格构造的信号」理论上覆盖，但存在「复权 EPS 配 raw 价」的混用坑。最稳健写法是**总市值口径**：EP = 净利润_TTM / raw 总市值，BP = 净资产 / raw 总市值——天然规避每股复权歧义（复权 EPS×hfq 价 ≡ 原始 EPS×raw 价 ≡ 总盈利/总市值，但绝不可交叉混用）。
3. **绝对价格/金额阈值类规则缺总则**：低价股剔除（如 <1 元退市风险线）、单笔 2 万线、5 元最低佣金的判定阈值——一律 raw 空间（v2 已对「2 万元」标注 raw 口径 ✅，应推广为总则）。

**修改建议（M5）**：§2.1 配套规则 1 增补：① 股息率 = 每股股息（公告名义额）/ raw 价；② 估值类 EP/BP/PE/PB 用 raw 总市值口径（净利润_TTM/净资产 ÷ raw 总市值）；③ 总则句：一切绝对价格、绝对金额、股数阈值的规则判定均在 raw 空间。

### 问题 2：退市整理期强制卖出+5日顺延+清算规则是否可执行？——**修改（按实测定档，两分支预案保留）**

**实测**：名单 367 家再确认 ✅；新浪退市股行情不可得再确认 ✅（V7 维持）；**东财腿本轮仍不可实测（全端点被封，见 §0）**——与第一轮 V7「待回填」状态相同。因此裁决只能按两分支预案给出，v2 §3.5 #4 的两分支写法本身正确。

**但规则要可执行还缺四块拼图（本轮修改点）**：

1. **整理期起始日的确定**：退市名单只有「终止上市日期」（深市；沪市连此字段都没有，见下），没有「进入整理期日期」。整理期长度本身时变：2020 年底前 30 个交易日、2021 起 15 个交易日；**科创板不设退市整理期（直接终止上市）**。需定近似规则：整理期起始 = 终止上市日前 15 个交易日（2021+）/ 30 个交易日（2020 前），按终止年份切换，声明近似误差（±若干交易日，对「跌停顺延 5 日+清算」规则的触发时点影响有限）。
2. **沪市名单字段不对称**（本轮新发现）：`stock_info_sh_delist` 只有「暂停上市日期」无「终止上市日期」→ 引擎「按终止日动态剔除」需兼容两字段（沪市补拉终止上市日或按暂停上市日近似），规范应写明。
3. **「东财恢复后必跑回填清单」应写入规范**：退市股行情（V7）、东财 qfq 差异日定位（V1 补充）、ETF hfq 基准差（V8）——恢复后一次性回填定档，不影响本规范其他条款。
4. **与 v3 的一层关系需一句注记**：v3 §3 池过滤写「剔除退市整理」（选股层不买入），v2 §2.3 是「持仓进入整理期强制卖出」（持仓层处置）——两者不冲突但易被误读为双文档矛盾，加一句衔接说明。

### 问题 3：策略判定标准 7 条是否完备/过严？（卡玛 0.5 依据？三段均>0？）——**修改**

**裁决**：7 条骨架（经济+一致性、无显著性硬线）方向正确、可执行性良好，但有一处标定错误与一处可落地缺口：

1. **卡玛 ≥ 0.5 标定错误（P1 硬修正，本轮最重要的单项发现）**：实测主段双基准卡玛 0.006~0.010（2021-02+ 段 0.004 与 −0.003）。卡玛 0.5 的隐含要求：若回撤与基准相当（−45.6%），需年化 ≥22.8%；即使回撤压到 −30%（已显著优于基准），仍需年化 ≥15%。而主段基准年化仅 ~0.3%（价格）/~2.3%（ETF 全收益），策略总年化（基准+超额）量级 5~12% → **任何「回撤不劣于基准」的策略几乎必然卡玛 <0.5**。判定 3 的「最大回撤不劣于同段双基准」与「卡玛 ≥ 0.5」两半句**自相矛盾**：满足前者必挂后者。0.5 无任何依据（第一轮建议值，未经标定）。**修改（M1）：删除「卡玛 ≥ 0.5」硬线，卡玛降为报告项；观察线 = 卡玛 < 双基准卡玛；风险硬线仅保留「最大回撤不劣于同段双基准」。**
2. **判定 7 当前无法落地**：实测 `factor_registry.md` 存量 10 因子统计量列**全部为空**（状态「存量」，无 v3 116 月全流程记录）。「入池因子全部通过 v3 检验」对存量因子无对应证据 → 该条悬空。**修改（M4）：加过渡条款——存量 10 因子于本规范定稿后按 v3 补检（IC→PT MR→FM→经济闸全流程）并回填 registry；补检完成前，判定 7 以「存量审批记录（v1/v2 轮）+ 补检时间表」为替代口径并在报告声明。**
3. **三段均>0 的「合理解释」未操作化**：2019-01~2020-08 段是成长/白马风格期，价值策略该段为负是大概率事件，全靠「或负段有合理解释」兜底，但什么是「合理」未定义。**修改（并入 M8）：锚定 v3 观察线——负段期间因子层滚动 36m ICIR 未触发观察线（末端<0.3 / 连续12月负 / 断点后12月未回正）→ 判「风格现象，解释成立」；否则须归因到具体事件（如 2019 成长碾压），仍无法归因 → 观察不否决。**
4. **完备性补充（P2，并入 M9 注记）**：建议加「1x 成本拖累 ≤ 毛超额 50%」观察线——当前 7 条下，毛超额 15%、成本拖累 12% 的组合可通过全部判定，防「纸上财富」。

### 问题 5：仅「禁用 qfq」是否够？hfq 本身要不要异常校验？——**修改**

**裁决**：不够。「禁用 qfq」挡住的是隐含未来除权的泄漏，挡不住 **hfq 自身数据错误**（第一轮东财离群尚未定位，若离群在 hfq 侧，「禁用 qfq」完全无效）。需补三层：

1. **hfq 自洽校验（可完全离线，不依赖东财恢复）**：利用 qfq+hfq 重建隐含 raw（raw_t = qfq_t × hfq_now / hfq_t），然后校验：① F_t = hfq/raw **单调不减**（现金分红只增复权因子，出现下降即数据错）；② F_t 变动日集合 = 除权除息日集合（与 `stock_fhps_detail_em` 对账，多/少变动日均告警）；③ hfq 日收益 |r| > 板块板幅×(1+容差) 的离群日告警（除权日豁免但必须与派息额对账，第一轮 V2 对账模板复用）。§2.1 配套规则 4「重叠期价格比=常数」是同一思想的弱化版，升级为上述三件。
2. **双源抽查补默认参数**：现「随机抽 N 股」未定 N 与频率——定 N=20 股 × 全区间日收益对账、每次全量拉取后跑、差异>0.1% 告警（阈值已有）。
3. **主源/备用源策略缺失**：东财接口全但**两轮审查实测均被封**（本轮连裸端点首请求即断），新浪稳定但无退市股、无部分字段。规范必须写明主源/降级预案（并入 M13）。
4. 第一轮遗留「东财 qfq 差异日定位」本轮仍不可实测（东财被封）——列入「恢复后必跑回填清单」（M10），不改判（hfq 方向已有新浪侧双重实证）。

### 问题 6：停牌判定用「行情行缺失」推断是否正确？与退市/未上市/数据缺失如何区分？——**修改**

**裁决**：推断方向正确（V11 已证 tfp 按日查询不可靠），但**缺存活区间边界**这一必要条件：

1. **未上市日、退市后日会被误判为停牌**：交易日历 vs 行情行缺失的朴素实现，对 [上市日之前] 与 [终止上市日之后] 的日历日全部判「停牌」→ 池过滤/因子处理全错。必须先用上市日与终止上市日框定**存活区间**，区间外的日历日不算停牌（也不计缺失）。
2. **停牌 vs 数据缺失的区分规则**：停牌是**连续段**（A 股停牌 ≥1 日，实践中多为 ≥2 日连续）；单日偶发缺行大概率是接口漏拉。规则：存活区间内缺行连续 ≥2 交易日 → 判停牌（价格前收填充、可交易性=否）；=1 日 → 先重拉一次，仍缺 → 前收填充 + 记缺失率（§2.2 缺日补齐路径）。
3. **校验工具**：`stock_tfp_em` **按股查询**停复牌区间作抽查校验（不作主判定），与推断结果不一致时告警。

### 问题 7：净值时点选择（月末收盘计净值、隔夜跳空计入首月）是否最优？——**修改**

**裁决**：月末收盘计净值作为**常规口径正确**（行业惯例、与 v3 月度收益月末对齐、后续调仓月的过夜跳空旧仓真实持有）；但 v2 对首月跳空的定性错了：

1. **「隔夜跳空计入首月收益（真实执行的隐性成本）」表述不准确**：首次建仓 T 收盘 → T+1 开盘之间策略**不持仓**（全现金），该段跳空是策略未经历的市场波动——它不是成本也不是收益，是**估值基准伪收益**（方向不定、期望≈0、σ≈0.5~1.5%/日）。真正的「隐性成本」是 T+1 开盘成交相对 T 收盘信号的滑移，那部分已由「T+1 开盘价成交」规则本身体现。
2. **该问题只影响首月**（后续调仓月旧仓真实持有过夜），90 月回测中量级 ≤单月级，不改变任何判定——但表述必须修正。
3. **推荐修法（零成本）**：**首期净值从首次 T+1 开盘起算**（现金+按开盘价计的组合成本=初始资金−首期交易成本），之后维持月末收盘计价。或保守保留现值但改述为「首月跳空为估值基准伪收益，方向不定、量级单月，如实声明」。
4. 附带：回测 T+1 执行与 v3 月度收益（月末对月末）存在 1 天错位 → §3.1 #2/判定 4 的交叉验证容差应写明（±1pp 月均），避免把错位误读为引擎 bug（并入 M3）。

### 问题 8：参考段（2017-2018）「辅助证据」的具体使用规则？——**修改**

**裁决**：「辅助证据、不作主判定」的定位正确（与 4.1 原则、第一轮结论一致），但「显著为负则必须解释」不可操作：

1. **「显著」必须换成阈值**：24 月样本任何显著性检验都无功效（比 T=66 还差，t 检验无意义）。**触发线 = 参考段净超额年化 ≤ −3%（或参考段超额最大回撤 < −5%）**——与 Q9 的 3% 标签对称。
2. **「必须解释」的产物与标准**：报告固定小节《参考段连续性说明》，必含：参考段净超额与超额回撤、同期因子层滚动 36m ICIR（衔接 v3 观察线）、同期基准表现与风格/制度事件对照（2017 白马行情、2018 贸易战熊市）、归因结论（风格现象/制度差异/数据差异/无法归因）。
3. **解释不成立的处置**：策略降「观察」**不否决**（参考段非主判定段，否决违背 §4.1；且该段外推价值本身存疑）。写明「解释义务 ≠ 否决线」。
4. 判定 6（三段制度段）的「负段合理解释」与此共用同一判据（锚定 v3 观察线），两处规则合并表述（并入 M8）。

### 问题 9：判定标准 1「净超额>0」是否应加最小幅度（如年化 3%）？——**修改（不加硬线，加两级标签）**

**裁决**：**不加 3% 硬线**——实测功效证明硬线无检验力且必误杀：

| 证据（T=90，TE=10%） | 值 |
|---|---|
| 检 3%/年硬线的检验功效 | **20.3%** |
| P(真 3% 策略测量值 <3%) | **50%** |
| P(真 2% 策略测量值 >3%) | 17.1% |

即：真 3% 的策略有一半概率被 3% 线误杀；真 2% 的策略有 17% 概率误过线。硬线「过滤噪声」的能力接近于零（噪声级超额 0~2% 区间测量误差 ±1.05%/年，无法区分）。加线只会把「噪声通过」换成「真策略误杀」，纯负收益。

**但「>0 无幅度」的噪声担忧本身成立，解法是联合门+标签，不是单线**：
1. 现有 7 条已是联合门：主段>0 ∩ 核心段>0 ∩ 2x成本>0 ∩ 三段>0 ∩ 回撤——对真 0-alpha 策略，各门独立误放概率 ~50%，联合误放被压到低个位数~十几%（段间有重叠，粗估），噪声级超额（+0.5%/年不稳健）大概率在 2x 成本或某制度段翻负被拦。
2. **加两级标签（M9）**：净超额年化 ≥3% =「达标」；0~3% =「边际通过」——必须附报告超额 80% 置信区间 + 声明「本窗口无法区分噪声级超额」，并建议以 v3 因子层证据链（判定 7）作为主要依据。标签不改变判定结果，只改变结论措辞与披露义务。

## 4. 总体结论

**裁决：需修改后定稿。第二轮 10 问：通过 0 / 修改 10 / 否决 0。第一轮整改 18 项全部有落实（15 完整、3 走样/遗留已并入修改清单）。本轮新增 P0×0、P1×5（M1~M5）、P2×9（M6~M14）。**

核心判断：
1. **v2 骨架无需推翻**：hfq 统一裁决、自研引擎四条件、双口径铁律、样本分层（2019+/2021-02+）、成本全衔接、判定标准 7 条框架、防泄漏 14 类——全部维持，第一轮 4 项 P0 的修复均正确落地。
2. **本轮唯一判定级硬伤是卡玛 0.5 线**（M1）：实测基准卡玛 ≈0.006~0.010，0.5 线会让一切「回撤不劣于基准」的策略必然出局，与判定 3 前半句自相矛盾——必须删。
3. **两处落实走样均为加固级**（M2 白名单前5日、M3 判定4限定恢复），一行修复，不影响已修复方向。
4. **东财跨两轮不可用是规范层面的新事实**（M13）：主源降级预案从「可有可无」升级为「必须写」。
5. **东财恢复后回填清单（M10）不影响定稿**：Q2 的两分支预案已把两种结局的处置都写死，恢复后只是把 §3.5 #4 从「两分支」定档为「可执行补测」分支。
6. **建议**：M1~M5 为定稿前置条件（P1），M6~M14 可与 P1 同批修订（成本低），修订出 v2.1 后**直接定稿，无需第三轮**；定稿即按 SOP §3.3 同步修订并生效。
