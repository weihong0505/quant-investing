## 1. 目标

在主策略现有因子（EP、BP、MOM_60D、TURNOVER、LOG_MCAP、VOL_RATIO）基础上，
加入**质量因子组**，将策略从"纯便宜"升级为"好公司 + 好价格"的量化版巴菲特框架。

## 2. 因子定义与数据源

数据源：akshare 的东方财富接口
- `stock_yjbb_em(date)` — 业绩报表（按报告期，全市场）
- `stock_zcfz_em(date)` — 资产负债表（按报告期，全市场）

| 因子 | 定义 | 原始字段 | 方向 |
|------|------|---------|------|
| ROE_TTM | TTM净利润 / 最新归母净资产 | 净利润(累计)、所有者权益合计 | 越高越好 |
| GPM | 销售毛利率 | 销售毛利率 | 越高越好 |
| NPM_TTM | TTM净利润 / TTM营业总收入 | 净利润、营业总收入 | 越高越好 |
| CFO_NI | 每股经营现金流量 / 每股收益 | 每股经营现金流量、每股收益 | 越高越好 |
| LEV | 资产负债率（取倒数方向=低负债） | 资产负债率 | 越低越好 |

## 3. 经济逻辑与学术依据

1. **ROE（盈利稳健性）**
   - Fama-French 五因子模型 (2015) 的 RMW 因子：盈利稳健公司长期超额收益
   - Piotroski (2000) F-Score：ROA/ROE 是财务健康九指标之首
   - 巴菲特/芒格框架："长期收益≈ROE，买入能持续维持高 ROE 的公司"

2. **GPM（毛利质量）**
   - **Novy-Marx (2013)**："毛盈利/资产"是比账面市值比更强的横截面收益预测变量，
     被称为"质量异象"的代表作
   - 高毛利 = 护城河/竞争地位的量化代理（波特五力）

3. **NPM_TTM（盈利效率）**
   - 与毛利率互补：毛利高但净利率低说明费用失控，两者结合识别"真质量"

4. **CFO_NI（盈利现金含量）**
   - **Sloan (1996)** 应计异象：盈利中现金成分越高，未来收益越可持续
   - 防造假：A股财务粉饰通常体现为利润与现金流背离

5. **LEV（财务稳健性）**
   - 格雷厄姆《聪明的投资者》防御型七标准：低负债是核心
   - Piotroski F-Score 的 LEVER 项：低杠杆公司未来收益更好

## 4. 数据处理流程

### 4.1 报告期获取
拉取最近 5 个报告期（保证 TTM 计算需要去年同期可比数据）。

### 4.2 TTM 计算（关键细节）
A股业绩报表的净利润/营收字段是**年初至今累计值**，不能直接相加。正确公式：

```
TTM(净利润) = 去年年报净利润
            + 今年最新报告期累计净利润
            - 去年同报告期累计净利润
```

例：2026年8月，最新报告期=2026Q2(累计)，
TTM = 2025年报 + 2026中报 - 2025中报

### 4.3 ROE_TTM 的净资产口径
- 分子：TTM 归母净利润
- 分母：最新报告期"归母所有者权益合计"
- 注：未做期初期末平均（简化处理，属已知偏差）

### 4.4 清洗与标准化
- winsorize ±3σ 去极值
- 金融行业（银行/保险/证券）特殊处理：LEV 因子对金融业不适用
  （高杠杆是商业模式而非风险信号），金融股 LEV 赋中性分
- 缺失值：因子缺失的股票该因子赋中性分，不整体剔除
- 打分：横截面 z-score 排名（与现有 6 因子一致）

## 6. 已知风险与偏差（自查）

1. **幸存者偏差**：stock_yjbb_em 仅含当前在市股票。对当前截面选股影响小，
   对历史回测有影响，回测阶段需另行处理
2. **报告期滞后**：财务数据公告有滞后（Q1 最晚 4/30 披露）。当前做**截面选股**
   无未来函数问题；未来做回测必须按公告日对齐
3. **TTM 分母未取平均**：ROE_TTM 分母用期末净资产而非期初期末均值，
   对增发/回购较多的公司有偏差
4. **因子共线性**：ROE 与 BP 存在一定相关性（PB-ROE 框架下），
   集成前需检查相关系数，|corr|>0.7 需调整权重或去冗余
5. **行业系统性差异**：银行业天然高杠杆、券商 ROE 周期性强，
   除金融 LEV 中性化外，是否需要对全部质量因子做行业中性化？——待审查意见

## 7. 检验计划（集成后执行）

按项目 SOP 的因子检验三件套：
1. 月度 Rank IC + ICIR（|ICIR|>0.5 才保留）
2. 5 分组多空收益单调性
3. 因子自相关（决定再平衡频率）
4. 补充：与 EP/BP 的相关系数矩阵（共线性检查）
