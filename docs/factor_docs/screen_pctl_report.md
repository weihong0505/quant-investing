## 1. 接口说明

### 1.1 calc_percentile(vh_df, asof=None) — 单股分位
- 输入: `get_valuation_history` 返回的 DataFrame (date/pe_ttm/pb_mrq 等列, 列名大小写容错)
- 窗口: **实际历史滚动窗口** — 2018-01-02 (数据源起点) 起全部累积, 截至 asof (默认最新交易日)
- 产出门槛: 窗口交易日 ≥250 **且** 有效观测 (剔除负值后) ≥250, 否则分位=NaN + `missing` 缺失标记
- 负值处理: PE<0 / PB<0 (含 0/NaN) 从分位序列剔除; 当前值无效 (<=0/NaN) → 该分位缺失
- 分位口径: `100 * mean(hist < cur)` — 严格小于占比的 ECDF 下侧 (参考序列含当日观测; 最小值→0, 最大值→<100)
- 返回 dict: `pe_pctl, pb_pctl, n_obs, n_obs_pb, n_trading, window_days, asof, missing`

### 1.2 percentile_for_candidates(codes, asof=None, max_workers=3) — 候选池批量
- 逐股 `get_valuation_history` (缓存命中秒回) → `calc_percentile`
- 并发 `max_workers=3` (requests 安全), 每请求后 sleep 0.2s + data_fetcher 内置 0.5s 全局节流
- 返回 DataFrame[code, pe_pctl, pb_pctl, n_obs, window_days, n_obs_pb, n_trading, asof, missing]
- 失败/无数据个股: **行保留, 分位=NaN, missing 注明原因** (不静默丢弃)

### 1.3 filter_by_percentile(df, max_pctl=50) — 分位过滤
- 保留条件: **PE_PCTL < 50 且 PB_PCTL < 50 (两者都<50, 严格 AND)**
- 取舍说明: 宽松版"任一<50"会放过"PE便宜但PB贵"的个股 (如周期股盈利高点呈低PE+高PB),
  安全边际打折; 严格 AND 版对两个估值维度同时要求处于自身历史下半区, 更符合价值投资"便宜"定义。
  7 只演示候选恰好验证了该取舍: 600595/002215/002532 PE 分位极低 (<9) 但 PB 分位 >50, 被严格版剔除。
- 分位 NaN 个股: **保留但标注 `pctl_status='missing'` + `pctl_note` 原因**, 不静默剔除 — 留人工复核
- 返回: 过滤后 DataFrame (通过 + 缺失保留, pass 在前), 新增 pctl_status / pctl_note 列

## 6. 遗留问题 / 注意事项

1. **PB 分位普遍偏高**: 7 只中 6 只 PB_PCTL>50。A 股 2018 年后整体净资产扩张而股价未同步, 或
   与数据源 PB 口径 (MRQ) 有关 — 需在真实回测/检验阶段确认 PB 分位因子区分度 (v2.1 P4 检验)
2. **幸存者偏差 (已知声明)**: 退市股在估值历史接口完全缺失 (实测 300104/600401 均空),
   分位计算不包含退市股历史, 回测期需统计退市股占池比例并声明 (v2.1 §3.3)
3. **分位口径**: 采用严格小于占比 ECDF (含当日观测)。与 (rank-1)/(n-1) 排序口径差异 <0.01pp,
   但若后续与外部工具对账需注意口径一致性
4. **负值剔除比例应报告**: 亏损期越多的个股有效观测越少 (002582 仅 52% 有效), 分位序列代表性下降;
   建议下游在输出中带上 n_obs 列 (已提供), 并报告剔除比例 (v2.1 §7 要求)
5. **月末快照未在此模块实现**: 本模块输出 asof 日快照; 回测/月末调仓的快照逻辑由调用方
   按 asof 参数逐月调用 (v2.1 §2.3 频率口径)
6. **缓存刷新**: valhist 缓存为全量历史, 新交易日数据需调用方定期重建缓存 (或增量更新,
   data_fetcher 当前为全量覆盖策略)
