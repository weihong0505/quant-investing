## 1. 验证方法

- 样本：5 只季节性强公司（白酒/旅游/农业）：600519 贵州茅台、000858 五粮液、601888 中国中免、300498 温氏股份、002714 牧原股份
- yjbb 字段：`data_cache/yjbb_{8期}.parquet` 的「销售毛利率」（与 `multi_factor_value.py` L247 同源同字段）
- 手算源：东财利润表 stock_lrb_em（同源同口径，最严对账）
- 三口径定义：
  - **当期累计** = (累计营业总收入 − 累计营业成本) / 累计营业总收入（年初至报告期末）
  - **单季** = (本期累计毛利 − 上期累计毛利) / (本期累计营收 − 上期累计营收)
  - **TTM** = 毛利TTM / 营收TTM，TTM = 最新期累计 + 上年年报 − 上年同期累计
- 判定容差 ±0.15pp（字段两位小数）

## 3. 结论

- **yjbb「销售毛利率」为报告期累计口径**（Q1=1季度、Q2=上半年、Q3=前三季、Q4=全年）。5 只样本 × 8 报告期共 40 个观测全部命中累计口径（容差 ±0.2pp），无一命中纯单季或纯 TTM。
- 判别力最强的证据（季节性反转公司）：牧原股份 20260630 字段 = −1.58%（=H1 累计手算 −1.58%），而 Q2 单季 = −8.41%、TTM = +7.13%；温氏股份 20260331 字段 = 2.71%（=Q1 累计），TTM 手算 = 8.45%。
- 茅台 4 个报告期偏差 0.15~0.17pp（如 20240930 字段 91.53% vs lrb 手算 91.69%）——东财两表对「营业成本」行项目的定义细节差（毛利公式差异），**不改变口径判定**；五粮液/中免/温氏/牧原均 ≤0.05pp 精确吻合。
- 影响（实证）：`multi_factor_value.py` L247 用**最新报告期**的累计毛利率——披露进度不同的公司横向不可比。实弹：温氏 2026Q1 累计毛利率 2.71%，2025H1 累计 13.76%；若同一横截面上 A 公司已披露半年报（用 H1 累计）、B 公司只披露一季报（用 Q1 累计），GPM 相差可达 10pp 以上，且与披露进度系统性相关（非随机噪声）。
- 修改建议（C9 子项③ 预定方案落地）：GPM 改为 **毛利TTM / 营收TTM**，数据源用东财利润表 `stock_lrb_em`（与 yjbb 同源、同报告期、含公告日期可做 PIT，本实测已确认 8 期全量可拉）。实现：按 yjbb 同款 ttm_value 模式对「营业总收入」「营业总支出-营业支出」逐股 TTM，`GPM = (营收TTM − 成本TTM)/营收TTM`。lrb 缺失期 → GPM=NaN → 中性 0 分（现有 fillna 兜底），**禁止回退用累计字段**。
