## 一、v2 §14 十个问题逐条裁决

### Q1. 经济闸门数值与多空口径 —— 结论：修改（小改）

**理由（全部实测）：**
- **净多空年化 ≥8% 合理**。成本拖累实测：月换手 50%~100%、往返成本 20~40bp 时，年化成本拖累仅 1.2%~4.8%（=12×月换手×往返成本）；A股毛多空年化 15~25% 的因子净得 12~24%，8% 恰好落在"真因子 vs 边缘因子"分界线上，且与 SOP §7 A.5 的 2x 成本规则衔接正确。高换手（200%/月）因子的净收益被成本吃掉一半以上，2x 成本为正成为实际约束——设计意图正确。
- **夏普 ≥0.8 与 8% 的联动需写明**。实测：两者同时可达当且仅当年化波动 ≤10%；波动 14% 时 0.8 夏普要求收益 11.2%（此时夏普线成为实际约束、8% 闸门被架空）。必须在 §10 写明口径：净多空月收益年化（×√12）、无风险利率=0，并补观察线（建议 0.5~0.8）。
- **多空口径**：8%/2x/夏普三个闸门施加于**预指定交易版本（默认原始版等权）**的净多空。三重稳健性版本（市值加权/微盘剔除/规模中性）**不套** 8%/0.8 绝对线——规模中性 spread 剔除微盘溢价后量级系统性低于原始 spread，套同一绝对线会把真因子误杀，维持 v2 现文"净多空为正且显著"即可，但需在 §10 写明这一区别。

**修改建议：** ① §10 补口径句（预指定交易版本、月收益年化 √12、rf=0）；② 夏普补观察线 0.5~0.8；③ 注明三重稳健性版本的判定线与其不同。

### Q2. 单侧 t≥3.0 固定线 vs max(2.8, Bonferroni(N')) 备选 —— 结论：修改

**理由（实测见脚本 A 节）：**
- **"两方案如何选择"答不上 = 规则缺陷**。两案并列必然诱发择机套利（哪个能过用哪个），这与多重检验控制的初衷相反。
- **"保守备选"名不副实**：单侧 Bonferroni（族 α=0.05）在 N'=19 时 z=2.79、N'=37 时才达到 z=3.000、N'=38 起才收紧（3.008）。即 max(2.8, Bonf(N')) 在 **N'≤37 时 = 2.8 < 主线 3.0**，且 2.8 底线对应单侧 p=0.26%，比 HLZ 3.0 的 0.135% 还松。"保守备选"在绝大多数场景下是**更松**的那条线。
- **单侧检验的陷阱（v2 有一个真漏洞）**：v2 §9 写 "|t| ≥ 3.0" 是**双侧化表述**——预登记符号为 +、t=−3.5 的因子按 |t|≥3.0 会误通过，但它是反方向的！必须改为 signed 判定："**预登记方向上的 t ≥ 3.0**"，反方向大 |t| 不计。
- **方向错了会怎样**：单侧检验永不拒绝 → 该因子按淘汰处理。这不是"更严厉的惩罚"，而是预登记纪律的应有之义；反转方向必须**以新因子号重新登记**并计入 N'，禁止原地改符号。
- **t 口径未定**：naive t 与 NW-t 并列报告，3.0 线套在哪个上未写 → 以 **NW-t 为准**、naive t 对照展示。

**修改建议：** 定案为单一规则——**预登记方向的 signed NW-t ≥ max(3.0, Bonferroni(N', 单侧 α=0.05))**，N'=本自然季度同期受检新因子数、季度重置。该规则在 N'≤37 时恒等于 3.0（α=0.05 使 Bonf 线在 N'=37 处与 3.0 无缝衔接，无断崖），N'≥38 自动收紧，同时消灭"两案择机"与"备选更松"两个问题。删除 2.8 底线。§9 补：符号与预登记不符 → 淘汰，反转按新因子重新登记计入 N'。registry 的"主方案/备选"表同步改写为单一公式。

### Q3. PT MR 检验实现细节 —— 结论：修改（补算法，v2 现文不可直接实现）

**回答：**
- **重抽单元 = 时间层（逐月整块重抽），不是股票层**。股票层重抽有两个硬伤：破坏时间序列相关结构；每期组合成分都在变，股票层无从定义联合分布。正确做法是**对月份做 stationary bootstrap**（Politis-Romano，平均块长 3），每次把该月 5 组收益**整行**带走。
- **R = 9999**（p 值分辨率 1e-4），随机种子固定（§13-11 归档）。
- **统计量与中心化**：J = min_j(Δ̂_j)，Δ̂_j = 相邻组收益差的时间均值。bootstrap 分布须做 null recentering：Δ̃* = Δ* − Δ̂（最小不利原假设 Δ=0 处中心化）。**不做中心化的 bootstrap 在备择假设下 p≈0.5，永远检不出单调性**——这是实现时最容易写错的一步。

**实测（脚本 F 节，T=84，Rboot=999，块长 3，200 次模拟）：** 原假设拒绝率 0.010（保守、size 受控 ✓）。功效依赖组内残差波动：σ_idio=0.3%/月（全市场等权 5 组的典型水平）时 weak/strong 功效 0.97/1.00；σ_idio=0.5% 时 0.71/1.00；σ_idio≥1%/月（10 分组、行业分组、小池子）时 weak 功效降至 0.33 以下。**结论：MR 检验作为全市场 5 分组主检验的硬门槛可用，但噪声大的场景（10 分组/行业分组）不得作为硬门槛**，改用倒挂计数 + FM β 为主判据，细则须写明。

**建议写入 §5.4 的伪代码：**
```
输入: R = 预指定交易版本月度 5 组收益矩阵 (T×5)；方向 d=±1（预登记符号，+1=递增）
1. Δ_tj = d × (R[t,j+1] − R[t,j])，j=1..4；J0 = min_j mean_t(Δ_tj)
2. 对 b = 1..9999:
   a. stationary bootstrap 重抽月份索引（平均块长 3）
   b. 重抽矩阵 R* → J*_b = min_j mean(Δ*_tj)
   c. 中心化: J̃*_b = J*_b − J0
3. p = (1 + #{b: J̃*_b ≥ J0}) / 10000
4. p < 0.05 → 拒绝"非单调"，判单调成立
```
另补：T<36 时功效不足须声明；毛收益主检 + 净收益版对照；Jonckheere-Terpstra 可作备选（v1 审查已注明，v2 保留其一即可）。

### Q4. 规模中性分层（3×5）spread 构造 —— 结论：通过（补细节）

**回答：是——"等权平均 3 个 size 层内的多空"正确**，且与"对每个因子 quintile 先等权平均 3 个 size 格、再取 Q5−Q1"**数学等价**（线性操作可交换）。

### Q5. FM 多元回归变量清单与形态 —— 结论：修改（补规格）

**建议写入 §7-2 的具体规格：**
- **模型**：`r_{i,t+1} = a + b1·f_new + b2·ln_mcap + b3·EP + b4·BP + b5·MOM_60D + Σ_k γ_k·I(ind_k) + ε`
- 行业 = 申万一级 31 个哑变量（减一维）**或**行业内 demean（等价吸收固定效应），二选一固定；金融股按 SOP §3.2 处理。
- 标准化：连续变量（含新因子）每月横截面 z-score（或 rank 化，二选一固定）；收益 1%/99% winsorize。
- FM 第二步：b1 月度序列 → 均值 + NW-t（lag=floor[4×(T/100)^(2/9)]，至少 2；月度系数序列自相关弱，不必用 T+1~T+3 的 max(3,·) 规则）。
- **显著线必须写明**（v2 §11 只写"增量系数显著"）：建议预登记方向单侧 NW-t ≥ 2.0——理由：多重检验税已在 IC 关按 3.0 收取，FM 增量是第二道增量闸，2.0 为文献惯例；若委员会要求更保守可与主闸同线 3.0，二选一写死即可。
- 报告：b1 均值/分位、NW-t、加入新因子前后 EP/MOM 系数变化、月度 R² 均值、VIF。

### Q6. 训练段/测试段与检验样本期自洽性 —— 结论：修改

**理由：** v2 §7-1 写"只用训练段数据裁决"，但**全文从未定义"训练段"是哪个区间**——不可执行。主判定样本（§3-5）是 2017-01~今全样本，且全文没有任何"测试段"角色。对"会不会用尽数据"的答案是反面的：不是用尽，而是**测试段根本不存在**，样本外确认这一环是空的。

**修改建议（新增"样本划分"条款，并入 §3）：**
1. 主判定样本 = 2017-01 起全样本（T≈116 月，用于 IC/分层/经济闸门的统计功效）；
2. "训练段"统一定义 = **截至检验日 −24 个月**（仅用于 §7-1 共线性保留裁决，决策记 registry）；
3. 最近 24 个月 = **样本外确认段**：仅作报告项（IC 表、净多空），不参与任何裁决；
4. **一次确认制**：样本外确认失败 → 因子降级观察/淘汰，禁止回训调参后重报。
5. 防过拟合靠 前置登记 + 多重检验线 + 一次确认制，而非切分样本（8 年数据再切训练/测试会两败俱伤）。

### Q8. 经济闸门与三重稳健性的成本口径漏洞 —— 结论：修改

**理由（实测见脚本 D 节 + SOP §7 附录A）：**
1. **换手成本公式缺失**：v2 §5.2 只写了"按市值分档逐股计滑点"，没说换手怎么进净收益。必须写明：净多空月收益 = (rQ5毛 − rQ1毛) − (toQ5×cQ5 + toQ1×cQ1)，其中 to = 该月各组成分变化比例（市值加权口径用权重换手），c = 该股所属市值档**往返成本**（买+卖两腿）。
2. **"扣成本"构成未定义**：只提滑点，未说含不含佣金/印花税/过户费 → 必须写全：佣金万2.5双边 + 印花税卖出（**按 A.4 时变表：2023-08-28 前千1、之后万5**）+ 过户费万0.1双边 + 分档滑点 5/10/20/30bp。
3. **2x 定义**：= 全部交易成本 ×2（与 SOP A.5 口径一致），不是只滑点 ×2。
4. **规模中性 15 格成本**：小格换手更高，必须按 15 格分别计换手与成本，不能复用主口径的换手。
5. **与实盘执行规则的落差**：分组检验用 T+1 全月收益，隐式假设月初可成交；SOP A.3 的 T+1 开盘价/涨停不买/跌停不卖在回测阶段校验——细则声明此落差即可（§3-3 的 T+1 可交易性剔除已缓解）。
6. 补一条与 SOP A.5 的衔接：分组年化换手 >10x → 至少"观察"。
