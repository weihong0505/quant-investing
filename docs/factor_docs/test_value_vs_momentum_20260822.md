## 4. 裁决结论（对照 M5 三情形）

1. **MOM：单变量反向显著，但 FM 增量不显著（初步）**：univariate signed IC NW-t=−3.66（41 月）超过 3.0 显著线；控制 ln_mcap+行业后 FM 系数仍为负（b=−0.59%/z·月）但 NW-t=−1.08（42 月）< 2.0。→ 反向动量效应**主要经由规模/行业渠道**传导，独立于规模/行业的截面预测力在试点中不显著。按 M5 规则属"只有一方显著"的动量侧：registry + 方向无证据，按 + 使用动量既无增量又方向相反。
2. **EP/BP：试点窗口 FM 增量未达线（初步，数据未就绪不裁决淘汰）**：16 月全模型 EP t=+1.94 / BP t=+0.61 / MOM t=−0.80；univariate BP IC 方向与 registry + 一致（22 月，NW-t=+2.51），EP 弱正（+0.36）。价值因子的单变量正信号同样部分被规模/行业吸收。
3. 按 M5 三情形（初步样本）：全模型无因子达 2.0 线 → 近"都不显著→降权回炉"；但 MOM 另有独立反向 IC 证据，应优先处置：**建议 MOM_60D 权重归零（方案 A）或反转重检（方案 B）**；EP/BP 维持权重但标记"观察"，待全 A 2017+ 数据（≥60 月）正式复核。
