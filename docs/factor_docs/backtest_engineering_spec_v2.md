## 1. 目的与范围

定义回测的**数据口径、引擎规则、样本期、策略判定标准**，保证回测结果真实、可复现、与当前市场结构可比。

## 2. 数据质量与复权规范

### 2.1 复权方式：全系统统一后复权（hfq）

**裁决：全系统统一 hfq。** 论证（经一轮审查修正）：

| 维度 | 前复权 qfq | 后复权 hfq |
|------|-----------|-----------|
| 收益率计算 | ✅ 正确 | ✅ 正确 |
| **历史稳定性** | ❌ qfq[t] = raw[t]×F_t/F_now，每发生新除权事件**全部历史同比例改写**（实测：派1元改写2.3%，年化漂移4~5%） | ✅ hfq[t] = raw[t]×F_t 只依赖 t 及以前事件，历史恒定 |
| 收益/比率类信号（MOM_60D、换手率、量比） | ✅ 等价（实测 60日收益横截面 Spearman=1.0000） | ✅ 等价 |
| **价格水平类信号（市值、股价水平）** | ❌ 实测水平 Spearman=0.3714，严重不等价 | 同左 |

**配套规则（v2 修正强化）**：
1. **双口径铁律**：
   - **收益/比率类信号** → hfq（含分红再投，实测对账：3 个除息日差 <0.03pp 吻合）
   - **市值、股价水平、以绝对价格构造的任何信号（LOG_MCAP、滑点分档市值、成交额）** → **不复权价**
2. 行情一律 `adjust="hfq"` 拉取缓存；不复权价 `adjust=""` 同缓存；**禁止混用复权口径、禁止跨源混用**（实测东财累积因子5.47 vs 新浪6.74，水平值不可比）
3. 涨跌停判定、成交价、股数、现金账 → raw 空间（见 §3.3）
4. 新旧数据合并时校验复权因子连续性（重叠期价格比 = 常数）

### 2.2 数据完整性校验（每次拉取后必跑）

| 校验 | 规则 | 违规处置 |
|------|------|---------|
| OHLC 合理性 | Low ≤ Open/Close ≤ High；价格 > 0 | 剔除当日 |
| 停牌日统一口径 | 价格前收填充、成交量=0、可交易性=否 | 标记 |
| 价格跳变 | **raw 价**上，阈值 = 板块涨跌停幅度×(1+0.5%容差)，板块×时间矩阵判定 | 人工核查（除权日/数据错） |
| 重复行 | 同代码同日期去重 | 保留最后 |
| 日期连续性 | 与交易日历比对，缺日补齐 | 报告缺失率 |
| 横截面完整性 | 每月股票数 vs 全市场数 | 报告覆盖率 |
| **双源抽查** | 新浪源随机抽 N 股对账日收益（东财 qfq 实测有离群数据问题，qfq 禁用后以 hfq 双源对账） | 差异 >0.1% 告警 |

**涨跌停幅度矩阵（v2 新增，随日历维护）**：
| 板块 | 幅度 | 起止 |
|------|------|------|
| 主板 | ±10%（ST ±5%） | 全期 |
| 创业板 | ±20% | 2020-08-24 起（此前 ±10%） |
| 科创板 | ±20% | 2019-07-22 起 |
| 北交所 | ±30% | 2021-11-15 起 |
| 免检白名单 | 新股首日（科创/创业/北交）、主板 2023-02-17 后新股前 5 日、退市整理期首日 | — |

**涨跌停价计算**：前收 × (1±幅度)，四舍五入到分。

### 2.3 特殊事件处理

| 事件 | 处理 |
|------|------|
| 停牌 | 前收填充+不可交易；复牌首日正常交易 |
| 次新股 | 未满 120 交易日剔除（**引用 v3 §3，不重述规则**） |
| 退市 | **进入退市整理期 = 强制卖出信号**（跌停顺延 5 日，仍卖不掉按整理期最后可成交日收盘清算，声明该路径低估真实损失）；名单用 `stock_info_sh_delist`(159)+`stock_info_sz_delist`(208)=367 家 |
| ST | 用生效日（非公告日）维护状态表；ST 期间不买入 |
| 送转/配股 | **持仓股数按比例调整**（raw 空间整数股，10送10股数翻倍）；配股缴款计入现金账（或声明未参与及收益口径调整） |
| 北交所 | **明确排除出池**（±30%、数据接口不同），不默认混入 |

### 2.4 交易日历
- `tool_trade_date_hist_sina` 生成，本地缓存
- 停牌判定：用"交易日历 vs 行情行缺失"推断（实测 `stock_tfp_em` date 参数可疑，不依赖）
- 月末再平衡日 = 当月最后一个交易日

### 2.5 数据快照与可复现
- parquet 缓存 + **快照清单**（文件名、行数、首末日、hash）
- 回测前校验 hash；**财务数据按首次公告快照固化**（防财务重述泄漏，防未来函数 #8）
- 快照清单随报告归档；报告附**代码版本 hash + 随机种子**（v2 补充）

### 2.6 已知偏差声明（写入每份回测报告）

| 偏差 | 方向 | 量级/说明 |
|------|------|----------|
| **打新收益缺失** | 低估 | 2019-2021 约 1~3%/年（网上口径），2022 起 <0.5%/年；**不得用打新上调判定线**（账户属性收益非策略 alpha） |
| 幸存者偏差 | 高估 | 见 §3.5 #4（退市股补测按数据可得性定档） |
| 停牌股价格填充 | 中性偏保守 | 前收填充略低估停牌风险 |
| 红利税/到账滞后 | 略高估 | hfq 含税后分红，未计 10% 红利税（持有<1年）与到账滞后 |
| ETF 基准代理 | 略高估 | ETF 费用 ~0.6%/年使基准仍被低估 ~0.6%/年 |
| 配股/可转债强赎 | 未计 | 声明口径 |

## 3. 回测引擎规范

### 3.1 引擎选型：自研轻量引擎（附验证条件）
月度调仓、30~100 只股，backtrader 黑盒反而妨碍审计。自研 **500~800 行**（不含 200 行——含涨跌停价+顺延+整手+时变税费+分档滑点+送转+退市清算现实规模）。

**四项强制条件**：
1. **金样本对账单测**：手算 2~3 只股 × 4~6 期（含一字板不买、跌停不卖、停牌顺延、整手取整、5 元最低佣金、2023-08-28 印花税切换、送转日股数调整、退市清算），引擎输出逐分对账
2. **与 v3 分层检验引擎共享收益/成本内核并交叉验证**：Top30 等权净收益应落在 v3 分层 Q4~Q5 之间接近 Q5，大幅偏离即引擎 bug
3. 单元测试覆盖全规则
4. **双口径**（§3.3）

### 3.2 净值与收益计算
1. 组合收益 = Σ 权重×个股收益（月度）；净值 = ∏(1+r_t)
2. 几何年化；月收益波动年化 ×√12；rf=0（与 v3 §10 一致，勿改）
3. **净值核算时点**：信号 T 月末收盘 → T+1 开盘建仓；净值按**月末收盘**计，T+1 开盘与 T 收盘间隔夜跳空计入首月收益（真实执行的隐性成本），明确写入报告
4. 现金 = 未投部分，计 0 收益；**现金与持仓在 raw 空间统一核算**（双口径）

### 3.3 执行模型（双口径铁律）
- **信号/收益层**：hfq（总收益口径）
- **执行/估值/成本层**：**不复权价**——成交价、股数、整手、现金、佣金/印花税金额、涨跌停判定、停牌判定全部 raw 空间
- 换算因子 = hfq_t/raw_t（单股常数）
- T 日收盘目标权重 → T+1 **raw 开盘价**成交；一字板（开盘价==涨停价）不买、跌停不卖
- 停牌顺延 5 日，期间每日重判；**放弃后资金 = 现金持有至下一调仓日**，不重配（防级联换手）；复牌首日跳空 >20% 直接放弃（可选加强）
- 买入整手（100 股）；单笔 <2 万元跳过（raw 金额口径）
- 调仓日恰逢除息日：raw 开盘价天然除息后，hfq 收益自动含分红再投，组合正确
- 送转日股数调整、配股缴款（§2.3）

### 3.4 成本与换手（与 SOP §7 附录A 全衔接）
- 逐股按市值档计往返成本：佣金万2.5双边 + 印花税（时变：2023-08-28 前千1/后万5）+ 过户万0.1双边 + 滑点 5/10/20/30bp
- **市值分档用 T 期 PIT 市值**（前收×股本，raw 空间）
- **年化单边换手 = 12 × 月均 Σ_i|Δw_i|**
- 默认全仓再平衡；再平衡带（±20%）作为变体单独跑

### 3.5 防未来函数检查清单（v2：14 类）

| # | 泄漏类型 | 检查 |
|---|---------|------|
| 1 | 用 T 日收盘决策 T 日收盘交易 | 执行价必须 T+1 开盘 |
| 2 | 财务未按公告日 PIT | v3 §3 PIT 规则 |
| 3 | 涨跌停/停牌假想成交 | 执行模型过滤 |
| 4 | 幸存者偏差 | **退市名单 367 家**：退市股行情可拉则并入主库按终止日动态剔除（可执行补测）；不可拉则池子覆盖核对+敏感性声明 |
| 5 | 全样本统计量做当期中性化 | 滚动 24 月窗口 |
| 6 | 全样本调参后同样本回测 | 样本外一次确认制（v3 §3-5） |
| 7 | qfq 数据进入引擎（隐含未来除权） | 引擎禁 qfq |
| 8 | 财务重述（用最新修订值回测历史） | 首次公告快照固化（§2.5） |
| 9 | 业绩预告/快报与正式财报混用 | 预告类按预告公告日 PIT |
| 10 | ST 公告日 vs 生效日 | 用生效日 |
| 11 | 涨跌停"日内曾触板"vs"开盘即板" | 一字板（开盘价==涨停价）才判不可买 |
| 12 | 市值/滑点分档用未来市值 | T 期 PIT 市值 |
| 13 | 停牌股前收填充因子失真 | T 期停牌剔除（引用 v3） |
| 14 | 除息日恰为 T+1 时外推成交价 | 用 T+1 实际 raw 开盘价（天然正确） |

### 3.6 基准与对齐
1. **主基准 = 510300/510500 ETF 的 hfq 行情**（复权含分红再投，真实可交易、无编制口径问题；ETF 费用 ~0.6%/年 → 基准仍低估 ~0.6%/年，写入偏差声明）
2. 价格指数（stock_zh_index_daily）保留为**辅基准/展示项**——**注意：价格指数不含分红**，用作主判定会虚增超额 ~1.5~2.5%/年（判决性误差，一轮审查修正）
3. 报告必须注明基准口径（价格/全收益）及差值估计
4. 对齐：同期间、同再平衡日历；报告超额年化、超额夏普、跟踪误差、信息比率

### 3.7 绩效指标口径（与 empyrical 一致）

| 指标 | 口径 |
|------|------|
| 年化收益 | 几何年化 |
| 年化波动 | 月收益 std × √12 |
| 夏普 | (年化 − rf)/年化波动，rf=0（与 v3 §10 一致） |
| 最大回撤 | 净值峰值→谷值 |
| 卡玛 | 年化/最大回撤 |
| 胜率 | 月收益>0 比例 |
| 换手 | 12 × 月均 Σ\|Δw\|（v2 修正公式） |
| **跟踪误差** | vs 双基准（决定判定功效解读，v2 补充） |

### 3.8 回测必报组合
毛/净收益、成本拖累、换手、三档成本敏感性（0.5x/1x/2x）、双基准超额（ETF 全收益为主+价格指数为辅）、逐年收益表、跟踪误差、滚动 36m 超额曲线。

## 4. 样本期、数据新鲜度与策略判定标准

### 4.1 原则：结构可比性 > 样本长度
2020-08 创业板注册制、2023-02 全面注册制、2023-08 印花税减半、2021-02 抱团瓦解、2024 微盘危机——旧数据描述已消失的市场结构。

### 4.2 样本分层

| 层级 | 区间 | 月数 | 角色 |
|------|------|------|------|
| 主回测 | 2019-01 ~ 今 | ~91 | 判定依据 |
| 核心子样本 | 2021-02 ~ 今 | ~66 | **最重要判定段** |
| 参考段 | 2017-2018 | 24 | **辅助证据**（v2 升级：不作主判定，但若此段显著为负而 2019+ 为正，必须解释结构断点） |
| 弃用 | <2017 | — | 不作任何依据 |

### 4.3 数据新鲜度
1. 回测数据更新到**最近一个完整月**；超 1.5 个月未更新 → 标记"陈旧"
2. **每季度强制重拉重跑**；输出**漂移对照表**（季度间结果差异 = 数据漂移检验）
3. 样本外确认（v3 §3-5）：最近 24 月不回看调参
4. 生产选股与回测口径一致

### 4.4 策略级判定标准（v2 新增，一轮审查 P0-1：草案完全缺失）

**回测不设显著性硬线**（90 月功效实测不足：超额 5%/年@TE10% 仅 40% 功效；显著性职责归 v3 因子检验层，其 116 月样本 t3 功效 62~64%）。回测判定 = **经济 + 一致性标准**：

| # | 判定项 | 通过线 |
|---|--------|--------|
| 1 | 主段净超额 | 主段（2019+）与核心段（2021-02+）**净超额均 > 0**（含全成本，ETF 全收益基准） |
| 2 | 成本敏感性 | **2x 成本下净超额仍 > 0** |
| 3 | 回撤约束 | 最大回撤不劣于同段双基准；卡玛 ≥ 0.5 |
| 4 | 引擎一致性 | Top30 净收益落在 v3 分层 Q4~Q5 之间且接近 Q5 |
| 5 | 结构稳定性 | 滚动 36m 超额曲线无结构断点（衔接 v3 观察线：末端<0、连续12月为负、断点后12月未回正 → 观察） |
| 6 | 制度段切分 | 2019-01~2020-08 / 2020-08~2023-02 / 2023-02~今 三段分别报净超额，三段均 > 0（或负段有合理解释） |
| 7 | 因子级证据链 | 入池因子全部通过 v3 检验（116 月样本） |

t 值仅作参考项展示，不参与判定。

### 4.5 与因子检验 v3 的衔接（v2 修正：删除一刀切）
- v3 主判定样本 2017+（已定稿）；本规范回测判定 2019+/2021+
- **2017-2018 有效性衔接 v3 滚动 36m ICIR 观察线**："断点后 12 月未回正 → 观察/剔除"（2019-2021 是成长碾压期，价值因子系统性弱势是风格现象而非结构失效，一刀切会误杀全部价值因子）

## 5. 第二轮待审查问题清单

1. 双口径铁律的边界是否完整？（还有哪些信号类别漏了？如"股息率因子"该用哪口径？）
2. 退市整理期强制卖出+5日顺延+清算规则是否可执行？（数据可得性：退市整理期行情在 akshare 可得吗？）
3. 策略判定标准 7 条是否完备/过严？（如"三段制度段均>0"是否过严？卡玛0.5 依据？）
4. 金样本对账单测的具体用例清单是否足够？
5. 东财 qfq 数据质量问题的处理：仅"禁用 qfq"是否够？还是需要对 hfq 本身也加异常校验？
6. 停牌判定用"行情行缺失"推断的正确性：停牌与退市/未上市/数据缺失如何区分？
7. 净值时点选择（月末收盘计净值、隔夜跳空计入首月）是否最优？还是 T+1 开盘起算更干净？
8. 参考段（2017-2018）"辅助证据"的具体使用规则：什么情况算"必须解释"？
9. 判定标准 1"净超额>0"没有幅度要求——90 月窗口下是否应加最小幅度（如年化>3%）以过滤噪声级超额？
10. 还有哪些遗漏？
