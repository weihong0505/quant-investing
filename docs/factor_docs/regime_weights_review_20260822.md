## 2. 审查意见（按 SOP §3.0 委托重点逐项）

### 2.1 36m ICIR 噪声下季度调权的增量价值 —— 🟠 有条件

- **噪声实锤**：月度 IC 波动 ~0.10~0.13（设计文档自认），36m 窗口 ICIR 的估计标准误可观；项目实测 90 月功效仅 20.3%，36m 更短。ICIR 绝对值**不足以**作为"因子有效"的判定依据（判定只能用 v3 主判定线 signed NW-t，见 ic_monitor）。
- **但用途不同**：本方案只用 ICIR 做**相对强弱排序**（raw_i / mean(raw) 缩放），决定权重微调方向而非有效性结论；±50% 幅度上限 + floor=0.1 把单期伤害封顶（最坏情况 = 基准权重 ±50% 内的扰动）。
- **增量价值必须实测**：设计文档 §5 的验证要求（PIT 调权 walk-forward、对比固定权重、2x 成本敏感性、调权增益>换手成本增量）是**批准实施的前提**，不是可选项。
- **条件**：调权增益（净成本）不能稳定为正、或 2x 成本下增益消失 → 方案 A 终止，不得进入主策略。

### 2.2 相关因子同步加成 —— 🟠 需处理（本次不加相关性惩罚）

- **风险**：EP/BP（价值簇）、ROE/GPM/CFO（质量簇）相关性高；公式无相关性惩罚，高相关因子同获高 ICIR 会被**同步加成**，集中度风险真实存在。
- **缓解（写进实施前提，本次实现不引入相关性惩罚以保持"规则简单可解释"红线）**：
  1. 调权只作用于**已通过 v3 统计检验 + 共线性闸门**（|corr|>0.7 已砍权/减半，SOP §3.2-5）的因子集合；
  2. 验证报告必须输出每期权重偏离度，检查是否存在同簇因子**同步顶到 ±50% 上限**；
  3. 若实测出现同步顶限 → 加簇级权重上限（如价值簇合计偏离 ≤ ±25%），需另行审批。

### 2.3 floor=0.1 / ±50% / 36m 参数敏感性 —— 🟡 必须做

- 三参数 ±20% 扰动是设计文档 §5-4 自定要求，实施时必做。`regime_weight_history` 已将 floor / max_dev / ic_window 全部暴露为函数参数，支持扰动实验。
- floor 语义提醒：ICIR≈0 时 raw=0.1 而非 0 —— 防归零的同时**拖慢"因子失效→降权"响应**，敏感性检查应覆盖 floor∈{0.05, 0.1, 0.15}、max_dev∈{0.4, 0.5, 0.6}、ic_window∈{30, 36, 42}。
- 36m 与 v3 观察线一致（复用同一统计量，无新增过拟合面）——此项通过。

### 2.4 与"先检验后集成"纪律的关系 —— ✅ 必须遵守

- SOP §3.0.2：统计检验通过后方可进入 WEIGHTS。季度调权属于 **WEIGHTS 层操作**：
  1. 未被 v3 检验的因子（即使设计已审）**不得参与调权**；regime_weights 只能作用于已检验因子集合；
  2. 调权规则本身样本外确定：公式与参数以本报告定稿日冻结，**禁止按回测结果回调参数**（一次确认制）；
  3. 本模块定位 = **研究验证工具**，不是实盘调权执行器；实盘接入需另走一次审批。

## 3. 与既有纪律/文档的一致性
