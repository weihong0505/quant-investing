## 1. 规则定义

`is_st(code, name)` — 纯名称前缀判定（code 参数不参与判定，仅接口/审计用）：

| 前缀 | 含义 | 示例 |
|---|---|---|
| `ST` | 特别处理（连续亏损/异常） | `ST华微` |
| `*ST` | 退市风险警示 | `*ST美盛` |
| `S*ST` / `SST` | 未股改 + ST（历史遗留写法，防御性覆盖） | `S*ST某公司` |
| `退` | 退市整理期（交易所强制冠名） | `退市海医` |

正则实现：`^(S?\*?ST)`（忽略大小写）+ `^退`。

**判定依据**：
- 交易所命名规范将 ST 标记固定置于证券简称**最前**，故前缀匹配 100% 覆盖，且天然避免误伤名称中段含 'ST' 的正常公司（如 `XXSTYY`、`SABCST科技`——实测两源中"含 ST 但非前缀"样本 = 0，防御写法仍保留）。
- **明确不用**子串式 `'ST' in name`（e2e_pipeline L437-438 的旧写法），防未来数据源引入英文简称/含字母代码时误伤。
- 大小写不敏感（`*st小写` → True）；NaN/None/空串 → False。

## 6. 遗留问题 / 风险

1. **仅当前简称口径**：is_st 反映"现在"的 ST 状态；历史某时点是否为 ST 不可得（需历史简称序列或日线涨跌停 5% 规则），e2e_pipeline 同样声明此限制。初筛（当前时点选股）不受影响，回测历史 ST 需另行处理。
2. **yjbb 非全市场**：yjbb(3876) ⊂ spot(5548)，交集仅 1587——初筛合并时必须以 spot 为全集、yjbb 左连接，防止漏掉未披露财报的股票。
3. **B 股**：yjbb 含 900xxx B 股（如 天雁B股），spot 无；若实盘仅投 A 股，B 股排除逻辑不在本模块范围，需在管线中另行处理。
4. **'退' 前缀样本空缺**：当前两源缓存中 '退' 开头简称 = 0（退市整理股未在快照中），规则已覆盖但未遇真实样本，以 `退市海医` 合成用例兜底验证。
5. **代码格式差异**：spot 代码为字符串 6 位、yjbb 为数值——cross_check 已归一化；filter_non_st 判定不依赖代码列，无影响。
6. **yjbb 双缓存变体**：`yjbb_20260630.parquet` 与 `yjbb_20260630_20260630.parquet` 实测完全一致（a.equals(b) = True），可任选其一。
