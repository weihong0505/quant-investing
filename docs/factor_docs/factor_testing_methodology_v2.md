## 1. 目的与范围

定义本项目新因子"能不能进主策略"的**统计判定标准与完整检验流程**。
核心问题：一个因子在 A股是否具有**稳定的、扣成本后可交易的**横截面预测能力？
本细则覆盖：IC 检验、分层检验、单调性、自相关、共线性、增量信息、多重检验、稳健性、经济显著性。
不含：因子经济逻辑审批（SOP §3.0）。

## 2. 术语定义

| 术语 | 定义 |
|------|------|
| 因子暴露 | 股票在 T 月末**最后一个交易日**的因子值（PIT 对齐） |
| 前瞻收益 | T+1 自然月收益（主口径）；T+1~T+3 复合收益（辅助，重叠修正见 §4.4） |
| IC | 横截面 Spearman 秩相关：corr(factor_T, ret_T+1)，月度频率 |
| ICIR | IC 均值 / IC 标准差（**ddof=1**，保留两位小数） |
| 分层 | 按因子值横截面分 5 组（20% 分位），组内等权（主）/市值加权（稳健性） |
| 多空组合 | 第 5 组 − 第 1 组 |

## 3. 数据准备规范（PIT 纪律）

1. **对齐**：财务类因子用"公告日 ≤ T"的最新值（PIT）
2. **收益处理**：前瞻收益 1%/99% winsorize（±50% 截断亦可，二选一固定）；因子值 ±3σ winsorize（行业内中性化则行业内）
3. **池过滤**（每月重算）：
   - 剔除 ST/*ST、退市整理
   - 剔除上市 < **120 交易日**（敏感性检验 60/250；IPO 炒作+业绩变脸窗口约 1 年）
   - 剔除 T 期停牌股
   - **T+1 可交易性规则**：T+1 月内停牌 ≥5 交易日或一字板 ≥5 交易日的股票当期剔除（前瞻收益不可得或不可交易）
   - ⚠️ 已知局限：akshare 仅含现存股票，**幸存者偏差无法完全消除**，检验结论须附此声明
4. **缺失**：因子缺失的股票当期剔除出检验样本；**必须报告月度因子覆盖率**（<70% 告警）+ 缺失指示变量与下期收益的 IC（检验 MCAR）
5. **样本期**：主起点 **2017-01**（结构稳定段）；2010/2015 起点作背景对照（akshare 财务接口历史深度不足时按数据覆盖率定起点，先跑覆盖率再定）
6. **中性化版本**：每个因子同时检验两版——原始值、行业+市值中性化值（回归取残差）。**检验前预指定交易版本**（默认原始版），仅中性化版通过时，中性化实施版必须单独报换手与净收益

## 4. IC 检验（第一道关）

### 4.1 主口径
月度 Spearman(factor_T, ret_T+1)，得 IC 时间序列。

**报告指标**：IC 均值、IC 标准差(ddof=1)、ICIR、IC 胜率、naive t、NW-t（**同时报告两者对照**）。

### 4.2 NW 滞后阶数
`lag = floor[4 × (N/100)^(2/9)]`（NW 1994 自动带宽，与 statsmodels cov_hac 默认一致，N=60→3）。
T+1~T+3 重叠收益时 `lag = max(3, 公式值)`。

### 4.3 判定（含经济显著性闸门，v2 新增）
| 档位 | 标准 | 处置 |
|------|------|------|
| 保留 | ICIR > 0.5 **且** \|mean IC\| ≥ 0.02 **且** 修正后显著性线通过 **且** IC 胜率 > 55% | 进入分层检验 |
| 观察 | 0.3 ≤ ICIR ≤ 0.5 且多空单调显著 | 标记观察，不启用 |
| 淘汰 | 其余 | 终止 |

> **v2 修订依据（审查 Q1/A）**：ICIR>0.5 与 NW-t>2 在 T>16 时冗余（实测 T=60、ρ=0.4 时 NW-t 仍 2.89），
> 故把第二个条件换成**经济幅度下限** \|mean IC\|≥0.02 与 §9 的**修正显著性线**；
> NW-t 保留为展示指标。另加**内部基准**：新因子 ICIR 必须 ≥ 存量 10 因子同窗口同池子 ICIR 的中位数（报告对比表）。

### 4.4 辅助口径
1. **IC 衰减曲线**：T+1/T+2/T+3/T+6/T+12 各期限 RankIC 与 ICIR（观察衰减，决定持有期）
2. T+1~T+3 **复合收益**（(1+r1)(1+r2)(1+r3)−1，非均值）的 IC——只作"信号持续性"描述
3. **down-month 条件 IC**：市场下跌月份的 IC 均值必须非负（硬指标）
4. **风险调整 IC**：因子对市场+规模+行业回归后残差与收益的 IC（防因子是波动率/β 代理）

## 5. 分层检验（第二道关）

### 5.1 做法
每月按因子值分 5 组，组内等权（主口径），月度再平衡。

### 5.2 成本口径（v2 修正）
按 **SOP §7 A.2 市值分档逐股计成本**（5/10/20/30bp 单边滑点），**禁止**统一用中盘档。

### 5.3 三重稳健性（v2 升级，全部必做）
| 检验 | 做法 | 通过标准 |
|------|------|---------|
| 市值加权 | 组内市值加权重算全套 | 净多空仍为正且显著 |
| 微盘剔除 | 剔除总市值 <30 亿样本重算 | 净多空仍为正且显著 |
| 规模中性分层 | 市值三分位 × 因子五分位，size-neutral spread | 净多空仍为正 |

### 5.4 单调性检验（v2 重写，修复统计硬伤）
1. **主检验：Patton-Timmermann (2010) MR 检验**——对"Q1<Q2<...<Q5 全序单调"做 bootstrap p 检验（p<0.05）
2. **辅助**：逐月对 5 组收益回归组序号得 β 月度序列，Fama-MacBeth 均值 + NW-t（lag=1~2，单侧，符号预登记）
3. 倒挂容忍：计数规则"相邻倒挂 ≤1 档 且 Q5>Q1"；**删除**"Q3 必须居中"（无文献依据）
4. 报告"完全单调月份占比"（描述性）
> 注意：v1 的"对 5 组年化收益回归"是错误形态（n=5 单横截面无时间维度），已废除。
> Spearman≥0.9 有浮点陷阱（恰一对相邻倒挂时 scipy 返回 0.8999...9 < 0.9 误杀），弃用。

### 5.5 分层必报清单
各组年化收益/年化波动/夏普/最大回撤/换手率、多空 NW-t、净多空年化（扣成本）、vs 基准（沪深300+中证500）超额、Q5 组平均市值与 ADV、分组迁移矩阵。

## 6. 因子自相关（决定再平衡频率）

1. 报告 **lag-1/3/6 自相关曲线**（横截面排名的月度 Spearman，对实际交易版本计算）
2. 三档阈值（>0.8 / 0.3~0.8 / <0.3）仅作**描述性标签**，不作硬门槛
3. **最终裁决用实证对比**：月度 vs 季度再平衡的**净收益（扣成本）**，哪个高用哪个
4. 自相关 <0.3 的处置：先提高频率重测净收益；净收益为负或低于基准则弃用（A股 T+1+高成本下"提高频率"不是免费选项）

## 7. 共线性与增量信息

1. 新因子 vs 存量 10 因子 Spearman 相关矩阵；|corr|>0.7 → 取 ICIR 较强者（**只用训练段数据裁决**，决策记入 registry，防样本内择优）
2. **Fama-MacBeth 多元回归增量检验（v2 新增，正式版）**：新因子加入存量因子（至少市值/EP/动量）的横截面回归，报告增量系数 NW-t——判定"增量信息"以它为准
3. 正交化残差检验作为辅助展示
4. 多因子合成前报告 VIF（>5 告警）

## 8. 稳健性检验（第三道关）

统一矩阵（身份标注：硬门槛 / 报告项）：

| 检验 | 做法 | 身份 |
|------|------|------|
| 样本分段 | 2017-01~2021-12 / 2022-01~今 两段 ICIR | 硬门槛：两段同号且均>0.3 |
| 分组数 | 5 组 vs 10 组 | 报告项 |
| 池子 | 全市场 / 沪深300 / 中证500 | 硬门槛：至少两个池子成立 |
| 压力测试 | 2015-06~08、2016-01、2018-10、2020-02、2024-01/02 逐月多空 | 报告项：单月多空<−10% 或连续两月亏损 → 至少"观察" |
| 熊市段 | 2015-06-12~2016-01-28、2018-01-24~2018-12-28、2022-01-04~04-26、2022-07-05~10-31、2024-01-02~02-05 | 报告项（不设 2/3 硬门槛） |
| 滚动 ICIR | 滚动 36 月 ICIR 曲线（标注 2017 风格切换/2021-02 抱团瓦解/2024 微盘危机） | 报告项，必须附图 |
| 中性化 | 原始 vs 行业市值中性 | 预指定版本为准，差异记录 |
| 参数敏感性 | winsorize ±2σ/±3σ、次新股 60/120/250 日、收益截断 ±50%/1%99% | 报告项，各跑一个变体 |
| 行业明细 | 行业内 IC 分布表（识别单行业驱动） | 报告项 |

## 9. 多重检验控制（v2 重写，修复非单调与误用）

**v1 三档方案的两处硬伤（审查 Q6 实测）**：
1. 严格性不单调：BHY(N=100) 首位 z≈3.90 比 HLZ(t=3.0) 更严；N=10/11 边界断崖
2. BH/BHY 是**批量 p 值同时排序**程序，单因子逐个审批场景无法使用

**v2 落地规则（固定阈值方案）**：
1. **预期符号在检验前登记** → 用单侧检验
2. 程序级固定显著性线：**|t| ≥ 3.0**（HLZ 线，与"新因子"先验风险匹配），全程序统一，不随 N 变化
3. 保守备选：|t| ≥ max(2.8, Bonferroni(N'))，其中 **N' = 本检验周期内同期受检新因子数**（不含存量、不含历史失败者），每季度重置
4. BH 仅用于"同期一批候选因子"的批量报告（辅助说明）
5. registry 的 N 口径同步修正：历史全量保留作审计，但阈值计算只用 N'

## 10. 经济显著性闸门（v2 新增，全流程级）

统计显著 ≠ 可交易。IC 与分层之外，必须过：
1. **净多空年化 ≥ 8%**（扣完整成本后）
2. **2x 成本敏感性下净多空仍为正**（衔接 SOP §7 A.5）
3. **净多空夏普 ≥ 0.8**
任一不满足 → 观察或淘汰，不论统计量多漂亮。

## 12. 检验流程（v2，含 registry 前置登记）

```
⓪ registry 前置登记（预期符号/样本期/数据版本/脚本路径）
  → ① 数据准备(PIT+池过滤+winsorize+覆盖率报告)
  → ② IC 检验（含经济幅度下限+内部基准）
  → ③ 分层+单调性（PT MR）+三重稳健性+成本后净多空
  → ④ 自相关曲线+再平衡频率实证
  → ⑤ 共线性+FM多元增量检验
  → ⑥ 稳健性矩阵+滚动ICIR+压力测试
  → ⑦ 多重检验（单侧 t≥3.0）
  → ⑧ 经济显著性闸门
  → ⑨ 回填 registry（完整统计量）+输出报告
  → ⑩ MImo 审批 → 入主策略
```

## 13. 输出报告模板（v2 扩充）

`factor_docs/test_{因子名}_{日期}.md` 必含：
1. 因子定义与经济逻辑（一句话）+ registry 编号
2. 数据来源、样本期、覆盖率曲线
3. IC 表：均值/标准差/ICIR/胜率/naive t/NW-t + IC 时序图 + 衰减曲线 + down-month IC
4. 分层表：5 组年化/夏普/回撤/换手 + 净多空（扣成本）+ 三重稳健性 + PT MR 单调性结果 + 迁移矩阵
5. 自相关 lag-1/3/6 曲线 + 再平衡频率实证结论
6. 共线性矩阵 + FM 多元增量检验结果 + VIF
7. 稳健性矩阵 + 滚动 36m ICIR 图 + 极端月份明细表
8. 多重检验：单侧 t、同期 N'、通过线
9. 经济闸门：净多空年化、2x 成本敏感性、夏普
10. 最终判定：保留/观察/淘汰 + 理由
11. 可复现材料：检验脚本路径、数据版本 hash、随机种子
