## 1. 目的与范围

定义回测的**数据口径、引擎规则、样本期、策略判定标准**，保证回测结果真实、可复现、与当前市场结构可比。
引用：成本模型（SOP §7 附录A）、因子检验（factor_testing_methodology_v3.md）、因子审批（SOP §3.0）。

## 2. 数据质量与复权规范

### 2.1 复权方式：全系统统一后复权（hfq）

| 维度 | 前复权 qfq | 后复权 hfq |
|------|-----------|-----------|
| 收益率计算 | ✅ | ✅ |
| 历史稳定性 | ❌ 新除权事件改写全部历史（实测年化漂移4~5%） | ✅ 历史恒定 |
| 收益/比率类信号 | ✅ 等价（实测 Spearman=1.0） | ✅ |
| 价格水平类信号 | ❌ 严重不等价（实测 0.3714） | 同左 |

**双口径铁律（v2.1 显式化，M5）**：本铁律同样适用于选股层因子构建（字段口径登记见 data_caliber_audit.md）

1. **收益/比率类信号**（MOM_60D、换手率、量比）→ hfq（含分红再投，实测对账误差 <0.03pp）
2. **水平/估值/股息类信号** → 明确口径：
   - **市值、股价水平、成交额、以绝对价格构造的信号**（LOG_MCAP、滑点分档市值）→ **不复权价**
   - **股息率 = 每股股息（公告名义金额）/ raw 价**（hfq 价会低估 F=2~7 倍，实弹）
   - **EP/BP/PE/PB 用 raw 总市值口径**：EP = 净利润_TTM / raw 总市值，BP = 净资产 / raw 总市值（天然规避每股复权歧义；**禁止复权 EPS 配 raw 价的交叉混用**）
   - **总则句：一切绝对价格、绝对金额、股数阈值的规则判定均在 raw 空间**
3. 行情一律 `adjust="hfq"` 拉取缓存；raw 价 `adjust=""` 同缓存；**禁止混用复权口径、禁止跨源混用**（东财累积因子 5.47 vs 新浪 6.74）
4. 涨跌停判定、成交价、股数、现金账 → raw 空间（§3.3）

### 2.2 数据完整性校验（每次拉取后必跑）

| 校验 | 规则 | 违规处置 |
|------|------|---------|
| OHLC 合理性 | Low ≤ Open/Close ≤ High；价格 > 0 | 剔除当日 |
| 停牌日统一口径 | 价格前收填充、成交量=0、可交易性=否 | 标记 |
| 价格跳变 | raw 价上，阈值 = 板块涨跌停幅度×(1+0.5%容差)，板块×时间矩阵 | 人工核查 |
| **hfq 自洽三件（M12）** | ① F_t=hfq/raw 单调不减（现金分红只增因子，下降即数据错）；② F_t 变动日集合 = 除权除息日集合（对账 stock_fhps_detail_em，多/少均告警）；③ hfq 日收益 \|r\| > 板块板幅×(1+容差) 告警（除权日豁免但必须与派息额对账） | 告警+人工核查 |
| **双源抽查（M12 定参）** | 新浪源 N=20 股 × 全区间日收益对账，每次全量拉取后跑 | 差异 >0.1% 告警 |
| 重复行 | 同代码同日期去重 | 保留最后 |
| 日期连续性 | 与交易日历比对，缺日补齐 | 报告缺失率 |
| 横截面完整性 | 每月股票数 vs 全市场数 | 报告覆盖率 |

**涨跌停幅度矩阵（随日历维护）**：
| 板块 | 幅度 | 起止 |
|------|------|------|
| 主板 | ±10%（ST ±5%） | 全期 |
| 创业板 | ±20% | 2020-08-24 起（此前 ±10%） |
| 科创板 | ±20% | 2019-07-22 起 |
| 北交所 | ±30% | 2021-11-15 起 |
| **免检白名单（M2）** | **科创板/创业板新股上市前 5 个交易日**（分别 2019-07-22/2020-08-24 起）、北交所新股首日、主板 2023-02-17 后新股前 5 日、**恢复上市首日**、退市整理期首日 | — |

**涨跌停价计算**：前收 × (1±幅度)，四舍五入到分。

### 2.3 特殊事件处理

| 事件 | 处理 |
|------|------|
| 停牌 | 前收填充+不可交易；复牌首日正常交易 |
| 次新股 | 未满 120 交易日剔除（引用 v3 §3，不重述） |
| 退市 | **进入整理期 = 强制卖出**（跌停顺延 5 日，仍卖不掉按整理期最后可成交日收盘清算，声明低估真实损失）。**整理期起始近似规则（M10）**：终止上市日前 15 交易日（2021+）/30 交易日（2020 前），按终止年份切换；**科创板无整理期**（直接终止）。**名单字段（M10）**：沪市 159 家无"终止上市日期"字段（仅暂停上市日期，实测）→ 引擎兼容两字段。**衔接注记**：v3 §3"剔除退市整理"是选股层不买入，本条是持仓层处置，不冲突 |
| ST | 用生效日（非公告日）；接口 `stock_zh_a_st_em` 类，**每周五收盘后维护一次**（M13） |
| 送转/配股 | 持仓股数按比例调整（raw 空间整数股）；配股缴款计入现金账（或声明未参与及口径调整）；**卖出可零股一次性清仓（M11 恢复条款）** |
| 北交所 | 明确排除出池（±30%、接口不同） |

### 2.4 交易日历与停牌判定（M6）

- `tool_trade_date_hist_sina` 生成日历，本地缓存
- **停牌判定用行情行缺失推断 + 存活区间边界**：
  1. 先用上市日与终止上市日框定**存活区间**，区间外日历日不算停牌不计缺失
  2. 存活区间内缺行**连续 ≥2 交易日** → 判停牌（前收填充、可交易性=否）
  3. 缺行 =1 日 → 先重拉一次，仍缺 → 前收填充 + 记缺失率
- `stock_tfp_em` **按股查询**停复牌区间作抽查校验（不作主判定，date 参数实测不可靠）
- 月末再平衡日 = 当月最后一个交易日

### 2.5 数据快照与可复现
- parquet 缓存 + 快照清单（文件名、行数、首末日、hash）；回测前校验 hash
- 财务数据按首次公告快照固化（防财务重述，防泄漏 #8）
- 报告附代码版本 hash + 随机种子

| 偏差 | 方向 | 量级/说明 |
|------|------|----------|
| 打新收益缺失 | 低估 | 2019-2021 约 1~3%/年，2022 起 <0.5%/年；**不得用打新上调判定线** |
| 幸存者偏差 | 高估 | §3.5 #4 两分支预案 |

## 3. 回测引擎规范

### 3.1 引擎选型：自研（500~800 行），四条件
1. **金样本对账单测（M11 扩编）**：用例清单 + 标的矩阵
   - 用例：一字板不买/跌停不卖/顺延期间第 2~5 日开板成交/停牌顺延放弃/整手取整/5 元最低佣金/印花税切换前后各一笔卖出（2023-08-27 按千1、08-28 按万5）/送转股数调整/配股缴款/退市清算/除息日恰为 T+1 调仓/多板块涨跌停矩阵（主板10% vs 创业20% vs ST5%）/T 日停牌剔除 vs T+1 停牌顺延边界/次新股 119 vs 120 交易日边界/卖出零股清仓
   - 标的矩阵：主板蓝筹 1（含除息日调仓）+ 创业板 1（含 2020-08-24 前后幅度切换）+ ST 股 1 + 退市股 1（深市现成：000004 国华退 2026-07）+ 高送转股 1（10送10）；样本期覆盖 2023-08-28 前后
   - 引擎输出逐分对账
2. **与 v3 分层引擎共享收益/成本内核并交叉验证（M3 恢复限定）**：**同一因子、同一池子、同一成本模型**下，Top30 等权净收益应落在该因子 v3 分层 Q4~Q5 之间接近 Q5；**容差 ±1pp 月均**（T+1 执行 vs v3 月末对齐的 1 天错位）
3. 单元测试覆盖全规则
4. 双口径（§3.3）

### 3.2 净值与收益计算
1. 组合收益 = Σ 权重×个股收益（月度）；净值 = ∏(1+r_t)；几何年化；波动 ×√12；rf=0（与 v3 §10 一致）
2. **净值时点（M7）**：**首期净值从首次 T+1 开盘起算**（现金 + 按开盘价计的组合成本 = 初始资金 − 首期交易成本），之后维持月末收盘计价。首月"隔夜跳空"是**估值基准伪收益**（策略当时不持仓），非隐性成本；真正的隐性成本是 T+1 开盘成交对 T 收盘信号的滑移，已由"T+1 开盘价成交"规则本身体现
3. 现金 = 未投部分，计 0 收益；现金与持仓在 raw 空间统一核算

### 3.3 执行模型（双口径铁律）
- 信号/收益层：hfq；执行/估值/成本层：raw（成交价、股数、整手、现金、税费金额、涨跌停、停牌全部 raw 空间）
- 换算因子 = hfq_t/raw_t（单股常数）
- T 日收盘目标权重 → T+1 raw 开盘价成交；一字板（开盘价==涨停价）不买、跌停不卖
- 停牌顺延 5 日，期间每日重判；放弃后资金 = 现金持有至下一调仓日，不重配；复牌首日跳空 >20% 直接放弃（2026-08-22 C4 拍板：放弃该次顺延，不再继续顺延——已落地为强制规则）
- 买入整手（100 股）；单笔 <2 万元跳过（raw 金额口径）；**卖出可零股一次性清仓**
- 调仓日恰逢除息日：raw 开盘价天然除息后，hfq 收益自动含分红再投
- 送转股数调整、配股缴款（§2.3）

### 3.4 成本与换手（与 SOP §7 附录A 全衔接）
- 逐股按市值档计往返成本：佣金万2.5双边 + 印花税（时变：2023-08-28 前千1/后万5）+ 过户万0.1双边 + 滑点 5/10/20/30bp
- 市值分档用 T 期 PIT 市值（前收×股本，raw 空间）
- 年化单边换手 = 12 × 月均 Σ_i|Δw_i|
- 默认全仓再平衡；再平衡带（±20%）作变体
- **容量衔接（M13）**：按 SOP A.7 检查（单股单日 ≤5% ADV、AUM>上限 20% 告警）

| 5 | 全样本统计量中性化 | 滚动 24 月窗口 |

### 3.6 基准与对齐
1. **主基准 = 510300/510500 ETF hfq 行情**（含分红再投，真实可交易；ETF 费率使基准低估 ~0.6%/年，写入偏差声明）
2. **价格指数为辅基准/展示项——价格指数不含分红**，作主判定会虚增超额 ~1.5~2.5%/年
3. 报告注明基准口径与差值估计
4. 对齐：同期间、同再平衡日历；报告超额年化、超额夏普、跟踪误差、信息比率

### 3.7 绩效指标口径（与 empyrical 一致）
年化收益（几何）、年化波动（月std×√12）、夏普（rf=0，与 v3 §10 一致）、最大回撤、卡玛、胜率、换手（12×月均Σ|Δw|）、跟踪误差（vs 双基准）。

### 3.8 回测必报组合
毛/净收益、成本拖累、换手、三档成本敏感性、双基准超额（ETF 主+价格指数辅）、逐年收益表、跟踪误差、滚动 36m 超额曲线。

## 4. 样本期、数据新鲜度与策略判定标准

### 4.1 原则：结构可比性 > 样本长度
2020-08 创业板注册制、2023-02 全面注册制、2023-08 印花税减半、2021-02 抱团瓦解、2024 微盘危机——旧数据描述已消失的市场结构。

### 4.2 样本分层

| 层级 | 区间 | 月数 | 角色 |
|------|------|------|------|
| 主回测 | 2019-01 ~ 今 | ~91 | 判定依据 |
| 核心子样本 | 2021-02 ~ 今 | ~66 | 最重要判定段 |
| 参考段 | 2017-2018 | 24 | 辅助证据（规则见 M8） |
| 弃用 | <2017 | — | 不作依据 |

**参考段使用规则（M8 操作化）**：
- **触发线**：参考段净超额年化 ≤ −3% 或超额最大回撤 < −5%（24 月样本任何显著性检验无功效，只用阈值）
- 触发后产物：《参考段连续性说明》固定小节，必含——参考段净超额与回撤、同期因子层滚动 36m ICIR、同期基准与风格/制度事件对照（2017 白马行情、2018 贸易战）、归因结论（风格现象/制度差异/数据差异/无法归因）
- **判据锚定 v3 观察线**：因子层滚动 36m ICIR 未触发观察线 → "风格现象，解释成立"
- **解释不成立 → 策略降"观察"，不否决**（解释义务 ≠ 否决线）

### 4.3 数据新鲜度
1. 更新到最近一个完整月；超 1.5 个月 → 标记"陈旧"
2. 每季度强制重拉重跑；输出漂移对照表
3. 样本外确认（v3 §3-5）：最近 24 月不回看调参
4. 生产选股与回测口径一致

### 4.4 策略级判定标准（经济 + 一致性，无显著性硬线）

| # | 判定项 | 通过线 |
|---|--------|--------|
| 1 | 主段净超额 | 主段与核心段净超额均 > 0（含全成本，ETF 全收益基准）。**两级标签（M9）**：≥3% = 达标；0~3% = 边际通过（必报超额 80% 置信区间 + "本窗口无法区分噪声级超额"声明 + 以判定 7 因子证据链为主要依据）。**不加 3% 硬线**（实测功效仅 20.3%，真 3% 策略 50% 概率被误杀） |
| 2 | 成本敏感性 | 2x 成本下净超额仍 > 0；**观察线：1x 成本拖累 ≤ 毛超额 50%**（M9） |
| 3 | 回撤约束 | 最大回撤不劣于同段双基准；**卡玛为报告项**（M1：删除"≥0.5"硬线——实测基准卡玛 0.006~0.010，0.5 线隐式要求年化 ≥22.8%，与回撤约束自相矛盾）；观察线：卡玛 < 双基准卡玛 |
| 4 | 引擎一致性 | 同一因子、同一池子、同一成本模型下，Top30 净收益落在 v3 分层 Q4~Q5 之间（容差 ±1pp 月均，M3） |
| 5 | 结构稳定性 | 滚动 36m 超额曲线无断点（衔接 v3 观察线：末端<0、连续12月负、断点后12月未回正 → 观察） |
| 6 | 制度段切分 | 2019-01~2020-08 / 2020-08~2023-02 / 2023-02~今 三段分别报净超额；负段的"合理解释"判据 = §4.2 参考段规则（锚定 v3 观察线，M8 合并） |
| 7 | 因子级证据链 | 入池因子全部通过 v3 检验。**过渡条款（M4）**：存量 10 因子 registry 统计量为空 → 定稿后按 v3 全流程补检（IC→PT MR→FM→经济闸）并回填；补检完成前，以存量审批记录（v1/v2 轮）+ 补检时间表为替代口径并在报告声明 |

t 值仅参考项，不参与判定。

### 4.5 与因子检验 v3 的衔接
- v3 主判定 2017+（116月）；本规范 2019+/2021+
- 2017-2018 有效性衔接 v3 滚动 36m ICIR 观察线（"断点后 12 月未回正 → 观察/剔除"）；2019-2021 成长碾压期价值因子弱势是风格现象，一刀切会误杀全部价值因子

## 5. 行情数据源策略与降级预案（M13）

|------|--------|------|
| 主源 | 东财 `stock_zh_a_hist` | 接口最全（含退市股页面候选）；**限流/封禁风险高**（两轮审查实测跨 ≥24h 持续被封，裸端点首请求即断） |
| 抽查/兜底源 | 新浪 `stock_zh_a_daily` | 稳定；无退市股、无部分字段 |

- 主源退避：失败重试 3 次指数退避；仍失败 → 用 parquet 缓存继续（数据稍旧但可用）
- **东财不可用超 24h → 可降级用新浪主源跑回测，但必须声明降级**（无退市股补测、覆盖率差异）
- **跨源只校验不拼接**（复权因子约定不同，实测累积因子 5.47 vs 6.74）
- 东财恢复后必跑回填清单（M10）：V7 退市股行情定档、V8 ETF hfq 基准差、V1 东财 qfq 差异日定位、东财分红对账——均不改判，只定档措辞
