## 2. 关键数据处理规则（P0 修订）

### 2.1 逐股 PIT 最新报告期（P0-2）
```
每只股票的最新报告期 L = max{ 报告期 | 该股"最新公告日期" ≤ 今日 }
```
- 未披露最新期的股票自动回退上一期（例：8/20 时 Q2 仅 40.6% 披露，其余用 Q1）
- 拉取 7 个报告期：20241231 ~ 20260630，覆盖回退
- TTM 公式（累计值滚动，审查 Q2 已确认正确）：
  `TTM = 去年年报 + 最新期累计 − 去年同期累计`；L=年报时自动退化为年报值
- 8 月中报季覆盖率 <90% 时告警

### 2.2 金融行业中性化（P0-3）
- 金融股（行业名含 银行/保险/证券/多元金融/信托）：**全部 4 个质量因子赋中性分 0**
- 非金融股：GPM / ROE_TTM / LEV 做**行业内 z-score**（用 yjbb"所处行业"字段）
- CFO_NI 全市场标准化（行业差异小）
- 其他 6 因子（EP/BP/MOM/TURN/LOG_MCAP/VOL_RATIO）维持全市场 z-score 不变

### 2.3 负利润符号保护（P0-4）
- TTM每股收益 ≤ 0 的股票：CFO_NI_TTM 直接赋 -3（最低分），不参与比值计算
- 防"双负得正"符号翻转

### 2.4 清洗
- winsorize ±3σ（行业中性化因子按行业内 winsorize，其余全市场）
- 缺失 → 该因子中性分 0

## 3. 打分体系（v2 修订：z-score 加权代替排名）

- 每个因子：winsorize → z-score → 乘方向系数（+1 越高越好 / -1 越低越好）
- 综合分 = Σ 权重 × 标准化因子分（金融股质量项=0）

## 5. 学术依据（v2 修正引用）

1. **ROE**：Fama-French (2015) RMW；Piotroski (2000) F-Score 首项实为 **ROA>0**（ROE 属同一盈利维度，措辞已修正）；F-Score 结论限于**高 BM 价值股子样本**，对外推已降级表述
2. **GPM**：Porter 竞争战略的议价权代理；Novy-Marx (2013) 变量是 **毛利润/总资产 (GP/A)**，与销售毛利率不同（差资产周转率维度）——v2 以 Porter 为依据，GP/A 升级列为 v1.1 路线
3. **CFO_NI**：Sloan (1996) 应计异象的**代理变量**（非应计项本身）；v1.1 可用 总市值/最新价 反推股本构造 Accruals_TTM
4. **LEV**：Piotroski F-Score 的 LEVER 项实为"长期杠杆率**同比下降**"（Δ），非低杠杆水平，引用已修正；Graham 防御型低负债标准继续作为独立依据
