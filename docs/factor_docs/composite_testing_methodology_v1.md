## 1. 目的与范围

定义"10 因子加权 SCORE 组合"能否作为主策略的**组合层统计判定标准与完整检验流程**。

核心问题：单因子全部过检之后，**按当前 WEIGHTS/DIRECTION 线性加权合成的 SCORE** 是否具有稳定的、扣成本后可交易的横截面预测能力？**权重配置本身是否有害**？

### 1.1 必要性（为什么单因子过检 ≠ 加权组合有效）

1. **因子相关**：因子间存在横截面相关（EP×BP 同属价值组，MOM 与价值类因子历史负相关——Wiki 自认的"最大矛盾"）。相关因子权重叠加会放大共同暴露、稀释独立信息，合成 SCORE 的有效信号不等于各因子有效信号的加总。
2. **权重配比**：权重决定组合暴露结构（当前价值组 0.40 / 质量 0.25 / 动量 0.15 / 流动性 0.15 / 规模 0.05）。配比无证据时，任何单因子检验结论都无法说明组合层面的暴露是否合理；权重集中度（如 EP+BP=0.40）本身就是一个未检验的赌注。
3. **方向叠加**：因子方向（d_i）若与实际预测方向偏离（如 MOM_60D 试点检验**反向显著**、VOL_RATIO 已淘汰），加权求和会把错误信号按权重放大进 SCORE，合成 IC 可能显著低于加权单因子 IC 基准甚至为负——这是因子层检验无法捕获的组合层风险。
4. **归因断裂**：缺组合层检验时，回测结果无法归因——跑赢/跑输是哪些因子暴露的功劳/损失，无法追溯到因子层证据，也就无法指导权重修订。

### 1.2 范围

- **检验对象** = `SCORE = Σ_i w_i × d_i × z_i`；w/d 当前为 `code/multi_factor_value.py` L60-75 的 v2 权重与方向（EP 0.20 / BP 0.20 / ROE_TTM 0.12 / MOM_60D 0.15 / TURNOVER 0.15 / GPM 0.06 / LOG_MCAP 0.05 / CFO_NI_TTM 0.05 / LEV 0.02；VOL_RATIO 已并入 TURNOVER）
- **不含**：因子经济逻辑审批（归 SOP §3.0/v3 上游）、权重取值的主观设计讨论（归 MImo 审批）、单因子检验本身（归 v3）
- **数据受限声明**：样本 <60 月时全部结论自动降级为"初步"，不得据此进入实盘讨论（与 v3 §1 同款声明）

## 2. 术语定义

| 术语 | 定义 |
|------|------|
| 组合层检验 | 以加权 SCORE 为唯一检验对象的检验流程（本文档定义） |
| 合成 SCORE | Σ_i w_i × d_i × z_i；z 的标准化口径与各因子检验口径一致（全市场 z-score / 行业内 z-score，见 wiki factor-direction-map.md），月度 PIT 对齐 |
| 合成 IC | 横截面 Spearman(SCORE_T, ret_T+1)，月度频率（与 v3 §2 的 IC 同一定义） |
| 合成 ICIR | 合成 IC 均值 / 合成 IC 标准差（ddof=1，保留两位小数），同 v3 §2 |
| 加权单因子 IC 基准 | B = Σ_i w_i × mean(IC_i)；IC_i 为因子 i 的**月度 IC 均值（signed，预登记方向口径）**——若因子实际方向与登记相反，其 signed IC 为负，自动压低基准（这是"权重方向有害"的检测机制） |
| 交互损耗 | 合成 IC − B（秩相关的非线性损失/增益，量化"抵消与交互"） |
| 证据编号 | W-<因子名>-<类型>-<YYYYMMDD>-<序号>，权重证据的唯一标识（§3.3） |
| 权重修订 | 对 WEIGHTS 任何数值/方向/因子集合的变更（含合并、拆分、清零） |
| 组合引擎 | backtest_engineering_spec_v2.1 定义的自研回测引擎（code/backtest.py） |

## 3. 检验步骤（对应 M2 任务书 §4 五条）

### 3.1 第一步：合成 SCORE 横截面检验（M2 §4-1）

**前置登记（⓪ 步，同 v3 §12 registry 纪律）**：合成 SCORE 定义（权重、方向、标准化口径）、样本期、数据版本 hash、检验脚本路径、登记时间戳——**登记后字段锁定**；权重表以登记时冻结版本为准（存量因子状态变化——如 MOM_60D 反向显著、VOL_RATIO 淘汰——使冻结版本失效时，须重新登记，原记录保留，计入 N'）。

**主口径**：月度 Rank IC（SCORE_T vs ret_T+1）。主判定样本 = 2017-01 起全样本（T≈116 月，与 v3 §3-5 一致）；训练段 = 检验日 −24 个月前（仅用于 §3.4 共线性裁决）；样本外确认段 = 最近 24 个月（仅报告，不参与裁决，一次确认制）。

**必报项**：
1. 合成 IC 均值 / 标准差 / ICIR / 胜率 / naive t / NW-t（NW lag 公式同 v3 §4.2，T+1~T+3 重叠时 lag=max(3, 公式值)）
2. 加权单因子 IC 基准 B、交互损耗（合成 IC − B）——**与单因子 IC 对比的基准规则，见下**
3. leave-one-out 合成 IC 表：剔除因子 f 后重算 SCORE_{−f} 的 IC，ΔIC_f = IC(SCORE) − IC(SCORE_{−f})（供 §3.4 交互检查与归因使用）
4. 合成 IC 衰减曲线（T+1/T+2/T+3/T+6/T+12）
5. 滚动 36m 合成 ICIR 曲线（衔接 v3 §8 观察线：末端 <0.3 / 连续 ≥12 月为负 / 断点后 12 月未回正 → 任一即降级观察）
6. down-month 合成 IC 与高波动月合成 IC（硬指标：必须非负，与 v3 §4.4 对称）
7. 分年度 / 分制度段（2017~2018 / 2019~2020-08 / 2020-08~2023-02 / 2023-02~今）合成 IC 表
8. 合成 SCORE 分层 5 组净多空（扣成本；成本口径同 v3 §5.2，含 2x 成本敏感性）——作为合成 IC 的稳健性交叉验证

**判定线（与 v3 单因子线对齐，不自创统计量）**：

| 指标 | 通过线 | 观察线 | 不通过线 |
|------|--------|--------|---------|
| 合成 ICIR | > 0.5（同 v3 §4.3 保留线） | 0.3~0.5 | < 0.3 |
| \|合成 mean IC\| | ≥ 0.02（同 v3 §4.3） | — | < 0.02 |
| 显著性 | signed NW-t ≥ max(3.0, Bonf(N'))（v3 §9 同线；组合层检验计入 N'） | — | 不达线 |
| **vs 加权基准 B** | **合成 mean IC ≥ B − 0.005** | B − 0.010 ~ B − 0.005 | < B − 0.010 |
| down-month / 高波动月合成 IC | 非负（硬指标，v3 §4.4 同款） | — | 任一为负 |

**基准规则说明**：
- 直觉：若权重只是把单因子信号线性搬移，合成 IC 的期望不应低于各因子 IC 的加权和；实际合成 IC（秩相关，非线性）低于加权和的部分即"抵消/交互损耗"。
- B 用 signed IC：某因子实际方向与登记相反时其 signed IC 为负，会压低 B——这正是检验"权重方向是否仍然有效"的机制。
- **联动条款**：合成 mean IC < B − 0.005（"权重配置有害"）→ 结论锁定不超过"部分通过"（§3.5），即使回测指标尚可；回测仍须完成，以量化损害并定位来源（哪几个因子的权重在拖累）。
- 观察线区间容差 0.005/0.010 的合理性 → 待审问题 A-1。

### 3.2 第二步：组合引擎回测（M2 §4-2）

按 **backtest_engineering_spec_v2.1 全文**执行（本节约束与摘要；完整规则以 v2.1 为准，不重述不修改）。本步是组合层的最终判定依据之一，与第一步构成"横截面证据 + 时序证据"双证。

**执行要点（引用 v2.1）**：
- 引擎：自研引擎（code/backtest.py），金样本对账单测 + 单元测试 + 与 v3 分层引擎交叉验证（v2.1 §3.1）；引擎一致性判定：Top30 净收益落在各因子 v3 分层 Q4~Q5 之间（容差 ±1pp 月均，v2.1 §4.4 #4）
- 数据：hfq/raw 双口径铁律（v2.1 §2.1）——信号/收益层 hfq，执行/估值/成本层 raw；数据完整性校验、hfq 自洽三件（M12）、双源抽查（v2.1 §2.2）；退市整理期强制卖出（M10 近似规则）；ST 用生效日（M13）
- 执行模型（v2.1 §3.3）：T 日收盘信号 → T+1 raw 开盘价成交；一字板不买 / 跌停不卖 / 停牌顺延 5 日（复牌跳空 >20% 直接放弃）/ 整手 100 股 / 单笔 <2 万元跳过 / 卖出零股一次性清仓
- 成本（v2.1 §3.4，与 SOP §7 附录 A 全衔接）：佣金万2.5双边 + 印花税时变（2023-08-28 前千1、后万5）+ 过户费万0.1双边 + 分档滑点 5/10/20/30bp（按市值档）；**2x 成本敏感性 = 全部交易成本 ×2**（非只滑点×2）；年化单边换手 = 12 × 月均 Σ|Δw|
- 组合构建：**主口径 Top30 等权**（与 v2.1 §3.1/#4 的 Top30 口径衔接）；变体 = SCORE 连续加权 + 再平衡带 ±20% 版本（v2.1 §3.4）
- 基准（v2.1 §3.6）：**主基准 = 510300/510500 ETF hfq**（含分红再投，真实可交易；ETF 费率 ~0.6%/年写入偏差声明）；价格指数为辅基准/展示项（防虚增超额 1.5~2.5%/年）
- 样本（v2.1 §4.2）：主回测 2019-01~今（~91 月）；核心子样本 2021-02~今（最重要判定段）；参考段 2017-2018 按 M8 规则（触发线：净超额年化 ≤ −3% 或超额最大回撤 < −5%）
- 防未来函数 14 类清单（v2.1 §3.5）逐项自查并归档

**判定：v2.1 §4.4 七条逐条执行**（组合层摘要表）：

| # | 判定项（v2.1 §4.4） | 通过线 |
|---|--------------------|--------|
| 1 | 主段净超额 | 主段与核心段净超额均 > 0（含全成本，ETF 全收益基准）；两级标签：≥3% 达标 / 0~3% 边际通过（必报 80% 置信区间 + 声明） |
| 2 | 成本敏感性 | **2x 成本下净超额仍 > 0**；观察线：1x 成本拖累 ≤ 毛超额 50% |
| 3 | 回撤约束 | 最大回撤不劣于同段双基准；卡玛为报告项（观察线：卡玛 < 双基准卡玛） |
| 4 | 引擎一致性 | Top30 净收益落在各因子 v3 分层 Q4~Q5 之间（±1pp 月均） |
| 5 | 结构稳定性 | 滚动 36m 超额曲线无断点（衔接 v3 观察线：末端<0、连续 12 月负、断点后 12 月未回正 → 观察） |
| 6 | 制度段切分 | 2019-01~2020-08 / 2020-08~2023-02 / 2023-02~今 三段分别报净超额；负段解释判据 = M8 参考段规则（锚定 v3 观察线） |
| 7 | 因子级证据链 | 入池因子全部通过 v3 检验；**过渡条款（M4）**：存量 10 因子补检完成前，以存量审批记录（v1/v2 轮）+ 补检时间表为替代口径并在报告声明 |

t 值仅参考项，不参与判定（v2.1 §4.4）。

**必报组合（v2.1 §3.8）**：毛/净收益、成本拖累、换手、三档成本敏感性、双基准超额（ETF 主 + 价格指数辅）、逐年收益表、跟踪误差、滚动 36m 超额曲线。

**组合层附加报告项（归因要求，§4.3）**：
- 组合月度因子暴露时间序列（各因子 Σ|w_i × z_i| 或暴露均值），超额收益归因到因子暴露贡献
- 单因子对照：每个过检因子单独跑一遍引擎（Top30），与合成组合净超额对比——实证回答"加权组合是否优于单因子"
- 已知偏差声明全项（v2.1 §2.6：打新缺失、幸存者偏差、停牌填充、红利税、ETF 费率、配股/可转债）

### 3.3 第三步：权重证据编号制度（M2 §4-3）

**原则**：每个因子权重必须挂证据编号；无证据编号且未标注"主观先验（待验）"的权重 = 违反 SOP 纪律，不得进入最终权重表。

**编号格式**：`W-<因子名>-<类型>-<YYYYMMDD>-<序号>`
- 类型 ∈ {TEST（因子层检验报告）, COMP（组合层检验报告）, DESIGN（设计审批记录）}
- 例：`W-EP-TEST-20260822-01` → 引 docs/factor_docs/test_EP_20260822.md；`W-EP-COMP-20260822-01` → 引 docs/factor_docs/composite_test_20260822.md

**三种证据标签**（回填至 wiki factor-direction-map.md"依据"列）：

| 标签 | 含义 | 可否作为最终权重依据 |
|------|------|--------------------|
| 检验报告编号 | 因子层 v3 全流程过检 + 组合层贡献验证（§3.1 leave-one-out ΔIC_f > 0，未被 §3.4 处置） | ✅ 是 |
| 设计审批引用 | MImo 审查记录 / registry"已审(v2)"标记（仅存量过渡条款 v2.1 M4 可用） | ⚠️ 过渡期可用，S1 补检完成后必须替换为检验报告编号 |
| 主观先验（待验） | 无统计证据的经验/拍脑袋权重 | ❌ 不得作为最终权重依据；须在组合层检验中显式暴露（§3.1 基准规则会惩罚其拖累），补检不过 → 权重修订 |

**weight-change 日志**：所有权重调整（数值/方向/因子集合变更/合并/清零）记**追加式**日志，不改原行（同 registry 纪律），字段：日期 | 版本 | 变更内容 | 原因 | 证据编号（本次调整依据）| 决策者 | 审批。落点：wiki factor-direction-map.md 权重变更记录表；涉及因子集合变更时同步 factor_registry.md 审计日志。

**最小粒度**：一个因子一个证据编号；一次权重修订对应一条 weight-change 日志行（不做子权重拆分编号）。粒度是否足够 → 待审问题 A-3。

**存量处理**：当前 WEIGHTS 共 9 项（VOL_RATIO 已并入 TURNOVER）证据编号全部为空 → 先统一标注"⏳ 主观先验（待验）"，S1 补检 + 组合层检验完成后逐项回填。

### 3.4 第四步：因子交互检查（M2 §4-4）

**对象**：组合内所有 |corr| ≥ 0.5 的因子对（Spearman，月度截面相关的中位数；主候选：EP×BP 同属价值组、MOM×TURNOVER 等）。0.5 为**筛查线**，**处置线沿用 v3 §7 共线性闸门 |corr| > 0.7**（不自创阈值）。

**做法**（全部基于 v3 已有框架，不引入新统计量）：
1. 相关矩阵：组合内因子两两 Spearman（同 v3 §7-1：**只用训练段 = 检验日 −24m 前数据裁决**，决策记 registry）
2. 联合贡献 vs 单独贡献（对每个高相关对 (f1, f2)，数据来自 §3.1 leave-one-out 表）：
   - 单独贡献：ΔIC_1、ΔIC_2（各自剔除后的合成 IC 变化）
   - 联合贡献：同时剔除 f1、f2 的 ΔIC_{12}
   - **"联合不加分"判据**：|corr| > 0.7 且 ΔIC_{12} ≤ max(ΔIC_1, ΔIC_2) + 0.005（容差 = 0.005 绝对 IC，与 §3.1 基准规则容差一致）——即去掉冗余一方后组合 IC 不下降
3. 处置：联合不加分 → 按 SOP 共线性闸门（v3 §7-1）：**取 ICIR 较强者保留**，弱者权重归并或清零，走 weight-change 日志（§3.3）；决策记 registry
4. 报告：相关矩阵、每对联合/单独贡献对比表、处置记录（保留/归并/清零 + 证据编号）

筛查线与容差的合理性 → 待审问题 A-5。

### 3.5 第五步：结论三档（M2 §4-5）

| 档位 | 条件（AND） | 处置 |
|------|-----------|------|
| ✅ **通过** | ① 合成 IC 检验全部通过线；② 回测判定 7 条全部通过线；③ 权重证据编号齐备（无"主观先验（待验）"残留，或残留权重已补检通过）；④ 无"联合不加分"对未处置 | 策略可进入**实盘讨论**（仍需 MImo 审批 + 实盘前检查清单，本文档不含） |
| ⚠️ **部分通过** | ①/② 通过线基本满足但触发 ≤2 项观察线/报告项告警；或 ③ 有"先验待验"残留；或 ④ 有冗余对待处置；或 §3.1 联动条款触发（vs 基准"权重配置有害"） | **权重修订再验**：定位问题因子（leave-one-out ΔIC 表 + 回测归因）→ 走 weight-change 日志 → 重跑 §3.1 或 §3.2 对应环节 → 重新登记（原记录保留，计入 N'） |
| ❌ **不通过** | ① 合成 IC 硬线不满足（ICIR < 0.3 / \|IC\| < 0.02 / down-month 或高波动月为负 / vs 基准 < B − 0.010）；或 ② 主段或核心段净超额 ≤ 0 / 2x 成本下净超额 ≤ 0；或 ③ 证据缺失且修订无明确方向 | **回炉因子选择**：回到 S1 因子池 / 权重结构重新设计（含单因子权重清零预案），重走本方法全流程 |

**阈值依据**：三档条件中的每一条都直接映射 v3 §11 / v2.1 §4.4 既有判定线（对齐表见 §4.2），不新增绝对线；"≤2 项观察线告警"档位组合规则的依据 → 待审问题 A-4。

## 4. 判定线与 v3 的一致性要求

### 4.1 不引入新统计量
组合层只允许使用：
- **v3 已定义**：IC、ICIR、NW-t（含 lag 公式）、signed NW-t 多重检验线、PT MR、FM 增量检验、分层净多空、经济闸门（净多空年化 ≥8% / 2x 成本为正 / 夏普 ≥0.8）
- **v2.1 已定义**：年化收益、年化波动、夏普（rf=0）、最大回撤、卡玛、信息比率、跟踪误差、换手、成本模型

任何新统计量（含"组合层专用"的提议）必须走与 v3 同款的 MImo 两轮审查流程后方可加入——v1 草案已刻意避免引入新统计量（"交互损耗"与"ΔIC"是对既有 IC 统计量的算术分解，非新统计量）。

### 4.3 可归因性（组合层统计量 → 因子层证据）
1. 合成 IC 必须附分解：合成 IC、加权单因子基准 B、交互损耗（差值）、leave-one-out ΔIC 表——任何"组合有效/有害"结论都能定位到具体因子权重
2. 回测超额必须附因子暴露归因：组合月度暴露 × 因子层检验结论（registry 预期符号/IC 方向），说明超额主要来自哪些因子、哪些暴露是负贡献
3. 任何"通过"结论必须在因子层找到对应证据行（registry 编号 + 检验报告编号）；找不到 → 结论自动降为"部分通过"
4. 组合层检验报告必须引用其依赖的因子层报告编号，形成证据链（§6 报告模板第 7 项）

## 附录 A：审查请求区（供 MImo 独立审批）

> 本附录为 v1 草案的独立审批入口。以下待审问题为草案作者主动暴露的设计疑点，请 MImo 逐条给出裁决意见；裁决结果回填至 §7 修订记录。

**A-1 合成 SCORE 的 IC 基准是否合理**
基准 B = Σ_i w_i × signed mean(IC_i)。待审点：① 用 signed（登记方向）IC 还是 |IC_i|？signed 会把"方向失效因子"自动变成负贡献压低基准——敏感，但可能过度惩罚（因子层方向失效与权重配比问题混在一起）；② 容差 0.005（通过线）/ 0.010（不通过线）的取值依据是否成立？③ "组合 IC < B − 0.005" 即锁定"部分通过"的联动条款是否过严？

**A-2 组合回测与因子检验的证据优先级**
v2.1 判定 #7 依赖因子级证据链（M4 过渡条款）。待审点：① 若 S1 补检未全部完成，组合回测可否先跑（仅报告不判定）？还是严格禁止？② 因子层检验结论与组合层回测结论冲突时（如单因子 ICIR 全部达标但组合净超额为负），最终裁决以哪一层为准？③ "先验待验"权重的存在是否应该一票否决"通过"档？

**A-3 权重证据编号的最小粒度**
方案：一个因子一个编号 + 一次修订一条日志。待审点：① 是否应按"权重调整事件"编号（同一次修订涉及多个因子 → 一个修订编号组）以便审计追溯？② "设计审批（v2 轮）"标签在 S1 补检完成前是否可作为过渡依据（M4 口径）？③ 粒度不足的后果（审计困难）与过度工程的代价如何权衡？

**A-4 结论三档的阈值设定依据**
方案：通过 = ①+②+③+④ 全过；部分通过 = ≤2 项观察线/报告项告警。待审点：① "≤2 项"的数字依据（为何不是 1 或 3）；② 观察线告警与"先验待验"残留是否应分权重计分（如先验待验残留一票否决 vs 告警累计）；③ "不通过"档的"回炉因子选择"是否应包含**单因子权重清零预案**（证据不足的因子先清零再验，而非整体回炉）？

**A-5 因子交互检查的筛查线与容差**
方案：|corr| ≥ 0.5 筛查 / > 0.7 处置（v3 闸门）；"联合不加分"容差 0.005。待审点：① 筛查线 0.5 是否合理（0.4 防漏 vs 0.6 减少检查对数量）；② leave-one-out 的 ΔIC 判定对相关结构是否足够——是否需要组合层 FM 增量检验（但那是新统计量，需 v3 同款审批流程，本文档已刻意回避）；③ 处置规则"取 ICIR 较强者保留"是否应附加"组合贡献"标准（ICIR 高但组合层 ΔIC 为负的因子如何处理）？

**A-6 组合构建主口径**
方案：主口径 Top30 等权（与 v2.1 #4 衔接），SCORE 连续加权为变体。待审点：① 主口径选择是否影响判定结论；② 是否要求两口径同向（都通过/都超过观察线）才可判"通过"；③ TopN 的敏感性（Top20/Top50）是否应纳入稳健性报告。
