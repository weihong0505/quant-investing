## 1. 接口说明

### fetch_mcap(codes, batch_size=60, retries=3) → Dict[code, float]
- 腾讯 qt.gtimg.cn 实时总市值批量拉取, 返回 `{6位代码: 总市值(亿元)}`
- URL: `https://qt.gtimg.cn/q=sh600000,sz000001,bj920000` (每批 ≤60 只, 已实现 0.5s 节流 + 每批 3 次重试)
- 解析字段45 = 总市值(亿元), 与 e2e_pipeline.fetch_qt_quotes 同源口径
- 代码转换: `60xxxx→sh`, `00/30→sz`, `8/4/9→bj`; 非法代码自动清洗, 失败个股跳过不抛错
- 代理绕过三件套内置: `NO_PROXY=*` + 清空 proxy 环境变量 + monkey-patch `requests.Session.request` (proxies=None)
- 缓存: 读 `data_cache/mcap_{YYYYMMDD}.parquet` (列: code/mcap_yi/ts), 缺的才拉, 拉完合并写回; 当日有效
- 响应按 GBK 显式解码 (`r.content.decode('gbk')`), 中文名不乱码

### filter_by_mcap(codes_df, min_mcap_yi=50, mcap_map=None) → DataFrame
- 输入 DataFrame 须含 `code` 列 (6位数字), 输出保留原列并新增 `mcap_yi` 列
- 剔除规则:
  - 市值不可得 (拉取失败/停牌无行情/非法代码): **保守剔除**, 打印数量并声明"市值不可得"
  - 市值 < min_mcap_yi: 剔除 (默认50亿, 避开微盘)
- `mcap_map` 可选: 传预拉取市值则跳过网络 (便于测试与管线复用)

## 5. 遗留问题 / 注意

1. **市值口径为实时**: 腾讯字段45为最新交易日实时总市值, 非财报时点市值; 初筛当天用没问题, 回测需历史市值 (可用 总股本×历史收盘 估算, 见 e2e_pipeline 声明)
2. **yjbb 缓存无"总股本"字段** (已确认: 列为序号/股票代码/每股收益/.../所处行业/最新公告日期), 故市值只能走腾讯 qt 实时, 无本地财务口径备选
3. **停牌/退市股**: 停牌股 qt 仍返回市值 (实测正常); 退市股不在 spot 池, 如遇拉不到则按"市值不可得"保守剔除, 符合初筛意图
4. **B股/基金代码** (5xxxxx, 900xxx) 不在映射表内, 会被跳过; 当前 spot 池为 A 股, 无影响
5. **全市场拉取**: 5548 只 ≈ 93 批 ≈ 2-3 分钟, 建议初筛管线仅在 spot 缓存刷新日全量拉一次 (当日缓存复用)
6. **覆盖率依赖网络**: 实测 100% 是本机网络环境结果; 若网络波动, 失败个股自动跳过、下次调用按缺补拉, 不会抛错中断管线
7. 文件编码: 模块为 UTF-8 无 BOM + LF; 若与项目其他工具混用需注意 (项目惯例 utf-8-sig 读可兼容)
