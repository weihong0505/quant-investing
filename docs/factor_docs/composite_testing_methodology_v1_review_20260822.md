### A-1 合成 SCORE 的 IC 基准（signed vs |IC|、容差、联动条款）

| 待审点 | 作者方案 | MImo 裁决 | 理由（数学复核） |
|--------|---------|-----------|------------------|
| ① signed vs \|IC\| | L38：B = Σ wᵢ×signed mean(ICᵢ)，方向失效因子自动压低基准 | **改 |IC| 口径（P0-1）** | 线性近似下合成 IC ≈ Σλᵢ×ICᵢ（λᵢ 为有效权重）。因子 f 方向失效（真实 IC_f = −c）时，合成 IC 与 signed B **同步**下降 w_f×c（λ≈w 时两者各减 w_f·c），差值 Δ = 合成 IC − B 不变 → **vs-B 线对方向失效零检测力**。作者在 L74 声称的"检测机制"效果相反：signed B 把方向失效吸收进基准两侧，恰使"权重配置有害"更难触发。\|IC\| B 的零假设 = "所有权重方向正确时的线性期望"，方向失效因子按正贡献计入基准、其拖累直接表现为 合成 IC < B，检测力成立（Δ ≈ −2w_f·c < 0） |
| ② 容差 0.005/0.010 依据 | L69/L76：通过 ≥ B−0.005，不通过 < B−0.010 | **容差与 Δ 的时序 SE 挂钩（P1-1）** | 0.005 无任何推导。T=116 月、典型 σ_IC≈0.06~0.10 时合成 IC 时序 SE≈σ/√T≈0.006~0.009，0.005 ≈ 0.5~0.8 个 SE——"通过线容差"与噪声同量级，会与显著性线（NW-t≥3.0）冲突（显著为正的组合仍可能 Δ<−0.005）。修正：通过线 Δ ≥ −0.674×SE(Δ)（50% 分位对应，绝对下限 −0.005 保留）；不通过线 Δ < −1.645×SE(Δ)（单侧 5%，绝对上限 −0.010 保留）；观察线介于其间。SE(Δ) 用 bootstrap（月份整块重抽，种子归档） |
| ③ 联动条款是否过严 | L75：Δ < B−0.005 即锁定"不超过部分通过" | **保留，不过严（但依赖 ① 改为 \|IC\| 后才真正生效）** | 联动条款是"组合层独有信息"的最后防线，回测指标再好也不能掩盖权重配置有害，锁定部分通过合理。现规则下因 signed 自我抵消，该条款几乎永不触发——过严问题在 |IC| 口径下才需要正视，而 |IC| 口径下该条款的从严方向正确。另需在 L155 明确：联动触发**不消耗**观察线告警计数（见 P0-3） |

## 4. 逻辑漏洞检查（审查要求 4）

### 4.1 基准 B = Σwᵢ×signed ICᵢ 的推导（A-1 数学复核，详见 §1）

三层结论：
1. **有效权重问题（P1）**：严格线性近似为 IC(SCORE) ≈ Σλᵢ×ICᵢ，λᵢ = wᵢ/√(w'Rw)（等 σ 时），λ ≠ w 除非 w'Rw = 1。当前权重结构（价值组内部正相关 w'Rw>1）→ 文档 B 偏高 → vs-B 偏严；负相关对（MOM×价值）→ B 偏低 → 偏宽。偏差方向随相关结构变化，**不可当作"无交互零假设"**。修正：报告有效权重 λ 与 B* = Σλᵢ×ICᵢ 作为对照列（P1，计算成本近零，相关矩阵 §3.4 已有）。
2. **signed 自我抵消（P0-1）**：方向失效时合成 IC 与 B 同步下降，vs-B 检测力为零——详见 §1 A-1①。必须改 |IC|。
3. **B 的重算窗口未定义（P1-6）**：B 中 ICᵢ 必须与合成 IC 同期同池重算（2017+ 主判定样本），不得直接引用因子层报告历史值（试点 42 月/16 月窗口与合成 IC 窗口不同 → 基准错配）。L38 补一句。

### 4.2 leave-one-out ΔIC 的解读（A-5②，详见 §1）

- ΔIC_f > 0 = 正边际贡献；< 0 = 负贡献（拖累）——**解读规则 L55 未显式化**，且 ΔIC_f < 0 的处置全文缺失（§3.5 仅隐含"定位问题因子"）。P1-2。
- 0 阈值对噪声敏感 → 设 |ΔIC_f| ≤ 0.005 视为无贡献。P1-2。
- 联合贡献裁决须用训练段（与 L140 相关矩阵同窗口），全样本作报告列。P1-2。
- 三因子以上交互不查（A×B 单独不加分、联合加分）——与 v3 范围一致，接受为边界（P2 备注）。

### 4.3 交互检查的处理规则可操作性（A-5③，详见 §1）

- "联合不加分"判据 L144 有公式、有容差，**可操作** ✓。
- 处置"取 ICIR 较强者保留"缺组合贡献标准 → **P0-4**（保留标准 = ICIR 强者 且 ΔIC_f > 0，否则修订/清零）。
- 处置记录走 weight-change 日志 + registry ✓（L145）。

### 4.4 结论三档可判定性（A-4①，详见 §1）

- "≤2 项观察线告警"无清单、等权计数、无依据 + "基本满足"含糊 → **P0-3**（分类加权显式清单）。
- 不通过条件③"证据缺失且修订无明确方向"——"无明确方向"无操作性定义（P1-13）：改为"明确方向 = 至少一个因子具备可检验的修订假设（ΔIC_f ≤ 0 因子的清零/反转，或权重重归一化）；无任何可检验假设 → 不通过"。
- 档位优先级（不通过 > 部分通过 > 通过）隐含未写（P2 显式化一句）。
- "降级观察"（L57 滚动 36m 观察线触发）未映射到三档（P1-12）：明确"降级观察 = 部分通过（处置 = 权重修订再验）"。
