## 1. 目的与范围

定义回测的**数据口径、引擎规则、样本期**，保证回测结果真实、可复现、与当前市场结构可比。
本文不涉及：因子检验（见 factor_testing_methodology_v3.md）、成本模型（见 SOP §7 附录A）、因子审批（SOP §3.0）。

## 2. 数据质量与复权规范

### 2.1 复权方式：全系统统一后复权（hfq）——核心条款

**问题**：akshare `stock_zh_a_hist` 提供 前复权(qfq)/后复权(hfq)/不复权 三种。

**裁决：全系统统一用 hfq。** 论证：

| 维度 | 前复权 qfq | 后复权 hfq |
|------|-----------|-----------|
| 收益率计算 | ✅ 正确 | ✅ 正确 |
| **历史稳定性** | ❌ **每次新除权事件会改写全部历史价格**（以最新价为基准），今天拉的历史与下月拉的**不同** → 信号漂移、结果不可复现 | ✅ 以首日为基准，新除权不改写历史，**历史值恒定** |
| 横截面 rank 信号 | 与 hfq 等价 | 与 qfq 等价 |
| 跨期动量类信号 | 有漂移风险 | ✅ 稳定 |

> 关键洞察：本系统所有因子最终都是**横截面 rank/z-score 化**的，秩统计量对"每股乘同一常数"的复权变换不敏感，所以 hfq/qfq 对**同时点横截面排序无差异**；差异全在**历史稳定性**上，而 hfq 完胜。

**配套规则**：
1. 所有行情一律 `adjust="hfq"` 拉取并缓存；**禁止混用复权口径**
2. 回测中现金分红默认**红利再投资**（hfq 价格天然含分红再投），不再单独处理
3. 需要真实成交价（如涨跌停判定）时用 `adjust=""` 不复权价，仅限该场景
4. 新旧数据合并时校验复权因子连续性（相邻两段重叠期价格比 = 常数）

### 2.2 数据完整性校验（每次拉取后必跑）

| 校验 | 规则 | 违规处置 |
|------|------|---------|
| OHLC 合理性 | Low ≤ Open/Close ≤ High；价格 > 0 | 剔除当日 |
| 成交量 | ≥ 0；缺失为 0（停牌） | 标记 |
| 价格跳变 | 单日 |涨跌| > 21%（非涨跌停）| 人工核查（除权日/数据错） |
| 重复行 | 同代码同日期去重 | 保留最后 |
| 日期连续性 | 与交易日历比对，缺日补齐（停牌填前收价） | 报告缺失率 |
| 横截面完整性 | 每月股票数 vs 全市场数 | 报告覆盖率 |

### 2.3 特殊事件处理

| 事件 | 处理 |
|------|------|
| 停牌 | 价格前收填充；不可交易（T+1 执行时跳过）；复牌首日正常交易 |
| 上市首日 | 剔除（未满 120 交易日的次新股整体剔除，与检验 v3 §3 一致） |
| 退市 | 按最后可交易价清算，计入组合净值（防幸存者偏差在回测层的二次泄漏） |
| ST 标记 | 交易日历中维护 ST 状态表，ST 期间不买入（与策略池一致） |

### 2.4 交易日历
- 用 akshare `tool_trade_date_hist_sina` 生成交易日历，本地缓存
- 月末再平衡日 = 当月最后一个交易日（非自然月末）

### 2.5 数据快照与可复现
- 全部行情/财务数据落 parquet 缓存 + **快照清单**（文件名、行数、首末日、hash）
- 每次回测运行前校验快照 hash，数据变了回测结果即变 → 强制重跑
- 快照清单随回测报告归档

### 2.6 已知偏差声明（写入每份回测报告）

| 偏差 | 方向 | 说明 |
|------|------|------|
| **打新收益缺失** | 低估组合收益 | A股 2019-2021 打新是显著收益源（市值配售，与持仓相关）；历史回测不含打新 |
| 幸存者偏差 | 高估 | akshare 仅含现存股票（检验 v3 已声明，回测层重申） |
| 停牌股价格填充 | 中性偏保守 | 前收填充略低估停牌风险 |

## 3. 回测引擎规范

### 3.1 引擎选型
**裁决：自研轻量引擎**（约 200 行），不用 backtrader。
理由：30~100 只股票、月度调仓、规则简单；自研透明可控、逐行可审计、无框架黑盒；backtrader 优势（多品种/日频/复杂订单）用不上。

### 3.2 净值与收益计算
1. 组合收益 = Σ 权重×个股收益（月度）；净值 = 累积 ∏(1+r_t)
2. 年化 = 几何年化 `(V_end/V_start)^(12/T) − 1`；月收益波动年化 ×√12
3. 现金 = 未投部分，计 0 收益（保守）；持仓市值用 hfq 价计算收益率（含分红再投）
4. 调仓日成本扣减（见 3.4）

### 3.3 执行模型（与 SOP §7 A.3 衔接）
- T 日收盘计算目标权重 → **T+1 开盘价**成交（hfq 开盘价换算）
- 涨停不买、跌停不卖、停牌跳过（顺延至下一可交易日，最长 5 日，逾期放弃）
- 买入整手（100 股取整）；卖出可零股
- 单笔 < 2 万元跳过（最低佣金 5 元抬升费率，SOP A.3）

### 3.4 成本与换手（与 SOP §7 附录A 全衔接）
- 逐股按市值档计往返成本：佣金万2.5双边 + 印花税（2023-08-28 前千1/后万5，**时变**）+ 过户万0.1双边 + 滑点 5/10/20/30bp
- 调仓换手 = Σ|Δw_i|；报告单边年化换手
- 回测默认**全仓再平衡**；再平衡带（±20%）作为降成本变体单独跑

### 3.5 防未来函数检查清单（每轮回测前自查，报告附自查表）

| # | 泄漏类型 | 检查 |
|---|---------|------|
| 1 | 用 T 日收盘数据决策 T 日收盘交易 | 执行价必须 T+1 开盘 |
| 2 | 财务数据未按公告日 PIT 对齐 | 用 v3 §3 的 PIT 规则 |
| 3 | 涨跌停/停牌股假想成交 | 执行模型过滤 |
| 4 | 幸存者偏差（只回测现存股票） | 声明 + 用退市股列表补测 |
| 5 | 用全样本统计量（如全期均值/标准差）做当期中性化 | 中性化只用当时点前 24 月滚动窗口 |
| 6 | 参数在全样本上调优后回测同一样本 | 参数定于样本外（一次确认制，v3 §3-5） |

### 3.6 基准与对齐
- 双基准：沪深300、中证500（指数收益含分红，akshare `stock_zh_index_daily` / 指数收盘价近似）
- 对齐口径：同期间、同再平衡日历、月收益序列对比
- 报告：超额年化、超额夏普、跟踪误差、信息比率

### 3.7 绩效指标口径（与 empyrical 一致）

| 指标 | 口径 |
|------|------|
| 年化收益 | 几何年化（3.2） |
| 年化波动 | 月收益 std × √12 |
| 夏普 | (年化 − rf) / 年化波动，rf=0（一致于检验 v3 §10） |
| 最大回撤 | 净值峰值→谷值 |
| 卡玛 | 年化 / 最大回撤 |
| 胜率 | 月收益 > 0 比例 |
| 换手 | 单边年化 Σ\|Δw\| / 12 |

### 3.8 回测必报组合（与 SOP §3.3 衔接）
毛收益 / 净收益 / 成本拖累 / 换手 / 三档成本敏感性（0.5x/1x/2x）/ 双基准超额 / 逐年收益表。

## 4. 样本期与数据新鲜度（用户核心要求）

### 4.1 原则：结构可比性 > 样本长度
A股近年制度剧变：2020-08 创业板注册制+涨跌停±20%、2023-02 全面注册制、2023-08 印花税减半、2021-02 抱团瓦解、2024 微盘流动性危机、退市常态化、量化占比上升。**旧数据描述的是已消失的市场结构**，长样本≠高置信。

### 4.2 样本分层（回测用）

| 层级 | 区间 | 月数 | 角色 |
|------|------|------|------|
| **主回测** | **2019-01 ~ 今** | ~90 | 判定依据（注册制改革前夜至今，含完整牛熊周期） |
| **核心子样本** | **2021-02 ~ 今** | ~66 | **最重要的判定段**（抱团瓦解后，结构最接近当前；主判定结论必须在此段成立） |
| 参考样本 | 2017-01 ~ 2018-12 | 24 | 仅背景展示，不作判定 |
| 弃用 | < 2017 | — | 不作任何依据 |

### 4.3 数据新鲜度要求
1. 回测数据必须更新到**最近一个完整月**；超过 1 个半月未更新 → 回测结果标记"陈旧"
2. **每季度强制重拉数据重跑主回测**（同时检验数据漂移与策略稳定性）
3. 样本外确认（v3 §3-5）：最近 24 月不回看调参，作为策略上线前最后一道确认
4. 每月选股执行（生产）使用当月最新数据，与回测口径一致

### 4.4 与因子检验 v3 的衔接
- v3 因子检验主判定样本 = 2017-01 起（已定稿）；本规范回测判定 = 2019-01 起（更新鲜）
- 矛盾处理：因子入池需在 2017+ 显著；**策略回测判定以 2019+ 与 2021+ 为准**——因子在 2017-2018 有效但 2019+ 失效的，视为结构失效，不得入策略
