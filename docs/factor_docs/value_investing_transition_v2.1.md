## 1. 转型目标与哲学

### 1.1 现状诊断

当前系统为**多因子打分排序器**：9 因子（EP/BP/ROE_TTM/GPM/CFO_NI_TTM/LEV/MOM_60D/TURNOVER/LOG_MCAP，VOL_RATIO 已并入 TURNOVER）线性加权 z-score 合成 SCORE，月度调仓，取 top 30。

与价值投资理念的偏差：

| 现状 | 价值投资理念 | 偏差 |
|------|------------|------|
| 动量因子 MOM_60D 权重 0.15 | 价格不是价值的来源 | 试点检验反向显著（signed NW-t=-3.63），#13 原方向淘汰、#12 反转待检 |
| 月度调仓、top30 高换手 | 长期持有、集中持仓 | 换手成本侵蚀，与"买入并持有"相悖 |
| 截面相对打分（z-score） | 绝对估值 + 安全边际 | 系统永远选"相对不贵"，不回答"是否真的便宜" |
| 无估值历史维度 | 估值分位（均值回归） | 无法识别"当前价格在自身历史的位置" |
| 无股息视角 | 股息率是价值锚 | 缺少现金流回报维度 |
| 无自由现金流视角 | FCF 是内在价值源泉 | CFO_NI_TTM 只是比率，无 FCF 绝对水平 |
| 质量因子只打分不设门槛 | 质量是护城河代理，有最低要求 | 低质量股只要估值低也能入选 |

### 1.2 转型后定位

从"多因子打分排序器"转为**价值投资决策系统**：

1. **质量门槛先行**：先排除，后定价（排除不赚钱/高杠杆/现金流差的公司）
2. **绝对估值 + 估值分位**：用估值历史分位识别安全边际，回答"现在便宜吗"
3. **股息与现金流**：股息率、自由现金流收益率作为价值锚
4. **集中持仓**：top 10-15（默认 12，等权）
5. **长期持有**：季度调仓（从月度降频），卖出规则价值导向（估值过高/基本面恶化才卖）
6. **规模/流动性降级为约束**：不参与打分，只做容量与可交易性过滤

### 1.3 转型边界（不做的事）

- ❌ 不做择时（不预测市场涨跌）
- ❌ 不追热点/主题轮动
- ❌ 不引入技术分析指标（除卖出的流动性约束外）
- ❌ 不改变回测引擎（backtest.py 已定稿 v2.1，直接复用；季度调仓=传季度信号日期）
- ❌ 不放弃统计检验纪律（所有新因子仍走 registry 前置登记 + v3 检验）

### 2.3 新增因子（本设计引入，需登记+检验）

| 新因子 | 定义 | 数据源 | 角色 |
|--------|------|--------|------|
| PE_PCTL | PE(TTM) **实际历史滚动窗口**分位（2018-01-02起累积；最短窗口≥250交易日，更短缺失） | 东财 RPT_VALUEANALYSIS_DET | 核心（估值分位） |
| PB_PCTL | PB(MRQ) 实际历史滚动窗口分位（同上） | 同上 | 核心 |
| DY | 股息率 = 最近 12 个月每股股息（含税，方案进度=实施分配）/ raw 现价 | 东财 fhps_detail_em（除权除息日 PIT 对齐） | 加分项 |
| FCF_YIELD | FCF收益率 = TTM自由现金流 / raw 总市值 | 东财 RPT_DMSK_FN_CASHFLOW（FCF = NETCASH_OPERATE − CONSTRUCT_LONG_ASSET） | 加分项 |

**数据口径要点（两轮审查实测强制）**：

1. **PE_PCTL/PB_PCTL**：
   - 窗口：**实际历史滚动窗口主口径**（数据源 2018-01-02 起，窗口随日历从 1 年累积至 ≈8.6 年；最短窗口阈值 ≥250 交易日才产出 PE_PCTL，更短→缺失并声明占比）——2023-01 前样本窗口 <5 年属正常，**不做固定 5 年要求**（否则 2018-2022 段 58% 样本无分位，P4 检验死锁）
   - 5 年固定窗口**降为敏感性**（仅 2023+ 子段报告）
   - 频率：日频序列计算分位，**月末最后交易日快照**（与 v3 §2 对齐）
   - 负值处理：历史亏损期 PE<0 剔除出分位序列；净资产为负 PB 同理
   - 幸存者偏差：**退市股在估值历史接口完全缺失**（实测300104/600401均空）→ 已知偏差声明+量化（§3.3）
2. **DY**：每股股息=最近12个月实际实施分配（方案进度过滤"实施分配"），raw 现价口径（v2.1 双口径铁律）；勿用 fhps 的"股息率"快照列
3. **FCF_YIELD**：
   - FCF = NETCASH_OPERATE − CONSTRUCT_LONG_ASSET（TTM 累计口径：最新期+去年年报−去年同期）
   - **PIT 对齐：NOTICE_DATE 实测为修订日非首次公告日，必须改用首次公告快照固化口径**（与 yjbb/lrb 同款；⚠️ 该"同款"假设——yjbb"最新公告日期"是否同为修订日——**待 P1 阶段实测确认**，P1 出口做 fhps 业绩披露日期交叉校验）
   - **金融股（银行/保险/证券/多元金融/信托）：FCF 语义失效（经营现金流≈存贷款流量），剔除出打分（中性化→0）**；CFO 门槛同样豁免
4. **registry 登记**：4 新因子 ⓪ 步前置登记（预期符号：PE_PCTL −、PB_PCTL −、DY +、FCF_YIELD +），样本期如实登记 **2018-01+**（数据源起点），检验脚本路径、时间戳锁定；未检验前权重标注"实验性"

## 3. 决策框架（新架构）

### 3.1 分层管线（替代单一 SCORE 排序）

```
全市场股票池
  │
  ├─ ① 可交易性过滤（约束层）
  │    ├─ 停牌/退市/ST 排除
  │    ├─ 市值 ≥ 30亿（滑点 ≤20bp 档）
  │    ├─ 日换手率 0.1% ~ 20%
  │    └─ 上市 ≥ 5 年（注：分位窗口不足的真实原因是数据源2018-01起点，
  │        与上市年限无关；上市≥5年仅保证个股自身财务/估值历史长度，
  │        窗口不足的股票按 §2.3 最短窗口规则产出或缺失）
  │
  ├─ ② 质量门槛（排除层，一票否决）
  │    ├─ 非金融：ROE_TTM ≥ 8% 或 近5年ROE_TTM年度值中位数 ≥ 8%
  │    ├─ 周期行业豁免：近5年ROE_TTM年度值中位数 ≥ 4% 且 EPS>0（同源5年中位数口径）
  │    ├─ 非金融：GPM > 0
  │    ├─ 非金融：CFO_NI_TTM > 0（金融股豁免）
  │    ├─ 非金融：LEV < 70%
  │    └─ EPS_TTM > 0（亏损直接排除；金融股同样适用——亏损券商排除，价值上合理）
  │
  ├─ ③ 估值打分（核心层）
  │    ├─ 估值分位：PE_PCTL / PB_PCTL（实际历史滚动窗口，月末快照）
  │    ├─ 绝对估值：EP_z / BP_z（申万一级行业内 z-score，与 v3 §7-2 一致）
  │    ├─ 股息与现金流：DY_z / FCF_YIELD_z（金融股 FCF_YIELD 剔除出打分→0；
  │        DY 对金融股保留——股息是真实已实施分配，银行股息有现金流含义）
  │    └─ 安全边际分（主观先验权重，W-编号草案，组合层检验后定稿）：
  │         0.30×PE_PCTL + 0.30×PB_PCTL + 0.15×EP_z + 0.15×BP_z + 0.05×DY_z + 0.05×FCF_YIELD_z
  │
  └─ ④ 组合构建
       ├─ 按安全边际分取 top 10-15（默认 12，**等权主口径**）
       ├─ 行业上限 ≤30%（申万一级）
       ├─ 个股上限 ≤10%（集中度控制）
       └─ 容量检查：单股单日 ≤5% ADV（v2.1）
```

**权重标注（Q2/P2-D 落实）**：安全边际分权重为"主观先验（待验）"，挂 W-编号草案（W-PE_PCTL-DESIGN-20260825-01 等）；定稿权重 = 组合层检验（leave-one-out ΔIC + 合成 IC vs 加权基准 B）之后由证据决定。DY/FCF_YIELD 各 0.05 为**低权重占位防污染**——检验通过前对 top12 排序实际贡献极小（价值组 0.90 主导），其角色是"检验后由证据决定"，不构成实盘依据。共线性闸门（|corr|>0.7）在检验时对价值组（PE_PCTL/PB_PCTL/EP/BP）强制检查。

**行业口径（P1-C 落实）**：层③行业内 z-score **统一使用申万一级行业分类**（31 个，与 v3 §7-2 检验口径一致）。生产数据获取方案：东财 datacenter 行业字段映射到申万一级（P1 阶段建映射表并验证覆盖率），或直接采用申万行业数据源——二选一在 P1 阶段实测后固定，registry 与检验脚本同步锁定。

**周期行业清单（P1-A 落实）**：申万一级周期行业 = 煤炭、钢铁、有色金属、基础化工、石油石化、农林牧渔、交通运输、建筑材料（8 个）。映射：P1 阶段建"东财所处行业 → 申万一级"映射表并验证（东财 61 行业 vs 申万 31 一级），覆盖率 <95% 时按未映射处理（不豁免）。"5年中位数"口径 = 近 5 个完整年度的 ROE_TTM 年度值中位数（≥4%）；"EPS>0" = 同源 5 年 EPS 中位数 >0（与 ROE 同年度序列）。

### 3.2 持仓与调仓规则

| 规则 | 旧（多因子） | 新（价值投资） |
|------|------------|--------------|
| 持仓数 | top 30 | top 10-15（默认 12，等权） |
| 调仓频率 | 月度 | 季度（每季末月最后一个交易日信号，T+1 执行） |
| 买入 | 新月度信号全换 | 补足因卖出腾出的仓位；仅当新标的安全边际分 > 现有最低分 × 1.1 才换入 |
| 卖出触发 | 排名跌出 top_n 即卖 | ① 估值分位顶线（见下确认条件）② 质量跌破门槛 ③ 停牌/退市/ST ④ 持仓满 8 季重估 |

**卖出规则细节（Q4/Q6/P1-4/P1-5 落实）**：

1. **检查频率**：卖出条件为**每日检查、T+1 执行**（与 v2.1 §2.3 退市整理期强制卖出、ST 生效日一致）；买入只在季度调仓日
2. **分位顶线卖出**：月末快照分位**连续 2 个月 >80%** 触发（确认窗口防 whipsaw）；阈值 75/80/85 × 有无确认窗口纳入回测敏感性必报；若回测显示该规则不增净收益 → 删除（卖出锚定基本面恶化+绝对高估，绝对高估可用 PE_TTM>40x 且 >历史均值+2σ 补充）
3. **冷却期（P2-E 落实）**：分位顶线卖出后**1 个季度内不买回该股**（防下季度分位回落即重新买入的 whipsaw 残余）
4. **现金空窗**：卖出腾出的现金空窗至下一季度调仓日，计 0 收益并在报告声明现金拖累（v2.1 §3.2 口径）；或允许当日从最近季度候补队列补足——**主口径：空窗计 0 收益**（更保守），候补补足作敏感性变体
5. **8 季重估**：持仓满 8 季且未触发卖出时，调仓日允许全量重排（豁免 ×1.1 换入门槛）——"强制重估"仅此操作语义，不设独立卖出事件

### 3.3 安全边际语义与已知偏差

安全边际分是**排序工具**，不是内在价值估算（不做 DCF 绝对定价）。分位越低 + 绝对估值越便宜 + 股息现金流越高 → 安全边际越大。

**已知偏差声明（P1-1/P0-A 落实）**：

| 偏差 | 方向 | 量化要求 |
|------|------|---------|
| 退市股在估值历史接口完全缺失 | 高估 | 回测期统计退市股占池比例，报告声明；分位计算不包含退市股历史 |
| 估值分位起点 2018-01-02（非 2010s） | 窗口受限 | 分位窗口=实际历史长度（滚动累积），**缺失占比按月度报告**；检验分段报告 2018-2022（窗口 1~5 年段）与 2023+（≥5 年段）两段 IC 及窗口效应说明 |
| 历史亏损期 PE 为负剔除出分位序列 | 低估分位 | 报告剔除比例；负 PE 期间用 BP/市值替代 |
| 行业映射（东财→申万）覆盖不全 | 待定 | P1 阶段验证覆盖率；<95% 时未映射行业不豁免、不行业内 z（回退全市场）并声明 |

## 8. 风险与待确认问题

### 8.1 风险

1. **幸存者偏差（已知事实）**：退市股在估值历史接口完全缺失 → 回测期高估方向，量化声明
2. **质量门槛过严**：ROE≥8% 可能排除周期底部价值股 → 周期豁免（8行业清单+5年中位数≥4%且EPS>0）+ 门槛敏感性（6%/8%/10%）
3. **集中持仓波动**：12 只组合集中度高 → 行业上限30%+个股10%部分缓解
4. **新因子未检验**：PE_PCTL 等未经 v3 检验前权重"实验性"，生产开关 fail-closed 拒绝实盘使用
5. **分位卖出规则**：趋势市过早离场风险 → 确认窗口+冷却期+敏感性必报+不增净收益则删除
6. **分位窗口前段缺失**：2018-2022 段分位窗口 <5 年 → 滚动窗口主口径 + 缺失占比月度声明 + 分段报告

### 8.2 待终审确认（v2.1 修订后残余问题）

1. 滚动窗口主口径（最短窗口≥250交易日）+ 分段报告方案是否可接受？
2. 周期行业清单（8 个申万一级）与"5年中位数≥4%且EPS>0"口径是否可操作？
3. 事件驱动卖出行=完整持仓快照的信号语义是否明确？
4. 行业内 z-score 统一申万一级（P1 建映射）是否可接受？
