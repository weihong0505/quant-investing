## 3. 东财 spot 字段比对与结论

- 东财 spot（`stock_zh_a_spot_em`，含「60日涨跌幅」f24 字段）今日被拒（RemoteDisconnected），**无法直接比对**。
- 判别式（解封后一键复核，本脚本保留）：若东财 f24 ≈ raw60 → 不复权口径；若 ≈ hfq60（复权口径）→ 含分红再投。
- 实测确认：**qfq 与 hfq 的 60 日区间收益严格等价**（同除权因子集，数学恒等；样本差异 ≤0.01pp 舍入），raw 与复权差异 = 窗口内分红影响（样本 2.4~3.4pp，与每股派息/期初价对账吻合）。
- 分红对账（|raw−hfq| 收益差 vs 窗口内每股派息/期初 raw 价）误差 0.06~0.30pp → 新浪复权数据自洽、可用作 hfq 口径基准。601398 工商银行（窗口内无除权）为对照：三口径 60 日收益差 ≤0.04pp。
- 对 MOM_60D 的影响：raw 口径的 60 日涨跌幅会**系统性低估高股息股的动量**（样本内 银行/神华 raw−hfq 达 2~5pp），横截面 rank 与复权口径**不等价**（不同于 qfq/hfq 的 Spearman=1.0）；因此该字段口径**必须确认并固定**，一旦东财改口径因子静默漂移。
- 当前状态记录：今日缓存 spot（新浪降级源）的「60日涨跌幅」全列为 NaN → `multi_factor_value.py` 中 MOM_60D 全中性 0 分（fillna 兜底），因子暂时失效但不产生错误信号；东财解封后须复核口径并回填审计表。
- 修改建议：① 东财解封后立即跑本脚本复核 f24 口径并回填审计表；② 代码注释声明 MOM_60D 来源与口径（见 multi_factor_value.py L287 注释）；③ 中期方案：MOM_60D 改为自算 hfq 60 日收益（新浪 hfq 日线，月度缓存），彻底摆脱 spot 快照口径不确定性——需在 factor_docs 立项走 SOP 审批。
