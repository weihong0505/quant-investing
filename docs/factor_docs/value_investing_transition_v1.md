## 1. 转型目标与哲学

### 1.1 现状诊断

当前系统为**多因子打分排序器**：10 因子（EP/BP/ROE_TTM/GPM/CFO_NI_TTM/LEV/MOM_60D/TURNOVER/LOG_MCAP）线性加权 z-score 合成 SCORE，月度调仓，取 top 30。

存在的问题（与价值投资理念的偏差）：

| 现状 | 价值投资理念 | 偏差 |
|------|------------|------|
| 动量因子 MOM_60D 权重 0.15 | 价格不是价值的来源 | 试点检验反向显著（signed NW-t=-3.63），已作废待重登记 |
| 月度调仓、top30 高换手 | 长期持有、集中持仓 | 换手成本侵蚀，与"买入并持有"相悖 |
| 截面相对打分（z-score） | 绝对估值 + 安全边际 | 系统永远选"相对不贵"，不回答"是否真的便宜" |
| 无估值历史维度 | 估值分位（均值回归） | 无法识别"当前价格在自身历史的位置" |
| 无股息视角 | 股息率是价值锚 | 缺少现金流回报维度 |
| 无自由现金流视角 | FCF 是内在价值源泉 | CFO_NI_TTM 只是比率，无 FCF 绝对水平 |
| 质量因子只打分不设门槛 | 质量是护城河代理，有最低要求 | 低质量股只要估值低也能入选 |

### 1.2 转型后定位

从"多因子打分排序器"转为**价值投资决策系统**：

1. **质量门槛先行**：先排除，后定价（排除不赚钱/高杠杆/现金流差的公司）
2. **绝对估值 + 估值分位**：用估值历史分位识别安全边际，回答"现在便宜吗"
3. **股息与现金流**：股息率、自由现金流收益率作为价值锚
4. **集中持仓**：top 10-15（从 30 降）
5. **长期持有**：季度调仓（从月度降频），卖出规则价值导向（估值过高/基本面恶化才卖）
6. **规模/流动性降级为约束**：不参与打分，只做容量与可交易性过滤

### 1.3 转型边界（不做的事）

- ❌ 不做择时（不预测市场涨跌）
- ❌ 不追热点/主题轮动
- ❌ 不引入技术分析指标（除卖出的流动性约束外）
- ❌ 不改变回测引擎（backtest.py 已定稿 v2.1，直接复用）
- ❌ 不放弃统计检验纪律（所有新因子仍走 registry 前置登记 + v3 检验）

## 2. 因子体系取舍

### 2.1 保留并强化（核心价值因子）

| 因子 | 角色变化 | 说明 |
|------|---------|------|
| EP | 核心打分（权重提高） | TTM 口径已落地（C9），绝对水平+分位双用 |
| BP | 核心打分（权重提高） | 同上 |
| ROE_TTM | 质量门槛 + 打分 | 门槛：非金融 ≥8%；打分保留 |
| GPM | 质量门槛 + 打分 | 门槛：非金融 >0；金融中性化 |
| CFO_NI_TTM | 质量门槛 + 打分 | 门槛：>0（现金流质量） |
| LEV | 质量门槛 + 打分 | 门槛：<70%；金融股中性化 |

### 2.2 降级为约束（不参与打分）

| 因子 | 原角色 | 新角色 |
|------|--------|--------|
| TURNOVER | 打分（-1，低换手偏好） | 流动性过滤：排除日换手率 <0.1%（流动性枯竭）或 >20%（过度投机） |
| LOG_MCAP | 打分（-1，小市值偏好） | 容量约束：排除 <30 亿市值（滑点 30bp 档），不参与打分 |
| MOM_60D | 打分（+1，试点反向显著） | **淘汰**（试点反向证据 + FM 无增量，registry #12/#13/#17） |

### 2.3 新增因子（本设计引入，需登记+检验）

| 新因子 | 定义 | 数据源 | 角色 |
|--------|------|--------|------|
| PE_PCTL | PE(TTM) 过去 10 年分位（0-100%） | 东财 RPT_VALUEANALYSIS_DET 历史序列 | 核心（估值分位） |
| PB_PCTL | PB 过去 10 年分位 | 同上 | 核心 |
| DY | 股息率 = 最近 12 个月每股股息 / raw 现价 | 东财 fhps 分红送转表 | 加分项 |
| FCF_YIELD | FCF收益率 = TTM自由现金流 / raw 总市值 | 东财 RPT_DMSK_FN_CASHFLOW + 市值 | 加分项 |

> 注：PE_PCTL/PB_PCTL 数据跨 10 年需历史估值序列（接口已实测可用）；DY/FCF_YIELD 需先验证口径再登记。**所有新因子必须走 registry 前置登记 + v3 统计检验**（SOP §3.0.2 强制），未检验前权重标注"实验性"。

## 3. 决策框架（新架构）

### 3.1 分层管线（替代单一 SCORE 排序）

```
全市场股票池
  │
  ├─ ① 可交易性过滤（约束层）
  │    ├─ 停牌/退市/ST 排除
  │    ├─ 市值 ≥ 30亿（滑点 ≤20bp 档）
  │    ├─ 日换手率 0.1% ~ 20%
  │    └─ 上市 ≥ 2 年（估值分位需历史）
  │
  ├─ ② 质量门槛（排除层，一票否决）
  │    ├─ 非金融：ROE_TTM ≥ 8%
  │    ├─ 非金融：GPM > 0
  │    ├─ CFO_NI_TTM > 0（现金流为正）
  │    ├─ LEV < 70%（非金融）
  │    └─ EPS_TTM > 0（连续盈利，亏损直接排除）
  │
  ├─ ③ 估值打分（核心层）
  │    ├─ 估值分位：PE_PCTL/PB_PCTL（越低分越高）
  │    ├─ 绝对估值：EP/BP z-score（行业内）
  │    ├─ 股息与现金流：DY/FCF_YIELD 加分
  │    └─ 安全边际分 = 0.35×PE_PCTL + 0.35×PB_PCTL + 0.20×EP_z + 0.10×DY_z（权重待审）
  │
  └─ ④ 组合构建
       ├─ 按安全边际分取 top 10-15（默认 12）
       ├─ 行业上限 ≤30%（单一行业暴露控制）
       └─ 个股上限 ≤10%（集中度控制）
```

### 3.2 持仓与调仓规则

| 规则 | 旧（多因子） | 新（价值投资） |
|------|------------|--------------|
| 持仓数 | top 30 | top 10-15（默认 12） |
| 调仓频率 | 月度 | 季度（每季末月最后一个交易日信号，T+1 执行） |
| 买入 | 新月度信号全换 | 补足因卖出腾出的仓位；仅当新标的安全边际分 > 现有最低分 × 1.1 才换入 |
| 卖出 | 排名跌出 top_n 即卖 | ① 估值分位 >80% ② 质量跌破门槛 ③ 持仓满 8 季强制重估 ④ 停牌/退市/ST |

### 3.3 安全边际语义

安全边际分是**排序工具**，不是内在价值估算（不做 DCF 绝对定价——数据与假设风险过大）。分位越低 + 绝对估值越便宜 + 股息现金流越高 → 安全边际越大。卖出规则用分位顶线（>80%）实现"高估卖出"的均值回归逻辑。

## 8. 风险与待审查问题

### 8.1 风险

1. **估值分位幸存者偏差**：RPT_VALUEANALYSIS_DET 历史序列对已退市股票可能缺失——分位计算需处理
2. **质量门槛过严**：ROE≥8%+CFO>0 可能排除大量周期底部股票（周期股低 ROE 恰是买入点）——需考虑周期行业豁免或分位数门槛
3. **集中持仓波动**：12 只组合集中度高，单股黑天鹅影响大——行业上限 30% 只能部分缓解
4. **新因子未检验**：PE_PCTL 等未经 v3 检验前权重为"实验性"，不得作实盘依据（SOP §3.0.1 强制）
5. **季度调仓 + 卖出规则**：卖出规则可能造成"分位>80% 即卖"在牛市中过早离场——需回测验证

### 8.2 待审查问题清单（请审查 agent 逐项裁决）

1. 质量门槛阈值（ROE≥8%、LEV<70%、CFO>0、GPM>0）是否合理？金融股/周期股如何处理？
2. 安全边际分权重（0.35/0.35/0.20/0.10）依据是否充分？是否应加入 DY/FCF_YIELD 更高权重？
3. 估值分位窗口 10 年是否合适？（A 股制度变化频繁，是否 5 年更稳？）
4. "分位>80% 卖出"规则在趋势市中的行为是否可接受？
5. 持仓 12 只 + 行业上限 30% + 个股上限 10% 的参数合理性？
6. 季度调仓是否与卖出规则冲突（季度内涨到 80% 分位何时卖）？
7. 新增 4 因子的数据口径是否有坑（PE 用 TTM 还是动态？分位用日频还是月频？）
8. 转型后旧多因子系统是否保留作对照（A/B 对比回测）？
9. MOM_60D 直接淘汰 vs 保留观察的裁决是否与 registry #12/#13/#17 一致？
10. 阶段划分是否合理？P2 重构与 P4 检验的顺序是否符合 SOP §3.0.2（检验是 WEIGHTS 前置条件）？
